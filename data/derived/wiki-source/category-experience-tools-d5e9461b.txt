{{RightToc}}Experience Tools provide a way to request persistent permissions across multiple logins and with multiple objects and scripts.  In order to use these functions, you must have an ''experience key''.  For further information, see [http://community.secondlife.com/t5/English-Knowledge-Base/Experiences-in-Second-Life/ta-p/2744686 Experiences in Second Life] in the Second Life Knowledge Base.

== Experience Persistent Storage==
The persistent storage of experiences can still be used even where the experience is not set up as an allowed experience.

Current limits for Persistent storage:
* Each key may be a maximum of 1011 bytes
* Each value may be a maximum of 4095 bytes
* Total stored data is restricted to 128 MiB

These are all asynchronous functions, they all return a {{LSLGC|Key/handle|handle}} that corresponds to a [[dataserver]] event.

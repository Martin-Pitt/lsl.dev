{{LSL_Function
|func_sleep=0.0|func_energy=10.0
|func=llLinksetDataCountFound
|p1_type=string|p1_name=pattern|p1_desc=A regular expression describing which keys to return.
|return_type=integer
|return_text=Count of the keys in the datastore that match the supplied pattern.
|func_footnote
|func_desc=
The '''llLinksetDataCountFound''' function returns the number of keys in the linkset datastore that match the pattern supplied in the {{LSLP|pattern}}.
|func_footnote
|spec=
{{LSLP|pattern}} is a [https://en.wikipedia.org/wiki/Regular_expression Regular expression].
|examples=
The following regular expression code can be used to count UUID keys. (Such as those use to identify user UUID)
<source lang="lsl2">
        integer numKeysFound = llLinksetDataCountFound("(?i)^[0-9a-f]{8}(-[0-9a-f]{4}){3}-[0-9a-f]{12}$",  0, 0);
</source>
The following code can also be used to count UUID keys in LinksetData memory.
<source lang="lsl2">
        integer numKeysFound = llLinksetDataCountFound("^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$",  0, 0);
</source>

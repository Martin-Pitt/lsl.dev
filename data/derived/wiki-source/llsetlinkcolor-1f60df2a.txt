|p2_type=vector|p2_name=color
|p3_type=integer|p3_name=face
|func_footnote
|func_desc=If a prim exists in the link set at {{LSLP|link}}, set the [[PBR_Materials#Nomenclature_changes|Blinn-Phong]] {{LSLP|color}} on {{LSLP|face}} of that prim.
|return_text
|spec
|caveats=
* llSetLinkColor will have no visible effect on faces with a PBR material. To work on faces both with and without a PBR material, use this snippet: <source lang="lsl2">
if (llIsLinkGLTFMaterial(LINK_THIS, ALL_SIDES)) {
    llSetLinkGLTFOverrides(LINK_THIS, ALL_SIDES, [OVERRIDE_GLTF_BASE_COLOR_FACTOR, llsRGB2Linear(color)]);
} else {
    llSetLinkColor(LINK_THIS, color, ALL_SIDES);
}
</source>
|constants
|examples=Turn a link set green
<source lang="lsl2">
default
{
    touch_start(integer detected)
    {
        llSetLinkColor(LINK_SET, <0.0, 1.0, 0.0>, ALL_SIDES);
    }
}
</source>

|func_footnote=This function supports sha1, sha224, sha256, sha384, sha512 for '''algorithm'''.

Whitespace and newlines are ignored for '''public_key'''.
|func_desc
|return_text=indicating whether the {{Wikipedia|RSA_(cryptosystem)|RSA}} '''signature''' is valid for '''msg''' when using hash algorithm '''algorithm''' and public RSA key '''public_key'''.  Returns [[TRUE]] if the signature is verified, and [[FALSE]] otherwise.  Use [[llSignRSA]] to generate '''signature'''. Combined, the two functions can generate and verify signed messages.
|spec
|caveats=
* Despite its 50-byte cost (100 in Mono), if '''private_key''' does not include the "-----BEGIN PUBLIC KEY-----" header and "-----END PUBLIC KEY-----" footer, this function will throw a non-fatal error, "llVerifyRSA: failed to import public key", and return [[FALSE]].
* Any invalid '''algorithm''' will throw a non-fatal error, "llVerifyRSA valid algorithms are: sha1, sha224, sha256, sha384, sha512", and return [[FALSE]].

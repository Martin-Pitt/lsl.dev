# 2022-04-21.571166

Monday, April 25, 2022

# Release Notes

This release fixes some miscellaneous bugs, and also introduces some new LSL functionality.

### New LSL functionality

-
Added new LSL function llGetVisualParams(). Returns a list of avatar appearance details for a given agent. See [https://wiki.secondlife.com/wiki/LlGetVisualParams](https://wiki.secondlife.com/wiki/LlGetVisualParams) for details.

-
Added new options to llGetParcelDetails(): PARCEL_DETAILS_LANDING_POINT, PARCEL_DETAILS_LANDING_LOOKAT, PARCEL_DETAILS_TP_ROUTING, PARCEL_DETAILS_FLAGS, PARCEL_DETAILS_SCRIPT_DANGER. See [https://wiki.secondlife.com/wiki/LlGetParcelDetails](https://wiki.secondlife.com/wiki/LlGetParcelDetails) for details.

-
Added new options to llGetObjectDetails(): OBJECT_MATERIAL, OBJECT_MASS, OBJECT_TEXT, OBJECT_REZ_TIME, OBJECT_LINK_NUMBER, OBJECT_SCALE, OBJECT_TEXT_COLOR, OBJECT_TEXT_ALPHA. See [https://wiki.secondlife.com/wiki/LlGetObjectDetails](https://wiki.secondlife.com/wiki/LlGetObjectDetails) for details.

-
Added new options to llGetEnv(): “agent_limit_max”, “agent_reserved”, “agent_unreserved”. See [https://wiki.secondlife.com/wiki/LlGetEnv](https://wiki.secondlife.com/wiki/LlGetEnv) for details.

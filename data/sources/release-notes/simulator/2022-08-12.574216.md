# 2022-08-12.574216

Monday, August 15, 2022

# Release Notes

This release contains a few changes. It quadruples the L$ transaction throttle rate for Skill Gaming regions to 120 over 30 seconds, and adds server-side tracking of deprecated messages sent by the viewer. It also introduces 2 new LSL functions, which are listed below.

### New LSL functionality

-
Added new LSL function llReplaceEnvironment(). Replaces the environment of a parcel or region. See [https://wiki.secondlife.com/wiki/LlReplaceEnvironment](https://wiki.secondlife.com/wiki/LlReplaceEnvironment) for details.

-
Added new LSL function llSetEnvironment(). Overrides specified environmental settings for a region or a parcel. See [https://wiki.secondlife.com/wiki/LlSetEnvironment](https://wiki.secondlife.com/wiki/LlSetEnvironment) for details.

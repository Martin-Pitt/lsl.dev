# Release Notes

This release contains stability improvements, fixes a few miscellaneous bugs, and also introduces new functions to the LSL API to allow for sound playback across any prim in a linkset

The new LSL functions include llAdjustSoundVolume(), llLinkSetSoundRadius(), llLinkStopSound(), llLinkSetSoundQueueing(), and llLinkPlaySound().

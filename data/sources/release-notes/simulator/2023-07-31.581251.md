# Release Notes

## New Features:

- Animesh can now be identified through llGetPrimitiveParams
- Estate ban limit increased to 750, Estate manager limit increased to 20. Note that a viewer update will be required to see the increased limits.
- New LSL functions llLinksetDataDeleteFound and llLinksetDataCountFound
- Change so that identical assets share the same ID

## Bug Fixes:

- BUG-233830: DATA_PAYINFO information would not always expire from the cache
- Fixed an issue where thumbnails were stripped when editing rezzed objects
- Further work on issue with friends not appearing online

# Release Notes

## Features:

- New function llGetInventoryDesc - returns the description of the inventory item: [https://wiki.secondlife.com/wiki/LlGetInventoryDesc](https://wiki.secondlife.com/wiki/LlGetInventoryDesc)
- New function llIsFriend - returns TRUE if agent_id and the owner of the prim the script is in are friends: [https://wiki.secondlife.com/wiki/LlIsFriend](https://wiki.secondlife.com/wiki/LlIsFriend)
- New function llRezObjectWithParams - apply a list of prim properties that are applied when the object is rezzed: [https://wiki.secondlife.com/wiki/LlRezObjectWithParams](https://wiki.secondlife.com/wiki/LlRezObjectWithParams)
- New function llListFindListNext - find the index of non-unique list entries beyond the first instance: [https://wiki.secondlife.com/wiki/LlListFindListNext](https://wiki.secondlife.com/wiki/LlListFindListNext)
- llSetDamage can now set negative damage: [https://wiki.secondlife.com/wiki/LlSetDamage](https://wiki.secondlife.com/wiki/LlSetDamage)
- Object collision sounds and damage are now a property of an object rather than the script that set them

## Bug Fixes

- Fixed a crash mode

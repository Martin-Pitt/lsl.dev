# 2024-02-21.7995320426

Monday, February 26, 2024

# Release Notes

# Features

- New function llComputeHash - generates an unsalted hash of a string using one of several algorithms (md5, sha256, etc.) [https://wiki.secondlife.com/wiki/LlComputeHash](https://wiki.secondlife.com/wiki/LlComputeHash)
- New function llGetNotecardLineSync - allows for reading simulator-cached notecards synchronously and without delay: [https://wiki.secondlife.com/wiki/LlGetNotecardLineSync](https://wiki.secondlife.com/wiki/LlGetNotecardLineSync)
- New function llGetCameraAspect - returns the camera aspect ratio of a HUD-attached agent: [https://wiki.secondlife.com/wiki/LlGetCameraAspect](https://wiki.secondlife.com/wiki/LlGetCameraAspect)
- New function llGetCameraFOV - returns the camera field-of-view of an agent who has granted permissions: [https://wiki.secondlife.com/wiki/LlGetCameraFOV](https://wiki.secondlife.com/wiki/LlGetCameraFOV)
- New function llWorldPosToHUD - returns a vector position in HUD frame for given world-frame vector coordinates of an agent who has granted permissions: [https://wiki.secondlife.com/wiki/LlWorldPosToHUD](https://wiki.secondlife.com/wiki/LlWorldPosToHUD)
- ObjectUpdate messages for root prims now contain data about linkset prim count
- AvatarAppearance messages now contain a list of attachment points and task_ids of all non-HUD attachments

# Bug Fixes

- Fixed an issue in which accounts created after November 2023 failed to receive offline IM and group notice emails after opting in
- Fixed an issue in which llSensor-using scripts crossing into a simulator with a higher detected limit would fail to run

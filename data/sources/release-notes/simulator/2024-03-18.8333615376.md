# Release Notes

# Features

- Reduced mesh download weight by 15%
- Added estate manager controls for scheduled region restarts: [https://wiki.secondlife.com/wiki/Region_Debug_Console#Schedule_region_restarts](https://wiki.secondlife.com/wiki/Region_Debug_Console#Schedule_region_restarts)
- New function llSetLinkSitFlags - sets various flags for a given sit target: [https://wiki.secondlife.com/wiki/LlSetLinkSitFlags](https://wiki.secondlife.com/wiki/LlSetLinkSitFlags)
- Increased the maximum number of objects detected by llSensor and llSensorRepeat from 16 to 32
- Added new capability LLInventoryObject for fast and reliable viewing of prim inventory

# Bug Fixes

- Fixed an off-by-one bug with LSL notecard reading - the 1024 byte limit is now treated precisely
- Fixed an agent locomotion bug related to using llSetHoverHeight in an attachment

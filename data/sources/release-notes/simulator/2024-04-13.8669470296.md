# Release Notes

# Features

This release introduces server side support for the Materials Featurettes viewer release.

- Enables the feature flags for:

- Mirrors
- PBR Terrain
- PBR Material Swatch
- 2k Textures

- Adds support for 2k texture import. Note that 2k texture import incurs a higher upload cost and requires the Materials Featurettes viewer.
- Adds PRIM_REFLECTION_PROBE_MIRROR flag to PRIM_REFLECTION_PROBE: [https://wiki.secondlife.com/wiki/PRIM_REFLECTION_PROBE_MIRROR](https://wiki.secondlife.com/wiki/PRIM_REFLECTION_PROBE_MIRROR)

Please see this blog post for more information about the features: [https://community.secondlife.com/blogs/entry/15291-mirrors-pbr-terrain-and-2k-textures/](https://community.secondlife.com/blogs/entry/15291-mirrors-pbr-terrain-and-2k-textures/)

To enjoy these new features, residents must use the latest (or newer) Materials Featurettes viewer, which may be downloaded at [https://releasenotes.secondlife.com/viewer/7.1.5.8472515256.html](https://releasenotes.secondlife.com/viewer/7.1.5.8472515256.html)

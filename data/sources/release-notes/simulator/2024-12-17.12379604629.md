# Release Notes

# Bug Fixes

- llModPow() now returns the correct value when x^n is larger than a 32-bit integer.

# Features

- llModPow() no longer sleeps for 1 second.
- llSetHoverHeight() and llGroundRepel() no longer activate the AGENT_FLYING flag from llGetAgentInfo() when used with an item attached to an avatar. Instead they sets a new flag: AGENT_FLOATING_VIA_SCRIPTED_ATTACHMENT. While in this state the avatar moves at the same speed as walking. It will also stay in its hover animation when moving horizontal and faling from a ledge to hover height (no falling animation)
- New LSL function llGetAttachedListFiltered(): returns a filtered list of avatar attachments.

- [https://wiki.secondlife.com/wiki/LlGetAttachedListFiltered](https://wiki.secondlife.com/wiki/LlGetAttachedListFiltered)
- Can return hud attachments if the hud attachment is compiled with the same experience and the avatar has accepted the experience.

- New LSL function llTransferOwnership(): Transfers ownership of an object to another avatar.

- [https://wiki.secondlife.com/wiki/LlTransferOwnership](https://wiki.secondlife.com/wiki/LlTransferOwnership)
- Depending on flags, can transfer ownership and stay in-world, move to the avatar’s inventory or create a copy in the avatar’s inventory.

- New LSL function llMapBeacon(): Places a map beacon and can open the map.

- [https://wiki.secondlife.com/wiki/LlMapBeacon](https://wiki.secondlife.com/wiki/LlMapBeacon)
- Needs a viewer update for all features to work properly

# Release Notes

# Bug Fixes

- Fixed a bug in which an avatar would play a running animation after sitting on the ground and then standing up.
- Fixed a bug in which toggling VEHICLE_FLAG_CAMERA_DECOUPLED when calling llSetVehicleFlags and llRemoveVehicleFlags had no effect until the vehicle triggers a full object update.
- Fixed 2 crash modes.

# Features

- Added the ability to get Object Permission Information with llGetObjectDetails().

- [https://wiki.secondlife.com/wiki/LlGetObjectDetails](https://wiki.secondlife.com/wiki/LlGetObjectDetails)
- Added OBJECT_PERMS which retrieves the permissions for the object as 5 integers.
- Added OBJECT_PERMS_COMBINED which retrieves the permissions for this object combined with all of its inventory items as 5 integers.

- Added MASK_COMBINED to llGetObjectPermMask() & llGetInventoryPermMask().

- [https://wiki.secondlife.com/wiki/LlGetInventoryPermMask](https://wiki.secondlife.com/wiki/LlGetInventoryPermMask)
- Including the MASK_COMBINED does not impact the output of the llGetInventoryPermMask() function, as the combined permissions are the only accessible permissions for inventory items.

- Added the preliminary support for creating and editing landmarks at custom locations.

- Added new capability “CreateLandmarkForPosition”
- Will require a future viewer build for feature to work properly.

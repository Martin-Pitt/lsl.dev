# 2025-03-03.13640255822

Tuesday, March 4, 2025

# Release Notes

# Bug Fixes

- Fixed an issue where the create landmark capability could create a non-existent asset
- Fixed an issue in which the avatar could become unable to navigate after some region crossings or teleports, with ‘Unable to find specified agent to request permissions.’ script errors appearing.
- Fixed an issue in which a fewer than expected number of offline IMs would be delivered at login time

# Features

- New LSL function llSetGroundTexture(). Allows region owners/managers to modify ground textures and properties. [https://wiki.secondlife.com/wiki/LlSetGroundTexture](https://wiki.secondlife.com/wiki/LlSetGroundTexture)
- Premium Plus accounts can now upload meshes for free
- Number of picks increased to 20 (requires ForeverFPS viewer update newer than 7.1.12.12999043440 to work properly)

Wednesday, April 30, 2025

# Release Notes

# Bug Fixes

- Fixed a longstanding issue in which logging back into a region after the previous session disconnected uncleanly (e.g. due to viewer crash) would fail
- Fixed a bug related to llSetGroundTexture applying the southeast and northwest height ranges incorrectly
- Fixed a missing tooltip for experience_permissions in the LSL editor

# Features

- New LSL function llSetLinkGLTFOverrides(). Enables setting of certain GLTF material overrides in isolation. [https://wiki.secondlife.com/wiki/LlSetLinkGLTFOverrides](https://wiki.secondlife.com/wiki/LlSetLinkGLTFOverrides)
- New LSL function llIsLinkGLTFMaterial(). Returns a boolean indicating whether a prim face has a GLTF material or not. [https://wiki.secondlife.com/wiki/LlIsLinkGLTFMaterial](https://wiki.secondlife.com/wiki/LlIsLinkGLTFMaterial)
- Greatly improved the speed of llSetLinkPrimitiveParamsFast() when applying changes to multiple prims in a single call
- Extended the avatar hover height range allowed by the simulator from ±2m to ±3m. Note that this change requires a viewer with [https://github.com/secondlife/viewer/issues/2702](https://github.com/secondlife/viewer/issues/2702) to render extreme hover heights properly, such as the upcoming 2025.04 viewer.

# Release Notes

# Bug Fixes

- Fixed a bug in which certain objects would not appear in the viewer
- Texture animation and target omega properties of an object are properly copied on duplication
- Fixed an issue in which llGetTimeofDay() would not return the correct parcel’s time of day when called in the attachment of a seated agent
- Fixed the response data for the OBJECT_DAMAGE_TYPE parameter of llGetObjectDetails
- Fixed some issues around listing the parcels owned by a group

# Features

- New LSL function llSetParcelForSale(). Allows a parcel or region owner to toggle the ‘for sale’ properties of a parcel. Currently requires a new LSL permission flag which is not yet available.
- Reenabled PBR terrain transform settings (material repeats, offsets, rotations)
- Added support for parsing new mesh metrics fields

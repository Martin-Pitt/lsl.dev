# Release Notes

# Bug Fixes

- Fixed case in which llTransferOwnership would removed transferable inventory items which were next-owner-no-transfer
- Fixed llRezObjectWithParams automatically enabling the temp-on-rez flag for objects rezzed with the REZ_DAMAGE parameter
- Fixed some cases in which the webRTC voice moderation status of agents arriving in parcels would appear incorrectly
- Stability improvements

- LSL function llSetParcelForSale() is now available. Can update the ‘For Sale’ state of a parcel. See [https://wiki.secondlife.com/wiki/LlSetParcelForSale](https://wiki.secondlife.com/wiki/LlSetParcelForSale) for details.
- Annual SSL certificate updates

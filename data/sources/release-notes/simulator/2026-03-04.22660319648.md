# Release Notes

# Features

- This release enables WebRTC Voice audio by default on the simulator. See [https://community.secondlife.com/news/featured-news/webrtc-voice-open-beta-is-expanding-r11245/](https://community.secondlife.com/news/featured-news/webrtc-voice-open-beta-is-expanding-r11245/) for details.
- To see if your region is currently using WebRTC, open ‘About Second Life’ in the viewer, and look at the “Voice Server Version” shown at the bottom.

# Reporting Issues

- If you encounter any issues, please ensure that you are running a viewer with the latest fixes related to WebRTC voice.
- Currently, the Second Life 26.1.0.22641522367 Releas Viewer has the latest voice fixes: [https://releasenotes.secondlife.com/viewer/26.1.0.22641522367.html](https://releasenotes.secondlife.com/viewer/26.1.0.22641522367.html).
- These fixes have also been pulled into the Firestorm Nightly Viewer build as of 2026-03-17.
- Bug reports may be filed at the Second Life feedback portal: [https://feedback.secondlife.com/](https://feedback.secondlife.com/)

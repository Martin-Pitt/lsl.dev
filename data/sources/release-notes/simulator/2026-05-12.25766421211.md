# Release Notes

# Bug Fixes

- Fixed an issue that causes an avatar to be droped from P2P, group, or ad hoc voice calls approximately 1 minute after region crossing or teleport

# Features

- Changed voice-provisioning response for Vivox voice to prevent the viewer from showing an error notification after login

# Known Issues

- The latest voice-provisioning change exposes a bug in Linux viewer builds which can cause the ‘Speak’ button to become disabled unexpectedly. See the issue at [https://github.com/secondlife/viewer/issues/5795](https://github.com/secondlife/viewer/issues/5795) for details and a workaround.

# Reporting Issues

- If you encounter any issues, please ensure that you are running a viewer with the latest fixes related to WebRTC voice.
- Currently, the Second Life 26.1.0.22641522367 Release Viewer has the most important voice fixes: [https://releasenotes.secondlife.com/viewer/26.1.0.22641522367.html](https://releasenotes.secondlife.com/viewer/26.1.0.22641522367.html)
- The Second Life 26.2 “Flat UI” Beta viewer has even more fixes, plus support for moderating parcel & region voice chat: [https://releasenotes.secondlife.com/viewer/26.2.0.25021396775.html](https://releasenotes.secondlife.com/viewer/26.2.0.25021396775.html)
- For Firestorm users, we recommend running the latest Firestorm 7.2.4 (80703) Preview viewer, which should be up to date with voice changes found in the Second Life 26.2 viewer.

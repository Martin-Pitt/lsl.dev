# Known Issues

- In certain cases, Premium Plus users can still be charged for mesh uploads after crossing a region boundary (server#2565). If the estimated upload cost appears as nonzero, returning to the previous region or teleporting to a far-away region is a workaround.
- There are still some cases in which P2P chat conversations can hit session initialization failures (server#2573)
- Rezzing objects from agent inventory onto other objects can be incorrectly blocked if the surrounding parcels’ permissions disable build. Angling the camera to point downward is a known workaround for this issue.

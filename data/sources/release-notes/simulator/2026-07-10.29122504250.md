# Release Notes

# Bug Fixes

- Fixed an issue that intermittently caused certain regions to be inaccessible with a “Failed to grant capabilities” error
- Fixed an issue that caused group members’ attached scripts to not run when parcel options allow group scripts
- Fixed an issue that could cause object rez to fail unexpectedly due to parcel permissions when rezzing inside a very narrow parcel
- Fixed an issue that would sometimes cause “login to last location” to fail immediately after the last session ended
- Fixed an issue in which avatars would sometimes slide after crouch-walking a short distance
- Fixed an issue in which avatars would sometimes slide after walking next to a low obstacle
- Fixed an issue that would cause a WebRTC p2p call to be dropped after performing several region crossings

# Features

- Improved internal record-keeping when llManageEstateAccess operates with PERMISSION_SILENT_ESTATE_MANAGEMENT
- Fully removed support for Vivox voice chat
- Agents who are not the owner or estate manager are no longer able to login directly to a region that has already started its restart countdown

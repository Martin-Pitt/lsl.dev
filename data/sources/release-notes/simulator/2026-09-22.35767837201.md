Wednesday, September 23, 2026

# Release Notes

# Bug Fixes

- Fixed an issue that caused avatars to slide off of slow-moving platforms
- Fixed an issue that caused attached scripts to not run in no-script parcels at high elevation
- Fixed an intermittent issue that prevented some set of agents not hearing others in nearby voice after a voice server restart
- Fixed some crash modes
- Fixed a SimFPS performance regression in regions with very heavy script load
- Fixed Incorrect run-length encoding of zero values in UDP messages

# Features

- Reworked the LSL Game Control feature. Added new LSL permission [PERMISSION_GAME_CONTROL](https://wiki.secondlife.com/wiki/PERMISSION_GAME_CONTROL) , along with new LSL functions [llGetGameControlMode](https://wiki.secondlife.com/wiki/LlGetGameControlMode), and [llGetGameControlModeAxes](https://wiki.secondlife.com/wiki/LlGetGameControlModeAxes), [llGetGameControlModeButtons](https://wiki.secondlife.com/wiki/LlGetGameControlModeButtons) for the feature. See [LSL Game Control Beta](https://wiki.secondlife.com/wiki/LSL_Game_Control_Beta) for full details.
- Added new constants OBJECT_VOLUME_DETECT and OBJECT_LOCKED to [llGetObjectDetails](https://wiki.secondlife.com/wiki/LlGetObjectDetails)

# Known Issues

- The fix for server#2716 involved reverting the change that addressed bugs server#2196 and server#2563. The reverted bugs were originally fixed with server 2026-07-10.29122504250. Expect the original avatar sliding behaviors to return.
- server#2750: “game_control() events stop firing in script if the agent or script temporarily leaves the region”
- server#2749: “llGetGameControlModeButtons includes unbound buttons in returned mask”
- The current game control test viewer has a few known issues, which also impact the game control experience. See [viewer#6288](https://github.com/secondlife/viewer/issues/6288), [viewer#6291](https://github.com/secondlife/viewer/issues/6291), and [viewer#6302](https://github.com/secondlife/viewer/issues/6302).

# Release Notes

## Game Control Alpha

This Alpha release introduces support for the game control feature which provides new support for game controller devices and also sends GameControlData messages to the server for access to in-world scripted objects.

### Game Control

This feature is intended to work with most popular game controllers and joysticks, with either a bluetooth or wired connection. There is new UI for managing game controller devices:

Me menu –> Preferences… option –> Game Controls panel

The feature is enabled by default, but can be turned off:

Me menu –> Preferences… option –> Game Controls panel –> Server Data sub-tab –> [ ] Send GameControl Data to Server checkbox

A game controller is not required to use the feature: some keyboard input (e.g. when controlling the avatar) will be “translated” into data that can be used by in-world scripts.

For additional information please visit our Wiki [https://wiki.secondlife.com/wiki/Game_control](https://wiki.secondlife.com/wiki/Game_control)

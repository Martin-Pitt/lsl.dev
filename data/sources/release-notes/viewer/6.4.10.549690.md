# Release Notes

Updates to jellydoll behavior for better performance.

If an avatar is explicitly set to no render, or its complexity exceeds the chosen complexity threshold, it will be displayed as a jellydoll. Jellydolls are simplified human avatars, displayed in a uniform color without attachments, animations or other customizations.

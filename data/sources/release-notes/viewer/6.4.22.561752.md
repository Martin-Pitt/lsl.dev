# Release Notes

This release of the Viewer updates the embedded web browser to a substantially more recent version - you can think of it as being similar to Google Chrome version 91 that you might use as your desktop browser.

It also includes a large number of fixes for security related issues and exploits that Google have deployed since the last release.

# Release Notes

This project adds a feature to the Viewer that allows for the capture of 360 panorama (equirectangular) snapshots which can be saved to the users’ local computer and then viewed or shared via social media streams.

Start the Viewer, log in and select “World ▶ 360 snapshot” to give it a try.

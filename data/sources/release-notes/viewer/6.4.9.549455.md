# Release Notes

### Love Me Render #4

A wafer thin collection of high priority graphic fixes for the EEP viewer following it’s main release.

Including:
* Appearance Mode Lighting has been changed to be more accurate
* HUDs are no longer affected by Atmosphere & Lighting changes
* Derendering Avatar type would also derender some rezzed mesh objects
* Cloud texture was rendered backwards
* Viewer froze for several seconds after receiving a message from a large group

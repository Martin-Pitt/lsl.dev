# Release Notes

Combined release of DRTVWR-519 (Simplified Cache) and DRTVWR-534 (360 Capture).

This version of the viewer replaces the VFS cache system used to save local copies of frequently used assets such as meshes, sounds and animations with a simplified cache.

There should be no user facing differences and your Second Life experience should be identical to other versions.

This project also adds a feature to the Viewer that allows for the capture of 360 panorama (equirectangular) snapshots which can be saved to the users’ local computer and then viewed or shared via social media streams.

Start the Viewer, log in and select “World ▶ 360 snapshot” to give it a try.

# Release Notes

### Viewer MFA

Multi-factor authentication is now supported by the Second Life viewer in addition to login at [https://secondlife.com](https://secondlife.com)

Please see this article for full explanation of the changes (note that it does not yet mention Viewer support): [https://community.secondlife.com/blogs/entry/8952-introducing-multi-factor-authentication-for-your-second-life-account/](https://community.secondlife.com/blogs/entry/8952-introducing-multi-factor-authentication-for-your-second-life-account/)

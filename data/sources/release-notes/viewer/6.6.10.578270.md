# Release Notes

Say hello to many new UI translations for the following languages: *Español (Spanish) *Français (French) *Deutsch (German) *Italiano (Italian) *Português (Portuguese) *日本語 (Japanese)

Crashes are no fun, which is why we’ve added some helpful fixes. This includes an unpleasant crash that occurred while attempting to upload a model while having “Bounding Box” selected as Physics model.

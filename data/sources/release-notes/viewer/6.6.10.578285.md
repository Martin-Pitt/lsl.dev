# Release Notes

### Maintenance Resident Inspired Improvements

Don’t speak the same language? You don’t have to! The wonderful Translation services are now updated to be used in IMs and group messaging!

Groups now show recent chat when they first open up. See [https://community.secondlife.com/blogs/entry/12652-coming-soon-to-a-viewer-near-you-group-chat-history/](https://community.secondlife.com/blogs/entry/12652-coming-soon-to-a-viewer-near-you-group-chat-history/) for the details.

Users with Windows Mouse Keys accessibility enabled will no longer have their mouse pointers jumping around randomly.

For those curious about their object permissions, Slam bits have made a triumphant return from the dead! Find out more about slam bits here: [https://wiki.secondlife.com/wiki/Debug_Permissions](https://wiki.secondlife.com/wiki/Debug_Permissions)

Users have been so good at causing crashes so we’ve become better at fixing them. Said crash fixes are included here!

See below for more

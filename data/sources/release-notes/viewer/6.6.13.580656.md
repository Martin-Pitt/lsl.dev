# Release Notes

### Inventory Item Preview and Single Folder View

##### Inventory Item Preview

Finding this new feature is easy. The option menu for every inventory item, including folders, now has the option “Image.” There is no L$ charge for uploading an image as an item preview.

Merchants and creators can add previews to their delivery folders and items, and you will see them in your inventory with no extra effort on your part.

For textures and snapshots, you do not need to add previews yourself.

##### Single Folder View

Another new feature is what we call Single Folder View. This allows you to see the contents of a single inventory folder in its own window.

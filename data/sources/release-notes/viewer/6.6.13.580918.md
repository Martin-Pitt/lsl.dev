### Maintenance Transparent Translation

Our translation settings have been given an upgrade with Microsoft Azure and DeepL Translators making their debut appearance as they rise from the ashes of Bing Translate. (R.I.P Bing Translate. You will be somewhat missed.) Translation settings can be accessed via Preferences -> Chat -> Translation. Please visit the following links for information on how to set up these new translation services:

- Azure: [https://learn.microsoft.com/en-us/azure/cognitive-services/translator/create-translator-resource](https://learn.microsoft.com/en-us/azure/cognitive-services/translator/create-translator-resource)
- DeepL: [https://www.deepl.com/pro-api?cta=header-pro-api/](https://www.deepl.com/pro-api?cta=header-pro-api/)

We like to be transparent with our users so we had some fixes made regarding transparency:

- The ‘Highlight Transparent’ function (accessed via Advanced->Highlighting and Visibility), decided to make its highlighting textures opaque without our permission. The textures have now been restored back to what we all had known and loved.
- Transparent objects were continuing to hide when turning on highlights in the Beacons floater. This is no longer the case so playing ‘transparent-object hide and seek’ will now be much easier.

Please see below for more fixes added to this release.

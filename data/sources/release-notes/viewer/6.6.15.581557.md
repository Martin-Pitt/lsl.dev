# Release Notes

### Maintenance Visible Versatility

Which key have you selected to move forward? With this release we are introducing a requested feature for displaying user-customized keybindings in chat. Using “secondlife:///app/keybinding/push_forward” for example, will provide you with whatever crazy controls you may have chosen for moving forward. This will make it easier to provide key binding instructions to end users for those intricately designed vehicles, HUDs or anything you’ve created from your wildest dreams! Syntax for this feature can be found here: [https://wiki.secondlife.com/wiki/Viewer_URI_Name_Space](https://wiki.secondlife.com/wiki/Viewer_URI_Name_Space)

A nightmare fuel bug that previously occurred which caused an avatars eyes not to render in the Shape floater has been un-nightmare fueled.

This release also comes with some more crash fixes and everything else that’s listed below.

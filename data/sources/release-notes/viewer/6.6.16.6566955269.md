# Release Notes

### GitHub Actions

Welcome to Second Life Viewers built with GitHub Actions. This update should have no changes to existing features and functionality in world, except…

A major version update to CEF (Chromium Embedded Framework) which includes several performance updates and security fixes.
And build numbers will never look the same again, now with more digits!

#### Known Issues

An unintended side effect of viewers built with GHA was the forced obsolescence of Windows 7 compatibility. While we have not supported Windows 7 officially for many years, Second Life would still run on Windows 7 prior to this release.

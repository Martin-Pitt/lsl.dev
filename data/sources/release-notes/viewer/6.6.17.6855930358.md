# Release Notes

### Maintenance Yeet Dan’s Bugs

Context menus in the Outfit floater have been given a revamp in this release and users will be able to preview their breathtaking outfit photos when hovering their cursor down the My Outfits tab.

Residents that have been pulling their hair out every time the navigation bar suggests a hair store’s old location can now leave their hair unpulled as there is now an option to remove locations from history. This can be performed via the context menu located in the Places floaters Visited tab.

BONUS: Minor bug fixes! See below for more info.

# Release Notes

### Maintenance Quality Contributions

This viewer includes a nice collection of fixes contributed by RyeMutt (Sovereign Engineer).

We also added some nice new features and resolved issues some users were having.

#### New Features!

- A brand new beautiful Debug Settings UI
- Removing the buttons to add to outfit directly from a delivery box to stop avatars from “accidentally” ending up half naked.
- A new button to the Avatar floater to Add and Remove attachments as fast as you can say “I wish there was a button for this”
- Search fields now turn yellow in case you forgot you left some text there.

#### Issues resolved:

- You couldn’t see rainbows without Shadows enabled? Not anymore! Rainbows for all!
- An issue causing your rez day to appear one day early has been resolved. Everyone will now know the correct day to celebrate your SL birthday!
- Sometimes accidentally teleporting when clicking too fast? No more unnecessary double clicks when closing floaters.
- See below for more

Some users kept crashing the viewer so we made some more improvements to stop you from doing this.

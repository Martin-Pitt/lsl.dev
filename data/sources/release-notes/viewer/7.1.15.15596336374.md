# Release Notes

# 2025.04.01 Avatar Welcome Pack

The community has shown such great interest in the Avatar Welcome Pack we thought it was time to replace the contents of the Avatar Chooser with all the new outfits.

For the fans of Greg out there don’t worry, you may still find all the old avatars in the Library!

From now on a fresh install of Second Life will automatically present the new Avatar Welcome Pack to select from, while existing residents will not. For those interested in trying these on all it will take is opening the menu Avatar > Avatar Welcome Pack.

We hope you enjoy these new Avatars and want to thank all the creators that took part in helping make this happen!

# Release Notes

### Maintenance B: Bellusaurus

The name Bellusaurus means “beautiful lizard” which is an acclamation to this herbivores graceful form. It is believed that this small dinosaur was quite social and lived in herds during the Middle Jurassic period.

This beautifully named release brings many small beautiful updates including the renaming of a certain imposter setting in Advanced Graphics Preferences. The setting “Max # of non-imposters” will henceforth be known as “Maximum number of animated avatars” and will also be located on the basic Graphics Preferences tab in Preferences.

Additionally, some other small fixes have been added to this release which are listed below.

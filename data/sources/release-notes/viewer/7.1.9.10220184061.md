# Release Notes

### Atlasaurus

This release marks the beginning of a new alphabet of releases which will be themed after Dinosaurs!

Starting with the almighty Atlasaurus (not to be confused with the almighty [A](https://wiki.secondlife.com/wiki/File:Atlasaurus.webp)tlas Linden). This titan herbivore is predicted to be 20m long and weighing 15 tons. It was discovered in the Atlas Mountains of Morocco where the titan Atlasaurus was said to hold up the heavens.

This Atlasaurus release brings the following almighty features:

- Options to help with taking multiple objects so you can choose whether to take them all into your inventory as one or separately as individual objects.
- Stop rendering those other avatars with the Avatar Display setting now found in Preferences>Graphics which allows prioritization of rendering your friends. (For those recording a video or taking a photo, a “Render Only Friends” setting is temporarily located at Develop->Avatar->Character Tests->Render Only Friends.)

- Too bright? Control the amount of lights rendered with the new Max. Nearby Lights slider found in Advanced Graphics Settings.
- Better MOAP URL handling has also been implemented here in order for users to not only be able to CTRL+C or Cmd+C copy but also to see decoded URL payloads for easy inspection.
- Preview what your GLTF models may look like in Second Life! While editing a prim, check out the preview setting via Develop->GLTF->Open. Please note that this feature is still in the early stages of development and that GLTF models will only appear locally.

WebRTC Voice has also been merged into this release. Please see our blog post for more details: [https://community.secondlife.com/blogs/entry/15626-coming-to-an-agni-region-near-you-an-update-on-changes-to-voice/](https://community.secondlife.com/blogs/entry/15626-coming-to-an-agni-region-near-you-an-update-on-changes-to-voice/)

Plus many bugs have been squashed!

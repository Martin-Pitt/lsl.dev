# Sidebar

The sidebar is configured in `astro.config.mjs` (`sidebar:`) and rendered by our override of
Starlight's `Sidebar` in `src/components/starlight/Sidebar.astro` and `SidebarSublist.astro`
(a copy of Starlight 0.42's `SidebarSublist` with the changes below). When you upgrade Starlight,
diff its `components/SidebarSublist.astro` against ours.

## Group styles

- **Top-level groups** (Fundamentals, Reference, Features, Guides, Recipes) keep Starlight's large, bold heading style,
  including when they are split groups (below).
- **Nested groups** (any group inside another group) look like ordinary links in the list: same size
  and weight, plus a chevron.

## Split groups

A group, top-level or nested, whose children include a link with the `data-sidebar-group-link`
attribute is a split group. That link is removed from the children; its `href` becomes the group's label link, and a separate
chevron button beside it expands and collapses the group. The group's own `label` is shown, not the
link's label.

```js
{
	label: 'Combat',
	collapsed: true,
	items: [
		{ label: 'Overview', link: '/features/combat/', attrs: { 'data-sidebar-group-link': '' } },
		{ label: 'Combat Log', link: '/features/combat/combat-log/' },
	],
}
```

For autogenerated groups, set the attribute in the overview page's frontmatter (see
`src/content/docs/fundamentals/types/index.mdx`, which also sets a label as described below):

```yaml
sidebar:
  order: -1
  attrs:
    data-sidebar-group-link: ''
```

An autogenerated directory group is labelled with the directory name. To give it a proper label,
set the attribute's value to the label in the frontmatter of the directory's `index.mdx`; a
non-empty value replaces the group's label (an empty value keeps it). This is how a guide gets
sub-pages: `guides/constraining-rotations/index.mdx` is the guide (URL unchanged) and the split
label, and `guides/constraining-rotations/turret.mdx` is listed under its chevron. The directory
sorts by the lowest `order` among its pages, so give `index.mdx` the guide's place in the list and
the sub-pages higher numbers.

```yaml
sidebar:
  order: 4
  attrs:
    data-sidebar-group-link: 'Constraining rotations'
```

Groups take the attribute on a child link because Starlight's schema does not allow `attrs` on groups.
Keeping the link in the data also means Starlight, and `src/routeData.ts`, can still mark it current:
on the overview page (or a deep page whose closest entry is the overview), the label is highlighted
and the group opens.

Notes:

- At the top level, the split label keeps the large heading style (`li.split-group.top-split`), so
  the sections still read as headings. Fundamentals, Guides and Recipes (autogenerated; set by the
  frontmatter of their `index.mdx`), Reference and Features are top-level split groups; their overview is no longer listed as a child.
  Top-level entries without an overview page (Wiki archive, About) stay plain links.
- Any `class` on the lifted link (such as `is-priority`) is dropped. Put `is-priority` on the next child
  if it should stand apart from the rest.
- Groups without such a link stay single toggles (the whole row is the `<summary>`).
- The current split groups are the top-level Fundamentals, Reference, Features, Guides and Recipes; each feature with
  sub-pages (Combat, ...); each guide with sub-pages (Constraining rotations); and Reference's
  Categories, Constants, Types and Flow control.

## Behaviour and accessibility

- The label is a plain link and needs no JavaScript.
- The toggle is a `<button>` with `aria-expanded`, `aria-controls` (the group's `<details>`) and the
  name "Expand X" or "Collapse X". It clicks the group's hidden `<summary>`, so the native `<details>`
  state and Starlight's sessionStorage persistence work as for other groups.
- The toggle is at least 44px wide in the mobile menu and on coarse pointers.
- Without scripting (`@media (scripting: none)`) the button is hidden and the `<summary>` chevron is
  shown in its place.

`bun run test:sidebar` checks the built HTML (run `bun run build` first).

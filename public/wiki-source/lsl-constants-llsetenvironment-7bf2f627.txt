|-
|SKY_CLOUDS
| 2
| vector color, float coverage, float scale, float variance, vector scroll, vector density, vector detail
| Environmental cloud information:
* color: The color used for the clouds. <br/>range = [<0,0,0>, <1,1,1>]
* coverage: The coverage percentage. <br/>range = [0, 1]
* scale: The scaling applied to the cloud textures. <br/>range = (0 - 3]
* variance: A randomizing factor applied to the main cloud layer. <br/>range = [0, 1]
* scroll: The scroll speed of the clouds. X is east/west, Y is north/south, and Z is unused. <br/>range = [<-50,-50>, <50,50>]
* density: The X/Y and D parameter used to generate cloud density. <br/>range = [<0,0,0>, <1,1,3>]
* detail: The X/Y and D parameter used to generate cloud details. <br/>range = [<0,0,0>, <1,1,1>]

* max_altitude: altitude of the sky dome.<br/>range = [0,10000]

====Extended Errors====
When the [[HTTP_EXTENDED_ERROR]] parameter is [[TRUE]], [[llHTTPRequest]] will return extended error information to the script through the [[http_response]] event. A detailed error explanation is returned as a [[Json usage in LSL|JSON blob]] blob in the body of the event and an error code is provided through the HTTP status. The format of the [[Json usage in LSL|JSON blob]] is described in detail in [https://tools.ietf.org/html/rfc7807 RFC&nbsp;7807].

<syntaxhighlight lang="JavaScript">
{
    "type":   "http://wiki.secondlife.com/wiki/llHTTPRequest", // reference to the documentation for llHTTPRequest.
    "title":  "Error Title", // A human readable title for the error.
    "detail": "Description of error condition.", // A human readable description of the error condition.
    "status": 400 // The HTTP Status for the call.
}
</syntaxhighlight>

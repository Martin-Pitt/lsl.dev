## API hover cards

<div id="showcase-hovercards" data-showcase="hovercards">

Hover or Tab to any API link for its card; click or tap still navigates. A typical script calls
[llRequestPermissions](/functions/llRequestPermissions/) and waits for
[run_time_permissions](/events/run_time_permissions/) before it touches
[PERMISSION_DEBIT](/constants/PERMISSION_DEBIT/) and pays out with
[llGiveMoney](/functions/llGiveMoney/). Rezzing with [llRezObject](/functions/llRezObject/)
sleeps and costs energy, [llAgentInExperience](/functions/llAgentInExperience/) needs an
experience, and [llSetTimerEvent](/functions/llSetTimerEvent/) is not in SLua. Links inside
inline code get cards too: `llSetLinkPrimitiveParamsFast(LINK_THIS, [PRIM_COLOR, ALL_SIDES, <1, 0, 0>, 1.0])`.

- In a list: [llListen](/functions/llListen/) pairs with [listen](/events/listen/).
- Deprecated in SLua: [llAbs](/functions/llAbs/).

| Call | Notes |
|---|---|
| [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/) | No sleep, unlike [llSetPos](/functions/llSetPos/). |
| [llTeleportAgentHome](/functions/llTeleportAgentHome/) | Card near the table edge, never clipped. |

Opted out: <NoCard>[llSay](/functions/llSay/)</NoCard> has no card.

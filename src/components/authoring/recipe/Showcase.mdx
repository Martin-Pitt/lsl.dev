<Steps>
<BuildStep title="Rez and link the prims">
Rez a box for the frame, a flat box for the panel and a small cylinder for the handle.
Select the frame **last** before you link, so it becomes the root.
</BuildStep>
<BuildStep title="Name the panel">
Name the panel prim `Door panel`. The script finds it by name, so link order doesn't matter.
</BuildStep>
<BuildStep title="Add the script">
Drop this script into the frame.

<ScriptFile name="door.lsl" in="Door frame (root)">
```lsl title="door.lsl"
integer panel;
integer open;

default
{
    state_entry()
    {
        integer i = llGetNumberOfPrims();
        for (; i > 1; --i)
            if (llGetLinkName(i) == "Door panel") panel = i;
    }

    touch_start(integer n)
    {
        if (llDetectedKey(0) != llGetOwner()) return;
        open = !open;
        rotation r = llEuler2Rot(<0, 0, open * PI_BY_TWO>);
        llSetLinkPrimitiveParamsFast(panel, [PRIM_ROT_LOCAL, r]);
    }
}
```
</ScriptFile>
</BuildStep>
</Steps>

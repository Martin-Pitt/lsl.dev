<LSLConstant name="ACTIVE" />

If it is contained in the result of [llDetectedType](/functions/llDetectedType/)(), it means it is physical tasks. (Physical objects & agents)

If it is used as an filter of [llSensor](/functions/llSensor/)() or [llSensorRepeat](/functions/llSensorRepeat/)(), it will search for physical objects that are moving or objects containing an active script. Thus, it is using SL server resources now.

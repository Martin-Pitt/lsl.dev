<LSLConstant name="AGENT_ALWAYS_RUN" description />

Used with [llGetAgentInfo](/functions/llGetAgentInfo/) to determine if the queried avatar has 'always running' set.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
    // This is a code fragment only
    if (llGetAgentInfo( llGetOwner() ) & AGENT_ALWAYS_RUN)
        llSay(0, "Give me a rest!");
```

</details>

<LSLConstant name="AGENT_AUTOPILOT" />

This value is set when the user selects "Go Here" on the ground, or uses the optional Double-Click Auto-Pilot feature.

Under Viewer 2.0 and later, it is also set when:

- the user selects "Sit Here" on the ground.
- an object is selected or edited, *and* that selection can trigger a [control](/events/control/) ([CONTROL_ROT_RIGHT](/constants/CONTROL_ROT_RIGHT/) and [CONTROL_ROT_LEFT](/constants/CONTROL_ROT_LEFT/) can be activated when selecting an object near the far right or left edge of the screen).

## Examples

<details open>
<summary>Example 1</summary>

```lsl
    if (llGetAgentInfo( llGetOwner() ) & AGENT_AUTOPILOT)
        llSay(0, "Oops, sorry, don't blame me, it was my auto-pilot!");
```

</details>

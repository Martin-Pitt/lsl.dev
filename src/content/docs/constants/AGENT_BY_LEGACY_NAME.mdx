<LSLConstant name="AGENT_BY_LEGACY_NAME" />

If it is contained in the result of [llDetectedType](/functions/llDetectedType/), it means it is avatar.

If it is used as an filter of [llSensor](/functions/llSensor/) or [llSensorRepeat](/functions/llSensorRepeat/), it will search for avatars by [legacy name](https://wiki.secondlife.com/wiki/Category:LSL_Avatar/Name).

## Caveats

There is no avatar whose [llDetectedType](/functions/llDetectedType/) is *equal to* 1`({{#var:AGENT_BY_LEGACY_NAME}})` since there is no avatar who doesn't require the physical calculation, even if they are just standing. Standing agent's type will be equal to 3`({{#var:AGENT_BY_LEGACY_NAME}}|{{#var:ACTIVE}})`. Sitting agent's type will be equal to 5`({{#var:AGENT_BY_LEGACY_NAME}}|{{#var:PASSIVE}})`.

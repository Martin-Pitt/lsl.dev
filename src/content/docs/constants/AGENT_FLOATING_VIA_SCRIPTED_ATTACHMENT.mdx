<LSLConstant name="AGENT_FLOATING_VIA_SCRIPTED_ATTACHMENT" description />

Indicates that the agent is floating because of a scripted attachment using either [llSetHoverHeight](/functions/llSetHoverHeight/) or [llGroundRepel](/functions/llGroundRepel/).

## Caveats

Not available until server v2024.11-Apple_Cobbler

## Examples

<details open>
<summary>Example 1</summary>

```lsl
    // This is a code fragment only
    if (llGetAgentInfo( llGetOwner() ) & AGENT_FLOATING_VIA_SCRIPTED_ATTACHMENT)
        llSay(0, "You're walking on air!");
```

</details>

<LSLConstant name="ALL_SIDES" />

Selects all sides of an object in an applicable function.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        string texture = llGetInventoryName(INVENTORY_TEXTURE, 0);
        llSetTexture(texture, ALL_SIDES);
    }
}
```

</details>

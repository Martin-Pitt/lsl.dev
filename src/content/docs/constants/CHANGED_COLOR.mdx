<LSLConstant name="CHANGED_COLOR" description />

Prim [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) color or alpha parameters have changed

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    changed(integer change)
    {

        if (change & CHANGED_COLOR) //note that it's & and not &&... it's bitwise!
        {
            llOwnerSay("The color or alpha changed.");
        }
    }
}
```

</details>

<LSLConstant name="CHANGED_REGION_START" />

The region containing the object has just come online.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    changed(integer change)
    {
    //  note that it's & and not &&... it's bitwise!
        if (change & CHANGED_REGION_START)
        {
            key owner = llGetOwner();
            string region = llGetRegionName();
            llInstantMessage(owner, "Region '" + region + "' has restarted.");
        }
    }
}
```

</details>

## Notes

When a region is (re)started all [HTTP server](/events/http_request/) URLs are automatically released and invalidated.

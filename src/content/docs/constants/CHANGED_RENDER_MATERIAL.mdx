<LSLConstant name="CHANGED_RENDER_MATERIAL" description />

Prim [material ID](/constants/PRIM_RENDER_MATERIAL/) or [material overrides](https://wiki.secondlife.com/wiki/GLTF_Overrides) have changed on one or more faces.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    changed(integer change)
    {
        if (change & CHANGED_RENDER_MATERIAL) //note that it's & and not &&... it's bitwise!
        {
            llOwnerSay("The prim's material ID and/or overrides have changed on one or more faces.");
        }
    }
}
```

</details>

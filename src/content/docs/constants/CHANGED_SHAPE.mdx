<LSLConstant name="CHANGED_SHAPE" description />

[PRIM_TYPE](/constants/PRIM_TYPE/) (box, prism, torus, taper, twist, cut …) has changed.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    changed(integer change)
    {
        if (change & CHANGED_SHAPE) //note that it's & and not &&... it's bitwise!
        {
            llOwnerSay("The prim's shape has changed.");
        }
    }
}
```

</details>

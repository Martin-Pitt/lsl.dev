<LSLConstant name="CHARACTER_ORIENTATION" />

Constant used to indicate that the following argument is the orientation of the capsule for a [Pathfinding](https://wiki.secondlife.com/wiki/Pathfinding) character. This is used to help denote how to interpret the size of a character.

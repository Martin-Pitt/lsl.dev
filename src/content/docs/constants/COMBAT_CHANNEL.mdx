<LSLConstant name="COMBAT_CHANNEL" />

A channel reserved for [combat related log events](https://wiki.secondlife.com/wiki/Combat_Log) broadcast to the entire region.

System generated messages to this channel will be from [COMBAT_LOG_ID](/constants/COMBAT_LOG_ID/).

If the region settings allow for it (see ["restrict_combat_log"](/functions/llGetEnv/)), then scripts may write into this channel as well.

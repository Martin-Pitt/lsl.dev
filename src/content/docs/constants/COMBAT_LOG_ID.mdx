<LSLConstant name="COMBAT_LOG_ID" description />

Messages from the region to the [combat log](https://wiki.secondlife.com/wiki/Combat_Log) will all be from this ID.

Scripts may filter [llListen](/functions/llListen/) calls on this ID to receive only system generated combat log messages.

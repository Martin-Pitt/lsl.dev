<LSLConstant name="CONTENT_TYPE_FORM" />

Sets the [Internet media type](https://en.wikipedia.org/wiki/Internet_media_type) `String: {{String|Content-Type}}` header of any subsequent [LSL HTTP server](https://wiki.secondlife.com/wiki/LSL_HTTP_server) response via [llHTTPResponse](/functions/llHTTPResponse/) to `String: {{String|application/x-www-form-urlencoded}}`.

<LSLConstant name="CONTENT_TYPE_HTML" description />

Sets the [Internet media type](https://en.wikipedia.org/wiki/Internet_media_type) `String: {{String|Content-Type}}` header of any subsequent [LSL HTTP server](https://wiki.secondlife.com/wiki/LSL_HTTP_server) response via [llHTTPResponse](/functions/llHTTPResponse/) to `String: {{String|text/html}}`.

## Caveats

- When using [CONTENT_TYPE_HTML](/constants/CONTENT_TYPE_HTML/), this setting will be ignored unless all of these conditions are met:
- the web browser is the Second Life client
- the user (logged into the SL client viewing the page) is the owner of the object.
- the user (logged into the SL client viewing the page) is connected to the region the object is located in
- : Obviously this is not compatible with group owned objects. One way around this limitation would be to [temporarily attach](/functions/llAttachToAvatarTemp/) a repeated.

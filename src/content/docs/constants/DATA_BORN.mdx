<LSLConstant name="DATA_BORN" />

Used with [llRequestAgentData](/functions/llRequestAgentData/) to return a string that contains the date the user joined SL, it is the [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format of "`YYYY`-`MM`-`DD`". It is based on Pacific Time, not UTC.

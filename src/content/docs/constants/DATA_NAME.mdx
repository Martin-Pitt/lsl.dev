<LSLConstant name="DATA_NAME" />

Used with [llRequestAgentData](/functions/llRequestAgentData/) to return a string containing the avatars [legacy name](https://wiki.secondlife.com/wiki/Category:LSL_Avatar/Name).

- For legacy accounts (those with a first and last name). The format is "FirstName LastName".
- For modern accounts (those with only a first name). The format is "FirstName Resident".

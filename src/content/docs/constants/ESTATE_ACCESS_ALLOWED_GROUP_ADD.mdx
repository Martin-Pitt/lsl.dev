<LSLConstant name="ESTATE_ACCESS_ALLOWED_GROUP_ADD" />

Used in input parameters of [llManageEstateAccess](/functions/llManageEstateAccess/) .Add a group to this estate's Allowed groups list.

| **`action`** flag | V | Description |
| --- | --- | --- |
| [ESTATE_ACCESS_ALLOWED_AGENT_ADD](/constants/ESTATE_ACCESS_ALLOWED_AGENT_ADD/) | 0x4 | Add the agent to this estate's Allowed Residents list. |
| [ESTATE_ACCESS_ALLOWED_AGENT_REMOVE](/constants/ESTATE_ACCESS_ALLOWED_AGENT_REMOVE/) | 0x8 | Remove the agent from this estate's Allowed Residents list. |
| [ESTATE_ACCESS_ALLOWED_GROUP_ADD](/constants/ESTATE_ACCESS_ALLOWED_GROUP_ADD/) | 0x10 | Add the group to this estate's Allowed groups list. |
| [ESTATE_ACCESS_ALLOWED_GROUP_REMOVE](/constants/ESTATE_ACCESS_ALLOWED_GROUP_REMOVE/) | 0x20 | Remove the group from this estate's Allowed groups list. |
| [ESTATE_ACCESS_BANNED_AGENT_ADD](/constants/ESTATE_ACCESS_BANNED_AGENT_ADD/) | 0x40 | Add the agent to this estate's Banned residents list. |
| [ESTATE_ACCESS_BANNED_AGENT_REMOVE](/constants/ESTATE_ACCESS_BANNED_AGENT_REMOVE/) | 0x80 | Remove the agent from this estate's Banned residents list. |

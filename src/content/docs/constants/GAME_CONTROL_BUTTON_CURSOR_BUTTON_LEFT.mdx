<LSLConstant name="GAME_CONTROL_BUTTON_CURSOR_BUTTON_LEFT" description />

Set by a controller button bound to "Mouse click left". In [`GAME_CONTROL_MODE_CURSOR`](/constants/GAME_CONTROL_MODE_CURSOR/) the viewer also sets it while the real left mouse button is held, so a hardware click looks the same to the script as a controller one. In other modes a mouse click sets no game control button; see [Game control](/features/input/game-control/).

<LSLConstant name="HTTP_BODY_MAXLENGTH" />

Used with [llHTTPRequest](/functions/llHTTPRequest/) to set the maximum size the script will accept**\*** for an HTTP body. The largest value this can be set to depends upon the VM that is being used.

`{{KBtip|When you only need to request a small amount of data from a remote source, consider using the [https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Range Content-Range header] instead.}}`

**\* See caveats**

### [Lua/LSL on Lua](https://wiki.secondlife.com/wiki/SLua_Alpha)

- Maximum: 32KiB (32768)

### [LSL on Mono](https://wiki.secondlife.com/wiki/Mono)

- Maximum: 16KiB (16384)

### [LSO/LSL Legacy](https://wiki.secondlife.com/wiki/LSO)

- Maximum: 4KiB (4096) Sets the maximum (UTF-8 encoded) byte length of the HTTP response body.

## Caveats

- **\*** Only applies to the [Outgoing](https://wiki.secondlife.com/wiki/Category:LSL_HTTP) HTTP pipeline (HTTP calls invoked by [llHTTPRequest](/functions/llHTTPRequest/),and responses from [http_response](/events/http_response/)).

<LSLConstant name="INVENTORY_SCRIPT" />

Used with [Inventory](https://wiki.secondlife.com/wiki/Category:LSL_Inventory) functions and specifies inventory items of SCRIPT type will be retrieved by the function.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Gives THIS script to anyone touching this object
default
{
    touch_start(integer total_number)
    {
        // get the UUID of the person touching this object
        key user = llDetectedKey(0);
        // Give them this script
        llGiveInventory(user, llGetScriptName() );
    }
}
```

</details>

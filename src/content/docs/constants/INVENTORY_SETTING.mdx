<LSLConstant name="INVENTORY_SETTING" />

Used with [Inventory](https://wiki.secondlife.com/wiki/Category:LSL_Inventory) functions and specifies inventory items of SETTING type will be retrieved by the function.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Give all setting items from prim's contents to anyone touching this object
default
{
    touch_start(integer total_number)
    {
        // get the UUID of the person touching this object
        key user = llDetectedKey(0);
        integer count = llGetInventoryNumber(INVENTORY_SETTING);
        while (count--)
        // Give them each setting object found in the object's contents
            llGiveInventory(user, llGetInventoryName(INVENTORY_SETTING, count) );
    }
}
```

</details>

<LSLConstant name="INVENTORY_TEXTURE" />

Used with [Inventory](https://wiki.secondlife.com/wiki/Category:LSL_Inventory) functions and specifies inventory items of TEXTURE type will be retrieved by the function.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Give a texture to anyone touching this object
default
{
    touch_start(integer total_number)
    {
        // get the UUID of the person touching this object
        key user = llDetectedKey(0);
        // Give them the first texture found in the object's contents
        llGiveInventory(user, llGetInventoryName(INVENTORY_TEXTURE, 0) );
    }
}
```

</details>

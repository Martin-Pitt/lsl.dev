<LSLConstant name="JSON_APPEND" />

A special specifier for [llJsonSetValue](/functions/llJsonSetValue/) which indicates the given value should be appended to the array at the specified level.

Care should be taken, as if the value at that level is not an array, the existing data will be overwritten and replaced with the array meant for appending.

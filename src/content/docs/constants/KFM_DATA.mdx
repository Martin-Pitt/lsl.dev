<LSLConstant name="KFM_DATA" />

Flag used in the options parameter [llSetKeyframedMotion](/functions/llSetKeyframedMotion/) : is a flag followed by a bitwise combination of: [KFM_TRANSLATION](/constants/KFM_TRANSLATION/) and [KFM_ROTATION](/constants/KFM_ROTATION/). If absent, both rotations and translations must be provided in the first parameter of [llSetKeyframedMotion](/functions/llSetKeyframedMotion/) .

<LSLConstant name="NAK" />

NAK is a value returned by the [llGetNotecardLineSync](/functions/llGetNotecardLineSync/) function when the requested notecard data is not available due to the notecard not being in the region notecard cache. The value returned equals the characters with codes "10, 21, 10", which is to say the ASCII "NAK" character surrounded by two newline characters.

If the NAK response is encountered, the card can be fetched into the region notecard cache by using the [llGetNotecardLine](/functions/llGetNotecardLine/) or [llGetNumberOfNotecardLines](/functions/llGetNumberOfNotecardLines/) functions. If the notecard doesn't exist at all, further [llGetNotecardLineSync](/functions/llGetNotecardLineSync/) calls will continue returning NAK.

## Notes

NAK is an acronym that stands for "Negative AcKnownledgement".

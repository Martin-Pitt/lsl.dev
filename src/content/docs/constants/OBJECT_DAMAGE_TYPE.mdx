<LSLConstant name="OBJECT_DAMAGE_TYPE" description />

Gets the damage type that is applied when this prim collides with another object. Can match one of the [DAMAGE_TYPE\_\*](https://wiki.secondlife.com/wiki/Category:LSL_Combat2) constants, be a custom damage type or be a repurposed damage field.

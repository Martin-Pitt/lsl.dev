<LSLConstant name="OBJECT_OMEGA" description />

Used with [llGetObjectDetails](/functions/llGetObjectDetails/) to get the objects rotational velocity.

## Usage

### \[ [OBJECT_OMEGA](/constants/OBJECT_OMEGA/) \]

- [vector](https://wiki.secondlife.com/wiki/vector) **omega** — velocity of the object in radians per second.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        llTargetOmega(<0,0,0.5>, 1, 1);
    }

    touch_start(integer total_number)
    {
        llSay(0, (string)llGetObjectDetails(llGetKey(), [OBJECT_OMEGA]));
    }
}
```

</details>

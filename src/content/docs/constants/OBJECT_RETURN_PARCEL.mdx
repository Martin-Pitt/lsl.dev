<LSLConstant name="OBJECT_RETURN_PARCEL" />

For [llReturnObjectsByOwner](/functions/llReturnObjectsByOwner/), sets the scope to return all objects on the same parcel as the script which are owned by 'owner'. The script must be owned by an estate manager or over a parcel owned by the owner of the script.

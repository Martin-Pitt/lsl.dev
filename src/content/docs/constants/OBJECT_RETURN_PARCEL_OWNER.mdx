<LSLConstant name="OBJECT_RETURN_PARCEL_OWNER" description />

For [llReturnObjectsByOwner](/functions/llReturnObjectsByOwner/), sets the scope to return all objects owned by 'owner' which are over parcels owned by the owner of the script.

<LSLConstant name="OBJECT_RETURN_REGION" description />

For [llReturnObjectsByOwner](/functions/llReturnObjectsByOwner/), sets the scope to return all objects in the region owned by 'owner' - only works when the script is owned by the estate owner or an estate manager.

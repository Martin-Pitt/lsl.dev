<LSLConstant name="OBJECT_SELECT_COUNT" description />

This is a flag used with [llGetObjectDetails](/functions/llGetObjectDetails/) to get the total number of agents selecting any links in the object.

If **id** is an avatar, 0 is returned.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-8, 14-22}
//If someone selects the object it will glow
default
{
    state_entry()
    {
        llSetTimerEvent(0.01);
    }

    timer()
    {
        list details = llGetObjectDetails(llGetKey(), [OBJECT_SELECT_COUNT]);
        integer objectSelectCount = llList2Integer(details, 0);
        if(objectSelectCount > 0)
        {
            llSetLinkPrimitiveParamsFast(LINK_SET,  [ PRIM_GLOW, ALL_SIDES, 0.1] );
        }else
        {

            llSetLinkPrimitiveParamsFast(LINK_SET,  [ PRIM_GLOW, ALL_SIDES, 0.0] );
        }
    }
}
```

</details>

<LSLConstant name="PARCEL_COUNT_GROUP" description />

Used with [llGetParcelPrimCount](/functions/llGetParcelPrimCount/) to get the total land impact of objects shared with or owned by the parcel group.

## Caveats

- Does not count prims owned by the parcel owner that are also shared with the group.

## See also

### Constants

| Category |  | Description |
| --- | --- | --- |
| [PARCEL_COUNT_TOTAL](/constants/PARCEL_COUNT_TOTAL/) | 0 | All objects on the parcel(s). Does not include temp on rez objects. |
| [PARCEL_COUNT_OWNER](/constants/PARCEL_COUNT_OWNER/) | 1 | Objects owned by the parcel owner. |
| [PARCEL_COUNT_GROUP](/constants/PARCEL_COUNT_GROUP/) | 2 | Objects not owned by the owner, but set to or owned by the group of the parcel. |
| [PARCEL_COUNT_OTHER](/constants/PARCEL_COUNT_OTHER/) | 3 | Objects not set to group or owned by the owner. |
| [PARCEL_COUNT_SELECTED](/constants/PARCEL_COUNT_SELECTED/) | 4 | All objects selected or sat on. |
| [PARCEL_COUNT_TEMP](/constants/PARCEL_COUNT_TEMP/) | 5 | All temp on rez objects. |

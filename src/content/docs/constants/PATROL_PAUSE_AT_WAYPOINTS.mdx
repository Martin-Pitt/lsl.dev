<LSLConstant name="PATROL_PAUSE_AT_WAYPOINTS" />

Option parameter for [llPatrolPoints](/functions/llPatrolPoints/) function. Can be set [TRUE](/constants/TRUE/) or [FALSE](/constants/FALSE/) (the default).

When set [TRUE](/constants/TRUE/), characters will slow down and momentarily pause at each waypoint.

When set [FALSE](/constants/FALSE/), characters will continue to move to the next waypoint at full speed, with no pause.

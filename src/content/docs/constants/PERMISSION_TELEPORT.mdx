<LSLConstant name="PERMISSION_TELEPORT" description />

Permission required to use [llTeleportAgent](/functions/llTeleportAgent/).

## Caveats

- Cannot be granted by [temporary attachments](/functions/llAttachToAvatarTemp/). If attempted, the following error will be returned: *"Temporary attachments cannot request runtime permissions to teleport"*

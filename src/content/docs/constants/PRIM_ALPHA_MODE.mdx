<LSLConstant name="PRIM_ALPHA_MODE" description />

Used to specify how the alpha channel of the diffuse texture should affect rendering of a prim’s face.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
llSetPrimitiveParams([ PRIM_ALPHA_MODE, ALL_SIDES, PRIM_ALPHA_MODE_NONE, 0 ]);
llSetPrimitiveParams([ PRIM_ALPHA_MODE, ALL_SIDES, PRIM_ALPHA_MODE_MASK, 130 ]);
```

</details>

## Notes

- Note that as with [PRIM_NORMAL](/constants/PRIM_NORMAL/) and [PRIM_SPECULAR](/constants/PRIM_SPECULAR/), setting a custom (i.e. not [PRIM_ALPHA_MODE_BLEND](/constants/PRIM_ALPHA_MODE_BLEND/)) alpha mode on a prim faces causes the linkset to use the [new prim accounting system](http://community.secondlife.com/t5/English-Knowledge-Base/Calculating-land-impact/ta-p/974163).
- `mask_cutoff` is not used or stored unless the mode is set to [PRIM_ALPHA_MODE_MASK](/constants/PRIM_ALPHA_MODE_MASK/).
- To delete the material from `face`, set the `alpha_mode` to [PRIM_ALPHA_MODE_BLEND](/constants/PRIM_ALPHA_MODE_BLEND/), in addition to clearing [PRIM_NORMAL](/constants/PRIM_NORMAL/) and [PRIM_SPECULAR](/constants/PRIM_SPECULAR/)
- If `face` indicates a face that exists but does not contain a material, the [PRIM_ALPHA_MODE](/constants/PRIM_ALPHA_MODE/) return is '\[ [PRIM_ALPHA_MODE_BLEND](/constants/PRIM_ALPHA_MODE_BLEND/), 0 \]'

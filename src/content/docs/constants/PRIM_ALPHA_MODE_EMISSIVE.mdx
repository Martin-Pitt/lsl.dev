<LSLConstant name="PRIM_ALPHA_MODE_EMISSIVE" />

Used with [PRIM_ALPHA_MODE](/constants/PRIM_ALPHA_MODE/). Prims faces set to this type render with an emissivity corresponding to the opacity of each pixel of the diffuse texture. The more opaque a pixel is, the brighter it renders under all lighting conditions. A fully-opaque pixel will effectively render as 'full bright'.

<LSLConstant name="PRIM_ALPHA_MODE_MASK" />

Used with [PRIM_ALPHA_MODE](/constants/PRIM_ALPHA_MODE/). Prims faces set to this type render as either completely opaque or completely transparent on a per-pixel basis. Pixels which are less opaque than the specified `mask_cutoff` are rendered as completely transparent, and the rest are rendered as fully opaque.

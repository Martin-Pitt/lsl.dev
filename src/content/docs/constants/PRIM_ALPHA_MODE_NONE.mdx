<LSLConstant name="PRIM_ALPHA_MODE_NONE" description />

Used with [PRIM_ALPHA_MODE](/constants/PRIM_ALPHA_MODE/). Prims faces set to this type ignore the alpha channel of the diffuse texture, and render as completely opaque.

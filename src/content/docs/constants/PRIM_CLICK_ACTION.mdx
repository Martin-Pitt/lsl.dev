<LSLConstant name="PRIM_CLICK_ACTION" />

Which action will be taken when left-clicking the prim. Followed by one of these flags:

| Flag |  | Description | Cursor |
| --- | --- | --- | --- |
| [CLICK_ACTION_NONE](/constants/CLICK_ACTION_NONE/) | 0 | Performs the default action: when the prim is touched, touch events are triggered |  |
| [CLICK_ACTION_TOUCH](/constants/CLICK_ACTION_TOUCH/) | 0 | When the prim is touched, touch events are triggered |  |
| [CLICK_ACTION_SIT](/constants/CLICK_ACTION_SIT/) | 1 | When the prim is touched, the avatar sits upon it | [File:SitActionCursor.png‎](https://wiki.secondlife.com/wiki/File:SitActionCursor.png%E2%80%8E) |
| [CLICK_ACTION_BUY](/constants/CLICK_ACTION_BUY/) | 2 | When the prim is touched, the buy dialog is opened | [File:SaleOneclickCursor.png](https://wiki.secondlife.com/wiki/File:SaleOneclickCursor.png) |
| [CLICK_ACTION_PAY](/constants/CLICK_ACTION_PAY/) | 3 | When the prim is touched, the pay dialog is opened | [File:SaleOneclickCursor.png](https://wiki.secondlife.com/wiki/File:SaleOneclickCursor.png) |
| [CLICK_ACTION_OPEN](/constants/CLICK_ACTION_OPEN/) | 4 | When the prim is touched, the object inventory dialog is opened | [File:OpenOneclickCursor.png](https://wiki.secondlife.com/wiki/File:OpenOneclickCursor.png) |
| [CLICK_ACTION_PLAY](/constants/CLICK_ACTION_PLAY/) | 5 | Play or pause parcel media on touch | [Image:Toolplay.png](https://wiki.secondlife.com/wiki/Image:Toolplay.png) |
| [CLICK_ACTION_OPEN_MEDIA](/constants/CLICK_ACTION_OPEN_MEDIA/) | 6 | Play parcel media on touch, no pause | [Image:Toolmediaopen.png](https://wiki.secondlife.com/wiki/Image:Toolmediaopen.png) |
| [CLICK_ACTION_ZOOM](/constants/CLICK_ACTION_ZOOM/) | 7 | Zoom the avatar camera on this object ([Viewer 2](https://wiki.secondlife.com/wiki/Viewer_2_Help)) | [Image:Toolzoom.png](https://wiki.secondlife.com/wiki/Image:Toolzoom.png) |
| [CLICK_ACTION_DISABLED](/constants/CLICK_ACTION_DISABLED/) | 8 | No click action. No touches detected or passed. |  |
| [CLICK_ACTION_IGNORE](/constants/CLICK_ACTION_IGNORE/) | 9 | Clicks go through the object to whatever is behind it. No touches detected. |  | Prim parameter followed by a CLICK_ACTION\_\* constant to specify the default action taken when a user clicks or touches the prim.

## Caveats

- The caveats described at [llSetClickAction](/functions/llSetClickAction/#caveats) all apply to `PRIM_CLICK_ACTION`.

## Usage

```lsl
PRIM_COLOR, integer face, vector color, float alpha
```

- [integer](https://wiki.secondlife.com/wiki/integer) **face** — a [face](https://wiki.secondlife.com/wiki/Face) number or [ALL_SIDES](/constants/ALL_SIDES/)
- [vector](https://wiki.secondlife.com/wiki/vector) **color**
- [float](https://wiki.secondlife.com/wiki/float) **alpha** — opacity in the range 0.0 to 1.0

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_COLOR, integer face ]);
```

Returns the same values, in the same order.

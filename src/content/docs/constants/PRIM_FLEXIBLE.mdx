Used to get or set the prim's [flexible](https://wiki.secondlife.com/wiki/flexible) configuration.

## Usage

### \[ [PRIM_FLEXIBLE](/constants/PRIM_FLEXIBLE/), [integer](https://wiki.secondlife.com/wiki/integer) **boolean**, [integer](https://wiki.secondlife.com/wiki/integer) **softness**, [float](https://wiki.secondlife.com/wiki/float) **gravity**, [float](https://wiki.secondlife.com/wiki/float) **friction**, [float](https://wiki.secondlife.com/wiki/float) **wind**, [float](https://wiki.secondlife.com/wiki/float) **tension**, [vector](https://wiki.secondlife.com/wiki/vector) **force** \]

- [integer](https://wiki.secondlife.com/wiki/integer) **boolean**
- [integer](https://wiki.secondlife.com/wiki/integer) **softness** — ranges from 0 to 3
- [float](https://wiki.secondlife.com/wiki/float) **gravity** — ranges from -10.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **friction** — ranges from 0.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **wind** — ranges from 0.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **tension** — ranges from 0.0 to 10.0
- [vector](https://wiki.secondlife.com/wiki/vector) **force**

When used with [llSetPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams) & [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams)

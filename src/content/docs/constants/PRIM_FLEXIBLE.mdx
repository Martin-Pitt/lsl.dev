## Usage

```lsl
PRIM_FLEXIBLE, integer boolean, integer softness, float gravity, float friction, float wind, float tension, vector force
```

- [integer](https://wiki.secondlife.com/wiki/integer) **boolean** — TRUE enables, FALSE disables
- [integer](https://wiki.secondlife.com/wiki/integer) **softness** — ranges from 0 to 3
- [float](https://wiki.secondlife.com/wiki/float) **gravity** — ranges from -10.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **friction** — ranges from 0.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **wind** — ranges from 0.0 to 10.0
- [float](https://wiki.secondlife.com/wiki/float) **tension** — ranges from 0.0 to 10.0
- [vector](https://wiki.secondlife.com/wiki/vector) **force**

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_FLEXIBLE ]);
```

Returns the same values, in the same order.

<LSLConstant name="PRIM_GLTF_ALPHA_MODE_BLEND" description />

Alpha blending rendering mode for [GLTF](https://wiki.secondlife.com/wiki/GLTF_Overrides) materials, used with [PRIM_GLTF_BASE_COLOR](/constants/PRIM_GLTF_BASE_COLOR/). Transparency from the texture is applied and multiplied by the material's opacity multiplier, in linear color space.

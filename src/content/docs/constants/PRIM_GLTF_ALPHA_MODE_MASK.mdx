<LSLConstant name="PRIM_GLTF_ALPHA_MODE_MASK" />

Alpha masked rendering mode for [GLTF](https://wiki.secondlife.com/wiki/GLTF_Overrides) materials, used with [PRIM_GLTF_BASE_COLOR](/constants/PRIM_GLTF_BASE_COLOR/). Transparency from the texture is compared to the material's alpha cutoff, with pixels above the cutoff fully opaque and pixels below it fully transparent.

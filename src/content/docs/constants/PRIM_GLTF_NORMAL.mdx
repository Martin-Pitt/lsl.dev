<LSLConstant name="PRIM_GLTF_NORMAL" description />

Used to get or set the [GLTF](https://wiki.secondlife.com/wiki/GLTF_Overrides) normal map override of an object's `face`.

## Caveats

- **repeats** is not only used to set the number of repeats but the sign of the individual components is also used to set the "Flip" attribute.
- To clear any override parameters, supply an empty string ("") in the parameter slot.
- In the [default](/constants/PRIM_TEXGEN_DEFAULT/) [texture mapping](/constants/PRIM_TEXGEN/) **tg_type** the [texture](/constants/PRIM_GLTF_NORMAL/) **repeats** units are in texture repeats per face. In the [planar](/constants/PRIM_TEXGEN_PLANAR/) texture mapping mode the texture **repeats** units are in texture repeats per half meter. This is in contrast to the in-world editing tool, in which the planar texture scaling units are repeats per meter.

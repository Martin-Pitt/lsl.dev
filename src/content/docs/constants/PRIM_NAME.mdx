<LSLConstant name="PRIM_NAME" description />

Used to get or set the prim's name.

## Usage

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_NAME, string name ]);
```

- [string](https://wiki.secondlife.com/wiki/string) **name** — variable name

The same syntax applies to [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams) and [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/) but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

There is no **llSetLinkName** function, using this flag this way fills that niche.

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_NAME ]);
```

Returns the same values, in the same order.

The same syntax applies to [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/), but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

If [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) refers to an avatar (seated avatars are assigned link numbers), the avatar's [legacy name](https://wiki.secondlife.com/wiki/Category:LSL_Legacy_Name) is returned.

## Examples

<details open>
<summary>These are code fragments only</summary>

```lsl
    string NameOfThisPrim = llList2String( llGetLinkPrimitiveParams(LINK_THIS, [PRIM_NAME] ), 0);
```

</details>

<details>
<summary>In cases like this where a list only contains one entry, we can get away with a shortcut:-</summary>

```lsl
    string NameOfThisPrim = (string) llGetLinkPrimitiveParams(LINK_THIS, [PRIM_NAME] );
```

</details>

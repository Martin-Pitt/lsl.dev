<LSLConstant name="PRIM_NAME" description />

Used to get or set the prim's name.

## Examples

<details open>
<summary>These are code fragments only</summary>

```lsl
    string NameOfThisPrim = llList2String( llGetPrimitiveParams( [PRIM_NAME] ), 0);
```

</details>

<details>
<summary>In cases like this where a list only contains one entry, we can get away with a shortcut:-</summary>

```lsl
    string NameOfThisPrim = (string) llGetPrimitiveParams( [PRIM_NAME] );
```

</details>

<LSLConstant name="PRIM_PHANTOM" description />

Used to get or set the object's [phantom](/constants/STATUS_PHANTOM/) [status](https://wiki.secondlife.com/wiki/Category:LSL_Status).

## Usage

```lsl
PRIM_PHANTOM, integer boolean
```

- [integer](https://wiki.secondlife.com/wiki/integer) **boolean**

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

- NOTE: This sets the entire object (linkset) when used in either function.

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_PHANTOM ]);
```

Returns the same values, in the same order.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={10-19}
default
{
    state_entry()
    {
        llSetPrimitiveParams([PRIM_PHANTOM, TRUE]); // makes the object phantom...

        integer isPhantom = llList2Integer(llGetPrimitiveParams([PRIM_PHANTOM]), 0);

        if( isPhantom == 1 )
        {
            llSetText("Object is Phantom", <1, 1, 1>, 1.0);
        }

        else
        {
            llSetText("Object is Solid", <1, 1, 1>, 1.0);
        }
    }
}
```

</details>

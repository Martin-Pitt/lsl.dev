<LSLConstant name="PRIM_PHYSICS" description />

Used to get or set the object's [physics](/constants/STATUS_PHYSICS/) [status](https://wiki.secondlife.com/wiki/Category:LSL_Status). When enabled the object responds to SL physics.

## Usage

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_PHYSICS, integer boolean ]);
```

- [integer](https://wiki.secondlife.com/wiki/integer) **boolean**

The same syntax applies to [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams) and [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/) but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_PHYSICS ]);
```

Returns the same values, in the same order.

The same syntax applies to [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/), but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

## Caveats

- calls to set `PRIM_PHYSICS` in attachments fail silently

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={10-19}
default
{
    state_entry()
    {
        llSetPrimitiveParams([PRIM_PHYSICS, TRUE]); // makes the object physical...

        integer isPhysical = llList2Integer(llGetPrimitiveParams([PRIM_PHYSICS]), 0);

        if( isPhysical == 1 )
        {
            llSetText("Object is Physical", <1, 1, 1>, 1.0);
        }

        else
        {
            llSetText("Object is non-Physical", <1, 1, 1>, 1.0);
        }
    }
}
```

</details>

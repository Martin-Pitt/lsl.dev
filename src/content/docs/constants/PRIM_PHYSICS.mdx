<LSLConstant name="PRIM_PHYSICS" description />

Used to get or set the object's [physics](/constants/STATUS_PHYSICS/) [status](https://wiki.secondlife.com/wiki/Category:LSL_Status). When enabled the object responds to SL physics.

## Caveats

- calls to set `PRIM_PHYSICS` in attachments fail silently

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={10-19}
default
{
    state_entry()
    {
        llSetPrimitiveParams([PRIM_PHYSICS, TRUE]); // makes the object physical...

        integer isPhysical = llList2Integer(llGetPrimitiveParams([PRIM_PHYSICS]), 0);

        if( isPhysical == 1 )
        {
            llSetText("Object is Physical", <1, 1, 1>, 1.0);
        }

        else
        {
            llSetText("Object is non-Physical", <1, 1, 1>, 1.0);
        }
    }
}
```

</details>

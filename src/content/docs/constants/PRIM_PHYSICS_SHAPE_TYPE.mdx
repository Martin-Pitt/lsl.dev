<LSLConstant name="PRIM_PHYSICS_SHAPE_TYPE" description />

Used to set the type of shape the physics engine should use for the prim. This is primarily used to do [Physics Optimization](https://wiki.secondlife.com/wiki/Physics_Optimization).

## Usage

```lsl
PRIM_PHYSICS_SHAPE_TYPE, integer type
```

- [integer](https://wiki.secondlife.com/wiki/integer) **type** — PRIM_PHYSICS_SHAPE\_\* flag

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_PHYSICS_SHAPE_TYPE ]);
```

Returns the same values, in the same order.

## Notes

Modern physics engines achieve real-time results (as opposed to slower than real-time results) by approximating and simplifying the shapes. This means the shape that client displays on the screen is much more complicated than the shape the physics engine works with (with the exception of basic shapes like cubes or prisms). This flag gives the scripter some control over how the prim is treated by the physics engine.

<LSLConstant name="PRIM_POINT_LIGHT" description />

## Usage

```lsl
PRIM_POINT_LIGHT, integer boolean, vector linear_color, float intensity, float radius, float falloff
```

- [integer](https://wiki.secondlife.com/wiki/integer) **boolean**
- [vector](https://wiki.secondlife.com/wiki/vector) **linear_color**
- [float](https://wiki.secondlife.com/wiki/float) **intensity** — ranges from 0.0 to 1.0
- [float](https://wiki.secondlife.com/wiki/float) **radius** — ranges from 0.1 to 20.0
- [float](https://wiki.secondlife.com/wiki/float) **falloff** — ranges from 0.0 to 2.0[^v1]

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_POINT_LIGHT ]);
```

Returns the same values, in the same order.

## Caveats

- The viewer renders only the nearest local lights, up to its `RenderLocalLightCount` setting (default 256); lights beyond that count, or outside the draw distance, are not rendered[^v2]
- Lights with a high intensity have a wash-out effect when overlapping. Keep this in mind when using multiple lights. ***Never*** create an abundance of lights to get around the per-viewer light limit, as other viewers will be washed out and may suffer from client lag.
- Unlike most color in LSL, which expects a gamma-encoded value (sRGB), this expects a non-gamma-encoded value (linear RGB).[^v3] This means that the value you set as the light color is not the same value you'd pass to make the source (e.g. filament ) glow the same color. You may wish to implement an [sRGB Electro-Optical Transfer Function (EOTF)](/functions/llsRGB2Linear/) to bypass this.
- The `falloff` parameter is a bit of a misnomer. Instead of modifying the characteristics of light decay over distance, it instead acts as a modifier to a light's overall intensity value.

## Examples

<details open>
<summary>Set the prim's color and the color of the light it emits to the same color:-</summary>

```lsl collapse={1-13}
integer switch;

vector gLampCol = <255,190,121>; //Light colour in regular (0-255) sRGB space. This will be converted to LSL later.

default
{
    state_entry()
    {
        gLampCol /= 255; //Convert to LSL colour.
    }

    touch_start(integer total_number)
    {
        switch = !switch; //toggle the switch
        llSetLinkPrimitiveParamsFast(LINK_THIS,[
            PRIM_POINT_LIGHT,switch,llsRGB2Linear(gLampCol),1,20,0, //Convert colour to linear RGB as PRIM_POINT_LIGHT requires, using llsRGB2Linear
            PRIM_COLOR,ALL_SIDES,gLampCol,1,
            PRIM_GLOW,ALL_SIDES,switch,
            PRIM_FULLBRIGHT,ALL_SIDES,switch]);
    }
}
```

</details>

<details>
<summary>Basic light script:-</summary>

```lsl collapse={1-11}
integer isLightTurnedOn;

default
{
    touch_start(integer total_number)
    {
//      toggle isLightTurnedOn between TRUE and FALSE
        isLightTurnedOn = !isLightTurnedOn;

        if (isLightTurnedOn)
        {
            llSetPrimitiveParams([
                PRIM_FULLBRIGHT, ALL_SIDES, FALSE,
                PRIM_POINT_LIGHT, FALSE, ZERO_VECTOR, 1.0, 10.0, 0.6]);
        }
        else
        {
            vector COLOR_ORANGE  = <1.000, 0.522, 0.106>;

            llSetPrimitiveParams([
                PRIM_FULLBRIGHT, ALL_SIDES, TRUE,
                PRIM_POINT_LIGHT, TRUE, COLOR_ORANGE, 1.0, 10.0, 0.6]);
        }
    }
}
```

</details>

<details>
<summary>A compact version of the above:-</summary>

```lsl
integer switch;
default
{
    touch_start(integer total_number)
    {
        llSetLinkPrimitiveParamsFast(LINK_THIS, [       PRIM_FULLBRIGHT, ALL_SIDES, switch = !switch,
                PRIM_POINT_LIGHT, switch, <1, 0.5, 0.1> *  switch, 1, 10, 0.6 ] );
    }
}
```

</details>

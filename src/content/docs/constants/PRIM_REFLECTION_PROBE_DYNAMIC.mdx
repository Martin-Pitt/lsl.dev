<LSLConstant name="PRIM_REFLECTION_PROBE_DYNAMIC" />

Used with [PRIM_REFLECTION_PROBE](/constants/PRIM_REFLECTION_PROBE/). A reflection probe does not image avatars by default, otherwise it images avatars if this flag is set on the corresponding prim. Imaging avatars in reflection probes has a performance cost.

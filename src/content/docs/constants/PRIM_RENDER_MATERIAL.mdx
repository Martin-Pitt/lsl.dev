<LSLConstant name="PRIM_RENDER_MATERIAL" description />

Used to get or set the material settings of a prim's `face`.

## Usage

```lsl
PRIM_RENDER_MATERIAL, integer face, string render_material
```

- [integer](https://wiki.secondlife.com/wiki/integer) **face** — a [face](https://wiki.secondlife.com/wiki/Face) number or [ALL_SIDES](/constants/ALL_SIDES/)
- [string](https://wiki.secondlife.com/wiki/string) **render_material**

Used with [llSetPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams) & [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams).

#### Caveats

- If **render_material** is provided as [NULL_KEY](/constants/NULL_KEY/), the [glTF Material](https://wiki.secondlife.com/wiki/PBR_Materials) is removed from **face**, reverting back to any underlying [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) materials.

##### Examples

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_RENDER_MATERIAL, ALL_SIDES, my_render_material ]);
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_RENDER_MATERIAL, ALL_SIDES, llGetInventoryName(INVENTORY_MATERIAL, 0) ]);
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_RENDER_MATERIAL, 0, my_render_material ]);
```

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_RENDER_MATERIAL, integer face ]);
```

Returns the same values, in the same order.

#### Caveats

- With **render_material** as with [llGetRenderMaterial](/functions/llGetRenderMaterial/), [NULL_KEY](/constants/NULL_KEY/) is returned when the [owner](https://wiki.secondlife.com/wiki/Category:LSL_Owner) does not have [full permissions](https://wiki.secondlife.com/wiki/Category:LSL_Permissions/Asset) to the object and the [material](/constants/PRIM_RENDER_MATERIAL/) is not in the prim's inventory.

##### Target

In the case of [llGetPrimitiveParams](/functions/llGetPrimitiveParams/) is either the prim the script resides in, or the prim specified by the immediately prior [PRIM_LINK_TARGET](/constants/PRIM_LINK_TARGET/) call. However in the case of [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/), it is either the value of the **link** parameter, or the prim specified by the immediately prior [PRIM_LINK_TARGET](/constants/PRIM_LINK_TARGET/) call.

<LSLConstant name="PRIM_ROT_LOCAL" description />

`PRIM_ROT_LOCAL` is used to get or set the prim's local rotation.

## Usage

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_ROT_LOCAL, rotation rot ]);
```

- [rotation](https://wiki.secondlife.com/wiki/rotation) **rot** — Any valid rotation

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_ROT_LOCAL ]);
```

Returns the same values, in the same order.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-15}
integer isRotated = FALSE;
vector rotated = <25, 25, 0>;
rotation notRotated = ZERO_ROTATION;
rotation rot;

default
{
    state_entry()
    {
        rotated *= DEG_TO_RAD;
        rot = llEuler2Rot( rotated );
    }

    touch_start(integer total_number)
    {
        if( isRotated )
        {
            llSetLinkPrimitiveParams( 2, [PRIM_ROT_LOCAL, notRotated] );
            isRotated = FALSE;
        }

        else if( !isRotated )
        {
            isRotated = TRUE;
            llSetLinkPrimitiveParams( 2, [PRIM_ROT_LOCAL, rot] );
        }
    }
}
```

</details>

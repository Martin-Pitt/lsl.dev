`PRIM_SCULPT_TYPE_MASK` can be used when parsing the output of [llGetPrimitiveParams](/functions/llGetPrimitiveParams/) when dealing with sculpted prims ([PRIM_TYPE_SCULPT](/constants/PRIM_TYPE_SCULPT/)) to separate the sculpted type from the flags ([PRIM_SCULPT_FLAG_INVERT](/constants/PRIM_SCULPT_FLAG_INVERT/) and [PRIM_SCULPT_FLAG_MIRROR](/constants/PRIM_SCULPT_FLAG_MIRROR/)) that can modify it.

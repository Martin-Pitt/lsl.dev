<LSLConstant name="PRIM_SCULPT_TYPE_SPHERE" />

When used in conjunction with [PRIM_TYPE_SCULPT](/constants/PRIM_TYPE_SCULPT/) a sphere type sculpty is produced. It does this by stitching the left side to right then separately converging the top & bottom.

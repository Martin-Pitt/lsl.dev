<LSLConstant name="PRIM_SIT_TARGET" />

The sit target, if any defined for this prim. If the active value is 0 the sit target is deactivated. If it is nonzero the prim's sit target is set to the indicated offset and rotation. As with [llLinkSitTarget](/functions/llLinkSitTarget/)(), these values are relative to the prim. However, unlike `llLinkSitTarget()` an offset of `<0.0, 0.0, 0.0>` may be explicitly set. Prim parameter \[PRIM_SIT_TARGET, integer boolean, vector offset, rotation rot\] to get or set the prim's sit target.

<LSLConstant name="PRIM_SIZE" description />

Returns or sets the prim's `size`.

## Usage

```lsl
PRIM_SIZE, vector size
```

- [vector](https://wiki.secondlife.com/wiki/vector) **size** — ranges from 0.01 to 64.0 for x, y and z[^v1]

When used with [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_SIZE ]);
```

Returns the same values, in the same order.

## Caveats

- Does not work on [physical](/constants/STATUS_PHYSICS/) prims.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Changing the prim size and rotation
default
{
  touch_start(integer total_number)
  {
    llSetLinkPrimitiveParamsFast(LINK_THIS, [
        PRIM_SIZE, <0.25,0.5,1.0>,
        PRIM_ROTATION, <1.0, 0.0, 0.0, 0.0>
      ]);
  }
}
```

</details>

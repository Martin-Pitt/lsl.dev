<LSLConstant name="PRIM_SIZE" description />

Returns or sets the prim's `size`.

## Caveats

- Does not work on [physical](/constants/STATUS_PHYSICS/) prims.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Changing the prim size and rotation
default
{
  touch_start(integer total_number)
  {
    llSetPrimitiveParams([
        PRIM_SIZE, <0.25,0.5,1.0>,
        PRIM_ROTATION, <1.0, 0.0, 0.0, 0.0>
      ]);
  }
}
```

</details>

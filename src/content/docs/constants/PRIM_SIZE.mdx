<LSLConstant name="PRIM_SIZE" description />

Returns or sets the prim's `size`.

## Usage

### \[ [PRIM_SIZE](/constants/PRIM_SIZE/), [vector](https://wiki.secondlife.com/wiki/vector) **size** \]

- [vector](https://wiki.secondlife.com/wiki/vector) **size** — ranges from 0.01 to 64.0 for x, y and z

When used with [llSetPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams) & [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams)

### [llGetPrimitiveParams](/functions/llGetPrimitiveParams/)(\[ [PRIM_SIZE](/constants/PRIM_SIZE/) \]);

- [vector](https://wiki.secondlife.com/wiki/vector) **size** — ranges from 0.01 to 64.0 for x, y and z

## Caveats

- Does not work on [physical](/constants/STATUS_PHYSICS/) prims.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Changing the prim size and rotation
default
{
  touch_start(integer total_number)
  {
    llSetPrimitiveParams([
        PRIM_SIZE, <0.25,0.5,1.0>,
        PRIM_ROTATION, <1.0, 0.0, 0.0, 0.0>
      ]);
  }
}
```

</details>

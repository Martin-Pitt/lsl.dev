<LSLConstant name="PRIM_SLICE" description />

Used to get or set the prim's slice values (a shape attribute, equivalent to `cut`).

## Usage

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_SLICE, vector slice ]);
```

- [vector](https://wiki.secondlife.com/wiki/vector) **slice** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)

The same syntax applies to [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams) and [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/) but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_SLICE ]);
```

Returns the same values, in the same order.

The same syntax applies to [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/), but with an additional prefixed [link](https://wiki.secondlife.com/wiki/Category:LSL_Parameters/link) parameter in the function call.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//updated findings show the difference can be as small as 0.02 not 0.05 (Tomos.Halsey)
default
{
    state_entry()
    {
        llSetLinkPrimitiveParamsFast(LINK_THIS,[PRIM_SLICE,<0.0,0.02,0.0>]);
    }
}
```

<LSLConstant name="PRIM_SLICE" description />

Used to get or set the prim's slice values (a shape attribute, equivalent to `cut`).

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//updated findings show the difference can be as small as 0.02 not 0.05 (Tomos.Halsey)
default
{
    state_entry()
    {
        llSetLinkPrimitiveParams(LINK_THIS,[PRIM_SLICE,<0.0,0.02,0.0>]);
    }
}
```

</details>

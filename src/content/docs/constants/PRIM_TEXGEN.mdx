<LSLConstant name="PRIM_TEXGEN" />

`PRIM_TEXGEN` is used to get and set the configure the texture mapping mode of the `face`.

| Constant | Type | Value | Description |
| --- | --- | --- | --- |
| [PRIM_TEXGEN_DEFAULT](/constants/PRIM_TEXGEN_DEFAULT/) | integer | `0` | The texture repeats units are in texture repeats per face. |
| [PRIM_TEXGEN_PLANAR](/constants/PRIM_TEXGEN_PLANAR/) | integer | `1` | The texture repeats units are in texture repeats per half meter. This is in contrast to the in-world editing tool, in which the planar texture scaling units are repeats per meter. |

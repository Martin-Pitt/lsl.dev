<LSLConstant name="PRIM_TEXT" description />

Used to get or set the object's [floating text](https://wiki.secondlife.com/wiki/Category:LSL_Floating_Text).

## Usage

```lsl
llSetLinkPrimitiveParamsFast(LINK_THIS, [ PRIM_TEXT, string text, vector color, float alpha ]);
```

- [string](https://wiki.secondlife.com/wiki/string) **text** — [floating text](https://wiki.secondlife.com/wiki/Category:LSL_Floating_Text) to display
- [vector](https://wiki.secondlife.com/wiki/vector) **color**
- [float](https://wiki.secondlife.com/wiki/float) **alpha** — opacity in the range 0.0 to 1.0

Syntax for: [llSetPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams), [llSetLinkPrimitiveParams](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams#llSetLinkPrimitiveParams) & [llSetLinkPrimitiveParamsFast](/functions/llSetLinkPrimitiveParamsFast/)

```lsl
llGetLinkPrimitiveParams(LINK_THIS, [ PRIM_TEXT ]);
```

- [string](https://wiki.secondlife.com/wiki/string) **text** — [floating text](https://wiki.secondlife.com/wiki/Category:LSL_Floating_Text) displayed
- [vector](https://wiki.secondlife.com/wiki/vector) **color**
- [float](https://wiki.secondlife.com/wiki/float) **alpha** — opacity in the range 0.0 to 1.0

Syntax for: [llGetPrimitiveParams](/functions/llGetPrimitiveParams/), [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/)

## Caveats

- Do not rely on [Floating Text](https://wiki.secondlife.com/wiki/Category:LSL_Floating_Text) as a storage medium; it is neither secure nor finalized.
  - Floating text has been altered in past server updates, breaking existing content; future changes may occur.
  - Even "invisible"[^wiki-374698] floating text is transmitted to the client.
    - It can be viewed by anyone with a client that is capable of rendering text that is supposed to be invisible.
    - The network packets that contain the text can be sniffed and the text read.

[^wiki-374698]: Floating text with an **alpha** set to 0.0 is rendered "invisible"

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-12}
default
{
    state_entry()
    {
        // a string to display
        string displayMessage = llGetDisplayName( llGetOwner() ) + ", test number ";

        // just so could test changing the displayMessage
        integer loopControl;
        for( loopControl = 1; loopControl < 3; ++loopControl )
        {
            // on first iteration set the text
            if( loopControl == 1 )
            {
                llSetPrimitiveParams([PRIM_TEXT, displayMessage + (string)loopControl + ".", <1, 0, 0>, 1.0]);
            }

            // on second iteration get the text and say it.
            else if( loopControl == 2 )
            {
                llSay(0, llDumpList2String(llGetPrimitiveParams([PRIM_TEXT]), " "));
            }
        }
    }
}
```

</details>

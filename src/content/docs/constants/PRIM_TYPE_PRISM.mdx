<LSLConstant name="PRIM_TYPE_PRISM" />

`PRIM_TYPE_PRISM` is a parameter of [PRIM_TYPE](/constants/PRIM_TYPE/) used to make prim into a prism and to change specific properties that define the shape of that prism.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
llSetPrimitiveParams([PRIM_TYPE,
                        PRIM_TYPE_PRISM,
                            PRIM_HOLE_DEFAULT,  // hole_shape
                            <0.00, 1.0, 0.0>,   // cut
                            0.0,                // hollow
                            <0.0, 0.0, 0.0>,    // twist
                            <1.0, 1.0, 0.0>,    // top_size
                            <0.0, 0.0, 0.0>     // top_Shear
                      ]);
```

</details>

`PRIM_TYPE_SPHERE` is a parameter of [PRIM_TYPE](/constants/PRIM_TYPE/) used to make prim into a sphere and to change specific properties that define the shape of that sphere.

## Usage

```lsl
PRIM_TYPE, PRIM_TYPE_SPHERE, integer hole_shape, vector cut, float hollow, vector twist, vector dimple
```

- [integer](https://wiki.secondlife.com/wiki/integer) **hole_shape** — PRIM_HOLE\_\* flag
- [vector](https://wiki.secondlife.com/wiki/vector) **cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [float](https://wiki.secondlife.com/wiki/float) **hollow** — ranges from 0.0 (solid) to 0.95 (maximum hollowed)
- [vector](https://wiki.secondlife.com/wiki/vector) **twist** — ranges from -1.0 (-360 degree in the edit window) to 1.0 (+360 degree in the edit window) for both x and y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **dimple** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)

## Examples

<details open>
<summary>Example 1</summary>

```lsl
// this makes a simple sphere
vector cut = <0.0, 1.0, 0.0>;      // 0.0 to 1.0
float hollow = 0.0;                // 0.0 to 0.95
vector twist = <0.0, 0.0, 0.0>;    // -1.0 to 1.0
vector dimple = <0.0, 1.0, 0.0>;   // 0.0 to 1.0
llSetLinkPrimitiveParamsFast(LINK_THIS, [PRIM_TYPE, PRIM_TYPE_SPHERE, PRIM_HOLE_DEFAULT,
                        cut, hollow, twist, dimple ]  );
```

</details>

`PRIM_TYPE_TORUS` is a parameter of [PRIM_TYPE](/constants/PRIM_TYPE/) used to make prim into a torus and to change specific properties that define the shape of that torus.

## Usage

```lsl
PRIM_TYPE, PRIM_TYPE_TORUS, integer hole_shape, vector cut, float hollow, vector twist, vector hole_size, vector top_shear, vector advanced_cut, vector taper, float revolutions, float radius_offset, float skew
```

- [integer](https://wiki.secondlife.com/wiki/integer) **hole_shape** — PRIM_HOLE\_\* flag
- [vector](https://wiki.secondlife.com/wiki/vector) **cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [float](https://wiki.secondlife.com/wiki/float) **hollow** — ranges from 0.0 (solid) to 0.95 (maximum hollowed), or 0.70 when `hole_shape` is [PRIM_HOLE_SQUARE](/constants/PRIM_HOLE_SQUARE/)[^v1]
- [vector](https://wiki.secondlife.com/wiki/vector) **twist** — ranges from -1.0 (-360 degree in the edit window) to 1.0 (+360 degree in the edit window) for both x and y (z is ignored)[^v2]
- [vector](https://wiki.secondlife.com/wiki/vector) **hole_size** — x ranges from 0.05 to 1.0; y ranges from 0.05 (large hole) to 0.50 (no hole)[^v3]
- [vector](https://wiki.secondlife.com/wiki/vector) **top_shear** — ranges from -0.5 to 0.5 for both x and y (z is ignored)[^v4]
- [vector](https://wiki.secondlife.com/wiki/vector) **advanced_cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **taper** — ranges from -1.0 to 1.0 for both x and y (z is ignored)[^v5]
- [float](https://wiki.secondlife.com/wiki/float) **revolutions** — ranges from 1.0 to 4.00[^v6]
- [float](https://wiki.secondlife.com/wiki/float) **radius_offset** — depends on holesize.y and revolutions
- [float](https://wiki.secondlife.com/wiki/float) **skew** — ranges from -0.95 to 0.95; with more than 1.0 revolutions the magnitude is also raised to a minimum that grows with `revolutions` and `hole_size.x`[^v7]

## Examples

<details open>
<summary>Example 1</summary>

```lsl
// this makes a nice expanding spiral
vector cut= <0.00000, 1.00000, 0.00000>;
float hollow = 0.0;                    // 0.0 to 0.95
vector twist = <0, 0.0, 0.0>;          // -1.0 to 1.0
vector holesize = <1.0, 0.05, 0.0>;    // max X:1.0 Y:0.5
vector topshear = <0.0, 0.0, 0.0>;     // -0.5 to 0.5
vector profilecut = <0.0, 0.0, 0.0>;   // 0.0 to 1.0
vector taper_a = <0.0, 0.0, 0.0>;      // 0.0 to 1.0
float revolutions = 3.0;               // 1.0 to 4.0
float radiusoffset = 1.0;              // -1.0 to 1.0
float skew = 0.0;                      //
llSetLinkPrimitiveParamsFast(LINK_THIS, [PRIM_TYPE, PRIM_TYPE_TORUS, PRIM_HOLE_DEFAULT,
                        cut, hollow, twist, holesize, topshear,
                        profilecut, taper_a, revolutions,
                        radiusoffset, skew] );
```

</details>

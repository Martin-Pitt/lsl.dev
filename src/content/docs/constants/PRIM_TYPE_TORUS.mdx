`PRIM_TYPE_TORUS` is a parameter of [PRIM_TYPE](/constants/PRIM_TYPE/) used to make prim into a torus and to change specific properties that define the shape of that torus.

## Usage

### \[ [PRIM_TYPE](/constants/PRIM_TYPE/), [PRIM_TYPE_TORUS](/constants/PRIM_TYPE_TORUS/), [integer](https://wiki.secondlife.com/wiki/integer) **hole_shape**, [vector](https://wiki.secondlife.com/wiki/vector) **cut**, [float](https://wiki.secondlife.com/wiki/float) **hollow**, [vector](https://wiki.secondlife.com/wiki/vector) **twist**, [vector](https://wiki.secondlife.com/wiki/vector) **hole_size**, [vector](https://wiki.secondlife.com/wiki/vector) **top_shear**, [vector](https://wiki.secondlife.com/wiki/vector) **advanced_cut**, [vector](https://wiki.secondlife.com/wiki/vector) **taper**, [float](https://wiki.secondlife.com/wiki/float) **revolutions**, [float](https://wiki.secondlife.com/wiki/float) **radius_offset**, [float](https://wiki.secondlife.com/wiki/float) **skew** \]

- [integer](https://wiki.secondlife.com/wiki/integer) **hole_shape** — PRIM_HOLE\_\* flag
- [vector](https://wiki.secondlife.com/wiki/vector) **cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [float](https://wiki.secondlife.com/wiki/float) **hollow** — ranges from 0.0 (solid) to 0.95 (maximum hollowed)
- [vector](https://wiki.secondlife.com/wiki/vector) **twist** — ranges from -1.0 (-360 degree in the edit window) to 1.0 (+360 degree in the edit window) for both x and y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **hole_size** — x ranges from 0.05 to 1.0; y ranges from 0.05 (large hole) to 0.50 (no hole)
- [vector](https://wiki.secondlife.com/wiki/vector) **top_shear** — ranges from -0.5 to 0.5 for both x and y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **advanced_cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **taper** — ranges from -1.0 to 1.0 for both x and y (z is ignored)
- [float](https://wiki.secondlife.com/wiki/float) **revolutions** — ranges from 1.0 to 4.00
- [float](https://wiki.secondlife.com/wiki/float) **radius_offset** — depends on holesize.y and revolutions
- [float](https://wiki.secondlife.com/wiki/float) **skew** — ranges from -1.0 to 1.0

### \[ 1, [PRIM_TYPE_TORUS](/constants/PRIM_TYPE_TORUS/), [vector](https://wiki.secondlife.com/wiki/vector) **cut**, [float](https://wiki.secondlife.com/wiki/float) **hollow**, [float](https://wiki.secondlife.com/wiki/float) **twist_end**, [float](https://wiki.secondlife.com/wiki/float) **hole_size_y**, [vector](https://wiki.secondlife.com/wiki/vector) **top_shear**, [vector](https://wiki.secondlife.com/wiki/vector) **advanced_cut** \]

- [vector](https://wiki.secondlife.com/wiki/vector) **cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)
- [float](https://wiki.secondlife.com/wiki/float) **hollow** — ranges from 0.0 (solid) to 0.95 (maximum hollowed)
- [float](https://wiki.secondlife.com/wiki/float) **twist_end** — ranges from -0.5 (-180 degree in the edit window) to 0.5 (+180 degree in the edit window)
- [float](https://wiki.secondlife.com/wiki/float) **hole_size_y** — ranges from 0.05 (large hole) to 0.50 (no hole)
- [vector](https://wiki.secondlife.com/wiki/vector) **top_shear** — ranges from -0.5 to 0.5 for both x and y (z is ignored)
- [vector](https://wiki.secondlife.com/wiki/vector) **advanced_cut** — x and y range from 0.0 to 1.0, x must be at least 0.05 smaller than y (z is ignored)

This is the old [PRIM_TYPE](/constants/PRIM_TYPE/) format for the torus ([PRIM_TYPE](/constants/PRIM_TYPE/) used to be 1 instead of 9). Use the new format unless you are maintaining old code.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
// this makes a nice expanding spiral
vector cut= <0.00000, 1.00000, 0.00000>;
float hollow = 0.0;                    // 0.0 to 0.95
vector twist = <0, 0.0, 0.0>;          // -1.0 to 1.0
vector holesize = <1.0, 0.05, 0.0>;    // max X:1.0 Y:0.5
vector topshear = <0.0, 0.0, 0.0>;     // -0.5 to 0.5
vector profilecut = <0.0, 0.0, 0.0>;   // 0.0 to 1.0
vector taper_a = <0.0, 0.0, 0.0>;      // 0.0 to 1.0
float revolutions = 3.0;               // 1.0 to 4.0
float radiusoffset = 1.0;              // -1.0 to 1.0
float skew = 0.0;                      //
llSetPrimitiveParams( [PRIM_TYPE, PRIM_TYPE_TORUS, PRIM_HOLE_DEFAULT,
                        cut, hollow, twist, holesize, topshear,
                        profilecut, taper_a, revolutions,
                        radiusoffset, skew] );
```

</details>

<LSLConstant name="PUBLIC_CHANNEL" />

Chat channel that broadcasts to all nearby users & objects. This channel is sometimes referred to as: open chat, local chat and public chat.

If used with a [llRegionSayTo](/functions/llRegionSayTo/), it goes to the specified user or prim. Unlike private channels, the user's attachments do not receive the message.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer num_detected)
    {
        llSay(PUBLIC_CHANNEL, "Hello there, I'm talking in local chat on channel 0.");
    }
}
```

</details>

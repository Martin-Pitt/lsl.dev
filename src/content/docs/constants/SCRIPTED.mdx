<LSLConstant name="SCRIPTED" />

If it is contained in the result of [llDetectedType](/functions/llDetectedType/)(), it means what was detected has at least one active script.

If it is used as a filter of [llSensor](/functions/llSensor/)() or [llSensorRepeat](/functions/llSensorRepeat/)(), it will search for objects that has any script, which is doing anything in simulator just now.

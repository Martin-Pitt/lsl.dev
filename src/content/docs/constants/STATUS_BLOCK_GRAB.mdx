<LSLConstant name="STATUS_BLOCK_GRAB" />

This status flag keeps the object from being moved by [grabs](https://wiki.secondlife.com/wiki/Category:LSL_Grab). It will only block grab moves of unlinked prims or the root of a [linkset](https://wiki.secondlife.com/wiki/Viewerhelp:Glossary#linkset).

- To block grab moves of an entire linkset use [STATUS_BLOCK_GRAB_OBJECT](/constants/STATUS_BLOCK_GRAB_OBJECT/)

This means when a user tries to grab an object with this flag enabled, they will be unable to manipulate the object.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        // Block grabbing in this prim or the root if in a link_set
        llSetStatus(STATUS_BLOCK_GRAB, TRUE);
    }
}
```

</details>

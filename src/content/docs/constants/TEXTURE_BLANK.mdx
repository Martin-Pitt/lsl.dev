## Notes

Like any [LSO](https://wiki.secondlife.com/wiki/LSO) string constants longer then 3 characters and used in multiple places in the code, they should be stored in a global variable. The result will be a considerable memory savings. This does not apply to scripts compiled with [Mono](https://wiki.secondlife.com/wiki/Mono). See [LSL Constants vs Globals](https://wiki.secondlife.com/wiki/LSL_Constants_vs_Globals) for more information about this and examples.

<LSLConstant name="TOUCH_INVALID_VECTOR" description />

Returned by [llDetectedTouchPos](/functions/llDetectedTouchPos/), [llDetectedTouchNormal](/functions/llDetectedTouchNormal/), and [llDetectedTouchBinormal](/functions/llDetectedTouchBinormal/) when the [touch position](https://wiki.secondlife.com/wiki/LSL_Touch_Position) is not valid.

## Caveats

- For [llDetectedTouchPos](/functions/llDetectedTouchPos/), `{{LSL VR|0.0|0.0|0.0}}` may be a valid value so it is possible to get a false negative in this rare situation.

## Notes

- Is treated like [FALSE](/constants/FALSE/) in [conditionals](https://wiki.secondlife.com/wiki/Category:LSL_Conditional).

<LSLConstant name="VEHICLE_FLAG_CAMERA_DECOUPLED" />

This flag only has an effect when steering a vehicle with [mouselook](https://wiki.secondlife.com/wiki/mouselook). In other words, only when either [VEHICLE_FLAG_MOUSELOOK_STEER](/constants/VEHICLE_FLAG_MOUSELOOK_STEER/) or [VEHICLE_FLAG_MOUSELOOK_BANK](/constants/VEHICLE_FLAG_MOUSELOOK_BANK/) are also set. When it is in effect it has zero server-side consequences, except that a bit is set in the **flags** field in the vehicle's [ObjectUpdate](https://wiki.secondlife.com/wiki/ObjectUpdate) message sent from server to client. The client uses the flag as a hint for how to compute its mouselook camera orientation as vehicle moves under the seated avatar.

When the flag is NOT set the avatar's mouselook camera will move in the world-frame as the vehicle changes its own world-frame orientation. The avatar's mouselook camera is effectively at an offset relative to the vehicle's local-frame.

When the flag IS set the avatar's mouselook camera will be unaffected by the motion of the vehicle itself: it moves only in the world-frame according to user input.

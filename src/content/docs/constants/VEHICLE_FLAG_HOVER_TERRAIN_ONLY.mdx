Makes the vehicle float over land.

If you wanted to make a boat you should set the [VEHICLE_FLAG_HOVER_WATER_ONLY](/constants/VEHICLE_FLAG_HOVER_WATER_ONLY/) flag, or if you wanted to drive a hover tank under water you would use the [VEHICLE_FLAG_HOVER_TERRAIN_ONLY](/constants/VEHICLE_FLAG_HOVER_TERRAIN_ONLY/) flag instead. Finally, if you wanted to make a submarine or a balloon you would use the [VEHICLE_FLAG_HOVER_GLOBAL_HEIGHT](/constants/VEHICLE_FLAG_HOVER_GLOBAL_HEIGHT/).

The vehicle flags are independent of each other and that setting two contradictory flags will have undefined behavior. The flags are set using the script call [llSetVehicleFlags](/functions/llSetVehicleFlags/).

<LSLEvent name="final_damage" />

This event is triggered after all [on_damage](/events/on_damage/) events in all scripts and attachments have processed and damage has been applied to the avatar or distributed to all seated avatars.

All llDetected\* functions that are normally available within a collision event are available while processing this event. Additionally the [llDetectedDamage](/functions/llDetectedDamage/) methods may be called while processing this event.

```lsl title="How to use" frame="terminal"
final_damage(integer num_detected)
{

}
```

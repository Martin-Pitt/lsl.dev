Animesh is rigged mesh that has its own skeleton, so an object can play avatar-style animations by itself. Pets, NPCs, creatures and moving decor are typical uses.

It is not an avatar: there is no agent behind it. The object must be rigged mesh with the Animated Mesh option enabled in the build tools, and a script in the object starts and stops animations from the object's own inventory.

No permission is needed, because the script animates its own object rather than an avatar.

<Columns>
<Column>
<Box title="Concepts">

- An animesh object [plays animations](/functions/llStartObjectAnimation/) from its own inventory
  - Animations are referred to by inventory name or asset key
  - Several can run at once and blend by priority, as they do on avatars
  - [Stop one](/functions/llStopObjectAnimation/) by name, or [list what is playing](/functions/llGetObjectAnimationNames/)
- Animesh moves like any other object
  - For walking creatures, [keyframed motion](/functions/llSetKeyframedMotion/) or [pathfinding characters](/functions/llCreateCharacter/) are the usual choices
  - Start and stop animations to match the motion, for example when a character [starts](/events/moving_start/) or [stops](/events/moving_end/) moving, or on a [path update](/events/path_update/)
- Appearance works like other mesh
  - Faces take [textures and materials](/features/textures/)
  - Attachments can also be animesh; their animations play on the attachment, not on the [wearer](/features/avatar/)

</Box>

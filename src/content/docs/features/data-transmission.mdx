Chat, link messages, linkset data, notecards and HTTP all carry strings. Lists, numbers, vectors, rotations and keys must be turned into strings to be sent or stored, then parsed back on the other side.

This page is about formats, not channels: see [communications](/features/communications/) for how strings travel and [data storage](/features/data-storage/) for where they are kept.

Choose a format both sides understand: a delimited string for simple fields, CSV for lists of values, JSON for nested data or web services, and Base64 for binary or compact values.

<Columns>
<Column>
<Box title="Concepts">

- The most common format is a list [joined with a separator](/functions/llDumpList2String/)
  - Parsing [splits it again](/functions/llParseString2List/) (or [keeps empty fields](/functions/llParseStringKeepNulls/))
  - Typecasts or `llList2*` functions such as [`llList2Integer`](/functions/llList2Integer/) convert each field to its type; [`llGetListEntryType`](/functions/llGetListEntryType/) tells what a field holds
  - [CSV](/functions/llList2CSV/) is a ready-made variant, [parsed back](/functions/llCSV2List/) into a list
- [JSON](/functions/llList2Json/) represents nested objects and arrays, and is the format web services expect
  - LSL can build JSON from lists, [read](/functions/llJsonGetValue/) and [change](/functions/llJsonSetValue/) values by path, and [convert JSON arrays and objects back to lists](/functions/llJson2List/)
- Encoding
  - [Base64](/functions/llStringToBase64/) makes arbitrary text or [integers](/functions/llIntegerToBase64/) safe to embed in other formats
  - [URL escaping](/functions/llEscapeURL/) prepares values for HTTP
  - Characters convert to [codepoints](/functions/llOrd/) and [back](/functions/llChar/)
- Parsing strings: string functions [find](/functions/llSubStringIndex/), [cut](/functions/llGetSubString/) and [replace](/functions/llReplaceSubString/) text
  - Strings are UTF-8 internally but indexed by character
- Working with lists: received lists often need [searching](/functions/llListFindList/), [slicing](/functions/llList2List/), [sorting](/functions/llListSort/) or reshaping
  - [Strided lists](/functions/llList2ListStrided/) store records as repeating groups of fields
- Keys (UUIDs) identify avatars, objects and assets
  - [Generate unique keys](/functions/llGenerateKey/) for request IDs and records
- Integrity: [hashes](/functions/llComputeHash/), [HMACs](/functions/llHMAC/) and [RSA signatures](/functions/llSignRSA/) let a receiver check that a message has not been changed and came from the expected sender

</Box>

<Box title="Additional">

- [`llList2Json`](/functions/llList2Json/) — what to build
  - [`JSON_OBJECT`](/constants/JSON_OBJECT/) — the list is strided key-value pairs, encoded as an object
  - [`JSON_ARRAY`](/constants/JSON_ARRAY/) — the list is encoded as an array
  - [`JSON_INVALID`](/constants/JSON_INVALID/) — returned for badly formed input, an invalid type, or a nonexistent location
- [`llJsonSetValue`](/functions/llJsonSetValue/) — [`JSON_APPEND`](/constants/JSON_APPEND/) appends to the array at the given level
- [`llJsonValueType`](/functions/llJsonValueType/) — returns a type such as [`JSON_STRING`](/constants/JSON_STRING/) or [`JSON_NUMBER`](/constants/JSON_NUMBER/)
- [`llGetListEntryType`](/functions/llGetListEntryType/) — field types
  - [`TYPE_INTEGER`](/constants/TYPE_INTEGER/), [`TYPE_FLOAT`](/constants/TYPE_FLOAT/), [`TYPE_STRING`](/constants/TYPE_STRING/), [`TYPE_KEY`](/constants/TYPE_KEY/), [`TYPE_VECTOR`](/constants/TYPE_VECTOR/), [`TYPE_ROTATION`](/constants/TYPE_ROTATION/) — the stored type
  - [`TYPE_INVALID`](/constants/TYPE_INVALID/) — the entry is invalid
- [`llStringTrim`](/functions/llStringTrim/) — which end to trim
  - [`STRING_TRIM`](/constants/STRING_TRIM/) — both ends
  - [`STRING_TRIM_HEAD`](/constants/STRING_TRIM_HEAD/) — the beginning
  - [`STRING_TRIM_TAIL`](/constants/STRING_TRIM_TAIL/) — the end
- [`llListStatistics`](/functions/llListStatistics/) — operations such as [`LIST_STAT_MEAN`](/constants/LIST_STAT_MEAN/), [`LIST_STAT_MEDIAN`](/constants/LIST_STAT_MEDIAN/), [`LIST_STAT_SUM`](/constants/LIST_STAT_SUM/) or [`LIST_STAT_STD_DEV`](/constants/LIST_STAT_STD_DEV/)

</Box>

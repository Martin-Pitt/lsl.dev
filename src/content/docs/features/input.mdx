Users interact with objects by clicking them, and with scripted vehicles, weapons and HUDs through captured controls. A script can capture movement keys and the mouse button, and read gamepad buttons and axes.

Input is not free text: for choices and typed input, use [dialogs](/features/dialog/), text boxes or [chat commands](/features/communications/).

Touch needs no permission. Controls need [PERMISSION_TAKE_CONTROLS](/constants/PERMISSION_TAKE_CONTROLS/); gamepads need [PERMISSION_GAME_CONTROL](/constants/PERMISSION_GAME_CONTROL/) and viewer support.

<Columns>
<Column>
<Box title="Concepts">

- Clicking an object raises [touch_start](/events/touch_start/), [touch](/events/touch/) and [touch_end](/events/touch_end/), following a click from press to release
  - Several avatars can touch at once; [who touched](/functions/llDetectedKey/) and [which prim](/functions/llDetectedLinkNumber/) are read with the detected functions
  - The touch position functions give the [face](/functions/llDetectedTouchFace/) and [surface coordinates](/functions/llDetectedTouchST/), which makes single-prim buttons possible
  - Child prims can [pass touches to the root](/functions/llPassTouches/)
- A [click action](/functions/llSetClickAction/) changes what a left-click does: touch, sit, pay, open, play media, or nothing
  - Setting a HUD root to ignore clicks lets each interactive prim choose its own cursor
  - The right-click menu can show [other text instead of "Touch"](/functions/llSetTouchText/)
- Scripts can [capture](/functions/llTakeControls/) movement keys and the left mouse button
  - Needs [permission](/functions/llRequestPermissions/) from the avatar, granted in [run_time_permissions](/events/run_time_permissions/)
  - The [control](/events/control/) event reports which keys are held and which changed
  - Controls can also pass through to normal movement
  - Sitting avatars can be [forced into mouselook](/functions/llForceMouselook/), and [agent info](/functions/llGetAgentInfo/) tells whether an avatar is [in mouselook](/constants/AGENT_MOUSELOOK/)
- [Gamepad](https://wiki.secondlife.com/wiki/Game_control) buttons and axes arrive in [game_control](/events/game_control/)
  - Available on all regions of the main grid; viewer support is still in progress
  - Only triggers for scripts in attachments or seats

</Box>
</Column>

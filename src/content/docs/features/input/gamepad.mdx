A compatible viewer can send game controller input for an avatar to scripts. Part of the [Input](/features/input/) feature; lsl.dev lists these APIs together in the [Gamepad](/categories/gamepad/) category.

- Controller changes raise [`game_control`](/events/game_control/), but only for scripts in attachments or seats
  - **id** is the avatar supplying the controller input
  - **button_levels** is a 32-bit mask of the [canonical buttons](/constants/groups/GameControlButton/) currently held down
  - **axes** is a list of six floats in the range [-1.0, 1.0], the [canonical axes](#canonical-axes) indexed by `GAME_CONTROL_AXIS_*`
- A script can [read the current game-control mode](/functions/llGetGameControlMode/) of an avatar, as a [`GAME_CONTROL_MODE_*`](/constants/groups/GameControlMode/) value
  - Each mode has its own [modal axes](/functions/llGetGameControlModeAxes/) and [modal buttons](/functions/llGetGameControlModeButtons/); element count, index and bit meanings vary by mode
  - Modal values use the `GAME_CONTROL_AXIS_*` constants as indices and the `GAME_CONTROL_BUTTON_*` constants as masks
- [`PERMISSION_GAME_CONTROL`](/constants/PERMISSION_GAME_CONTROL/) is a [script permission](/constants/groups/ScriptPermission/) for game control

## Game-control modes

`llGetGameControlMode` returns one of these `GAME_CONTROL_MODE_*` values for the avatar given by **id**.

## Canonical axes

The six entries of the **axes** list in `game_control`.

| Constant | Index | Description |
| --- | ---: | --- |
| [`GAME_CONTROL_AXIS_LEFTX`](/constants/GAME_CONTROL_AXIS_LEFTX/) | 0 | Left stick X axis. Canonical axis index 0. |
| [`GAME_CONTROL_AXIS_LEFTY`](/constants/GAME_CONTROL_AXIS_LEFTY/) | 1 | Left stick Y axis. Canonical axis index 1. |
| [`GAME_CONTROL_AXIS_RIGHTX`](/constants/GAME_CONTROL_AXIS_RIGHTX/) | 2 | Right stick X axis. Canonical axis index 2. |
| [`GAME_CONTROL_AXIS_RIGHTY`](/constants/GAME_CONTROL_AXIS_RIGHTY/) | 3 | Right stick Y axis. Canonical axis index 3. |
| [`GAME_CONTROL_AXIS_LEFT_TRIGGER`](/constants/GAME_CONTROL_AXIS_LEFT_TRIGGER/) | 4 | Left trigger. Canonical axis index 4. |
| [`GAME_CONTROL_AXIS_RIGHT_TRIGGER`](/constants/GAME_CONTROL_AXIS_RIGHT_TRIGGER/) | 5 | Right trigger. Canonical axis index 5. |

## Modal axes

Indices into the list returned by `llGetGameControlModeAxes`; which ones apply depends on the mode.

| Constant | Index | Description |

| [`GAME_CONTROL_AXIS_STRAFE`](/constants/GAME_CONTROL_AXIS_STRAFE/) | 0 | Left/right movement. Modal axis index 0 for AVATAR, MOUSELOOK, and CAPTIVE modes. |
| [`GAME_CONTROL_AXIS_ADVANCE`](/constants/GAME_CONTROL_AXIS_ADVANCE/) | 1 | Forward/backward movement. Modal axis index 1 for AVATAR, MOUSELOOK, and CAPTIVE modes. |
| [`GAME_CONTROL_AXIS_TURN`](/constants/GAME_CONTROL_AXIS_TURN/) | 2 | Turning left/right. Modal axis index 2 for AVATAR, MOUSELOOK, CAPTIVE, and CURSOR modes. |
| [`GAME_CONTROL_AXIS_LOOK`](/constants/GAME_CONTROL_AXIS_LOOK/) | 3 | Looking up/down. Modal axis index 3 for AVATAR, MOUSELOOK, CAPTIVE, and CURSOR modes. |
| [`GAME_CONTROL_AXIS_RISE`](/constants/GAME_CONTROL_AXIS_RISE/) | 4 | Up/down movement. Modal axis index 4 for AVATAR, MOUSELOOK, and CAPTIVE modes. |
| [`GAME_CONTROL_AXIS_ZOOM`](/constants/GAME_CONTROL_AXIS_ZOOM/) | 6 | Camera zoom in/out. Modal axis index 6 for AVATAR, MOUSELOOK, CAPTIVE, and FLYCAM modes. |
| [`GAME_CONTROL_AXIS_TRUCK`](/constants/GAME_CONTROL_AXIS_TRUCK/) | 0 | Camera lateral (left/right) movement. Modal axis index 0 for FLYCAM mode. |

| [`GAME_CONTROL_AXIS_PAN`](/constants/GAME_CONTROL_AXIS_PAN/) | 2 | Camera pan left/right. Modal axis index 2 for FLYCAM mode. |

| [`GAME_CONTROL_AXIS_BOOM`](/constants/GAME_CONTROL_AXIS_BOOM/) | 4 | Camera up/down movement. Modal axis index 4 for FLYCAM mode. |

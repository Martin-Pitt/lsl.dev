An object is a linkset: one root prim plus any child prims, moving and rezzing as a unit. Each prim has a link number. The root is 1 when there are several prims, and 0 in a single-prim object. Seated avatars are added after the prims.

Most prim functions have a Link variant that works on any prim by link number, so one script can control the whole object. What a single prim looks like is covered by [Prims](/features/prims/).

<Columns>
<Column>
<Box title="Concepts">

- Every prim has a [link number](/functions/llGetLinkNumber/); the object has a [number of prims](/functions/llGetNumberOfPrims/) (including seated avatars) and a [prim count](/functions/llGetObjectPrimCount/)
  - Special link constants address [the root](/constants/LINK_ROOT/), [this prim](/constants/LINK_THIS/), [all prims](/constants/LINK_SET/), [all others](/constants/LINK_ALL_OTHERS/) or [all children](/constants/LINK_ALL_CHILDREN/)
  - [Names](/functions/llGetLinkName/) and [keys](/functions/llGetLinkKey/) help find a prim by role instead of by number, because numbers change when the object is relinked
- [Linking](/functions/llCreateLink/) and [unlinking](/functions/llBreakLink/) need `PERMISSION_CHANGE_LINKS` from the owner
  - The [`changed`](/events/changed/) event reports [`CHANGED_LINK`](/constants/CHANGED_LINK/)
- One script can [set](/functions/llSetLinkPrimitiveParamsFast/) or [read](/functions/llGetLinkPrimitiveParams/) many properties of any prim, or several prims, in one call
  - Scripts in different prims talk with [link messages](/functions/llMessageLinked/)
- The object as a whole has a [root position](/functions/llGetRootPosition/), a [bounding box](/functions/llGetBoundingBox/), a [mass](/functions/llGetObjectMass/) and an owner, and can be [scaled](/functions/llScaleByFactor/) as a unit
  - [Details of other objects](/functions/llGetObjectDetails/) are read by key
- Objects in inventory can be [rezzed](/functions/llRezObject/) with a position, velocity and parameters
  - [`llRezObjectWithParams`](/functions/llRezObjectWithParams/) sets many properties at rez time
  - The child receives the start parameter in [`on_rez`](/events/on_rez/)
  - Objects can [delete themselves](/functions/llDie/) or [derez others they own](/functions/llDerezObject/)

</Box>
</Column>

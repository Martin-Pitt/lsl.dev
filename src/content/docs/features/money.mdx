Objects can receive L$ from avatars and, with the owner's permission, pay L$ out. Vendors, tip jars, rentals and games are built from these few functions.

Receiving needs no permission: the [money](/events/money/) event fires when someone pays the object. Paying out needs [PERMISSION_DEBIT](/constants/PERMISSION_DEBIT/), granted by the owner. Handle it carefully, because a bug can spend the owner's money.

<Columns>
<Column>
<Box title="Concepts">

- Receiving payments
  - The [money](/events/money/) event fires when someone pays the object
  - The pay dialog shows a default amount and quick-pay buttons, which the script [controls](/functions/llSetPayPrice/)
  - Set the [click action](/functions/llSetClickAction/) to [pay](/constants/CLICK_ACTION_PAY/) to open it on click
- Paying out
  - The owner grants PERMISSION_DEBIT through [llRequestPermissions](/functions/llRequestPermissions/)
  - [llTransferLindenDollars](/functions/llTransferLindenDollars/) returns a transaction key, and reports success or failure in [transaction_result](/events/transaction_result/)
  - [llGiveMoney](/functions/llGiveMoney/) is the older call with no result
- Vendors
  - After payment, a vendor checks the amount and [gives the item](/functions/llGiveInventory/), refunding wrong amounts
  - Several items can be [given as a folder](/functions/llGiveAgentInventory/), and [agent data](/functions/llRequestAgentData/) can be looked up

</Box>
</Column>

<Box title="Additional">

- [llSetPayPrice](/functions/llSetPayPrice/) — suggests the default amount and the four quick-pay buttons ([pay buttons](/constants/groups/PayButton/))
  - [PAY_HIDE](/constants/PAY_HIDE/) — hide the specified quick pay button completely
  - [PAY_DEFAULT](/constants/PAY_DEFAULT/) — use the default value for the specified quick pay button
- [llSetClickAction](/functions/llSetClickAction/)
  - [CLICK_ACTION_PAY](/constants/CLICK_ACTION_PAY/) — opens the pay dialog when the prim is clicked or touched
- [transaction_result](/events/transaction_result/) — on failure, reports a [transfer error](/constants/groups/TransferError/)

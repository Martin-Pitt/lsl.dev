A physical object is simulated by the physics engine: it has mass, falls, collides and responds to forces. Non-physical objects stay where they are put but still collide with physical ones.

Physics settings cover the object's status, its shape and material, how it collides, and what it reports when it hits something. Moving objects without physics is covered under [Movement](/features/movement/).

<Columns>
<Column>
<Box title="Concepts">

- [Physical](/constants/PRIM_PHYSICS/), [phantom](/constants/PRIM_PHANTOM/), [temporary](/constants/PRIM_TEMP_ON_REZ/) and the rotation locks are [object status flags](/functions/llSetStatus/)
  - [Volume detect](/functions/llVolumeDetect/) makes an object phantom while still reporting collisions
- Mass depends on size and density; read it [in lindograms](/functions/llGetMass/), [in kilograms](/functions/llGetMassMKS/), [for any object](/functions/llGetObjectMass/), or find the [center of mass](/functions/llGetCenterOfMass/)
  - [Physics materials](/functions/llSetPhysicsMaterial/) set gravity, friction, density and restitution
  - The [physics shape type](/constants/PRIM_PHYSICS_SHAPE_TYPE/) changes how the engine sees the prim
  - The [prim material](/constants/PRIM_MATERIAL/) sets the default collision sound, friction and restitution without affecting mass
- [Collision events](/events/collision_start/) report contacts with objects and avatars, and [`land_collision`](/events/land_collision_start/) events with the ground
  - [Filters](/functions/llCollisionFilter/) and [pass-through settings](/functions/llPassCollisions/) narrow what is reported
  - What hit is read with the detected functions, such as [its velocity](/functions/llDetectedVel/)
  - [Replace the collision sound](/functions/llCollisionSound/)
- Forces act [continuously](/functions/llSetForce/); impulses act [once](/functions/llApplyImpulse/)
  - [Push other objects and avatars](/functions/llPushObject/) where the parcel allows it
- [Raycasts](/functions/llCastRay/) trace a line through the region for line of sight, hitscan weapons and placement
- Physics performance depends on the region: [time dilation](/functions/llGetRegionTimeDilation/) and [statistics](/functions/llGetSimStats/) show how busy it is

</Box>
</Column>

<Box title="Additional">

- [`llSetStatus`](/functions/llSetStatus/) and [`llGetStatus`](/functions/llGetStatus/) — object status flags ([`ObjectStatusParam`](/constants/groups/ObjectStatusParam/))
  - [`STATUS_PHYSICS`](/constants/STATUS_PHYSICS/) — Respond to physics, gravity and forces
  - [`STATUS_PHANTOM`](/constants/STATUS_PHANTOM/) — Avatars and objects pass through
  - [`STATUS_ROTATE_X`](/constants/STATUS_ROTATE_X/), [`STATUS_ROTATE_Y`](/constants/STATUS_ROTATE_Y/), [`STATUS_ROTATE_Z`](/constants/STATUS_ROTATE_Z/) — Allow or lock physical rotation per local axis
  - [`STATUS_DIE_AT_EDGE`](/constants/STATUS_DIE_AT_EDGE/), [`STATUS_RETURN_AT_EDGE`](/constants/STATUS_RETURN_AT_EDGE/) — Delete or return the object when it goes off-world
  - [`STATUS_BLOCK_GRAB`](/constants/STATUS_BLOCK_GRAB/) — Block click-and-drag grabbing
  - [`STATUS_SANDBOX`](/constants/STATUS_SANDBOX/) — Keep the object near its creation point
- [`llSetLinkPrimitiveParamsFast`](/functions/llSetLinkPrimitiveParamsFast/) — the same settings as prim params
  - [`PRIM_PHYSICS`](/constants/PRIM_PHYSICS/), [`PRIM_PHANTOM`](/constants/PRIM_PHANTOM/), [`PRIM_TEMP_ON_REZ`](/constants/PRIM_TEMP_ON_REZ/) — Physical, phantom and temporary status
  - [`PRIM_PHYSICS_SHAPE_TYPE`](/constants/PRIM_PHYSICS_SHAPE_TYPE/) — [`PRIM_PHYSICS_SHAPE_PRIM`](/constants/PRIM_PHYSICS_SHAPE_PRIM/) (default for non-mesh), [`PRIM_PHYSICS_SHAPE_CONVEX`](/constants/PRIM_PHYSICS_SHAPE_CONVEX/) (default for mesh) or [`PRIM_PHYSICS_SHAPE_NONE`](/constants/PRIM_PHYSICS_SHAPE_NONE/) (not on the root prim)
  - [`PRIM_MATERIAL`](/constants/PRIM_MATERIAL/) — Collision sound, friction and restitution preset
- [`llSetPhysicsMaterial`](/functions/llSetPhysicsMaterial/) — the mask selects which values apply ([`PhysicsMaterialParam`](/constants/groups/PhysicsMaterialParam/))
  - [`GRAVITY_MULTIPLIER`](/constants/GRAVITY_MULTIPLIER/) — Between -1.0 and +28.0
  - [`RESTITUTION`](/constants/RESTITUTION/) — Bounciness, between 0.0 and 1.0
  - [`FRICTION`](/constants/FRICTION/) — Between 0.0 and 255.0
  - [`DENSITY`](/constants/DENSITY/) — Between 1.0 and 22587.0 kg/m³
- [`llCastRay`](/functions/llCastRay/) — options ([`RayCastParam`](/constants/groups/RayCastParam/))
  - [`RC_REJECT_TYPES`](/constants/RC_REJECT_TYPES/) — Ignore types of hits ([`RayCastRejectType`](/constants/groups/RayCastRejectType/)), such as [avatars](/constants/RC_REJECT_AGENTS/) or [land](/constants/RC_REJECT_LAND/)
  - [`RC_DATA_FLAGS`](/constants/RC_DATA_FLAGS/) — Extra data per hit ([`RayCastData`](/constants/groups/RayCastData/)): [normal](/constants/RC_GET_NORMAL/), [root key](/constants/RC_GET_ROOT_KEY/), [link number](/constants/RC_GET_LINK_NUM/)
  - [`RC_MAX_HITS`](/constants/RC_MAX_HITS/) — Maximum hits to return; keep it small
  - [`RC_DETECT_PHANTOM`](/constants/RC_DETECT_PHANTOM/) — Also detect phantom and volume-detect objects
  - A negative status code is an error ([`RayCastError`](/constants/groups/RayCastError/))
- [`llGetObjectDetails`](/functions/llGetObjectDetails/) — [`OBJECT_PHYSICS`](/constants/OBJECT_PHYSICS/) tells whether physics is on; [`OBJECT_PHYSICS_COST`](/constants/OBJECT_PHYSICS_COST/) gets the physics cost
- [`llPushObject`](/functions/llPushObject/) — restricted by [`PARCEL_FLAG_RESTRICT_PUSHOBJECT`](/constants/PARCEL_FLAG_RESTRICT_PUSHOBJECT/) and [`REGION_FLAG_RESTRICT_PUSHOBJECT`](/constants/REGION_FLAG_RESTRICT_PUSHOBJECT/)
- [`llRezObjectWithParams`](/functions/llRezObjectWithParams/) — [`REZ_FLAG_PHYSICAL`](/constants/REZ_FLAG_PHYSICAL/) rezzes the object with physics enabled

</Box>

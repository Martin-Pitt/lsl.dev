<LSLFunction name="llAdjustDamage" description />

The `llAdjustDamage` modifies the amount of damage that will be applied by the current [on_damage](/events/on_damage/) event after it has completed processing.

```lsl title="How to use" frame="terminal"
llAdjustDamage(0, 0.0);
```

## Specification

This function allows a script to modify incoming damage before it is applied to an avatar or distributed by a task.

## Caveats

- Calling this function from any event handler other than [on_damage](/events/on_damage/) results in an error message being shouted to the debug channel.
- Requires the region to [allow damage adjustment](/functions/llGetEnv/) for the on_damage event to run
- Negative indexes are not supported.
- Indexes that are out of range will silently fail.

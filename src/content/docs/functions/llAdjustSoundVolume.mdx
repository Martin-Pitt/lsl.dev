<LSLFunction name="llAdjustSoundVolume" description />

Adjusts **volume** of attached sound.[^v1]

```lsl title="How to use" frame="terminal"
llAdjustSoundVolume(0.0);
```

## Caveats

Not work [llTriggerSound](/functions/llTriggerSound/)[^v2] and [llCollisionSound](/functions/llCollisionSound/)

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        llListen(42, "", llGetOwner(), "");
    }

    listen(integer chan, string name, key id, string msg)
    {
        float value = (float)msg;
        llAdjustSoundVolume(value);
        llOwnerSay("Volume set to: " + (string)value + " of 1.0");
    }
}
```

</details>

<details>
<summary>Example 2</summary>

```lsl
default
{
    collision_start(integer p)
    {
        llPlaySound("5df2e97f-d3ab-9a80-7063-69007470a182", 1.0);
        llAdjustSoundVolume(1.0);
        llSetTimerEvent(0.2); //In 0.2 seconds, will reduce the volume of the currently playing audio.
    }
    timer(){
        llAdjustSoundVolume(0.1);
        llSetTimerEvent(0.0);
    }
}
```

</details>

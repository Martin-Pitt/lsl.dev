<LSLFunction name="llAngleBetween" />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the angle in radians between rotation `a` and rotation `b`.

```lsl title="How to use" frame="terminal"
float result = llAngleBetween(ZERO_ROTATION, ZERO_ROTATION);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer num_detected)
    {
        rotation currentRootRotation = llGetRootRotation();
        float angle = llAngleBetween(ZERO_ROTATION, currentRootRotation);

        // PUBLIC_CHANNEL has the integer value 0
        llSay(PUBLIC_CHANNEL,
            "llAngleBetween(ZERO_ROTATION, " + (string)currentRootRotation + ") = " + (string)angle);
    }
}
```

</details>

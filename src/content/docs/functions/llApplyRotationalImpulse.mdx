<LSLFunction name="llApplyRotationalImpulse" description />

Applies rotational impulse to object.

```lsl title="How to use" frame="terminal"
llApplyRotationalImpulse(ZERO_VECTOR, 0);
```

## Caveats

- It does **not** work on attachments.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        llApplyRotationalImpulse(<0,5,0>,TRUE); //Rotates object.
    }
}
```

</details>

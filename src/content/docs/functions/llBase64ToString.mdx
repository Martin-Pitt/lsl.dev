<LSLFunction name="llBase64ToString" description />

Returns a [string](https://wiki.secondlife.com/wiki/string) that is the [Base64](https://wiki.secondlife.com/wiki/Category:LSL_Base64) **str** decoded into a conventional string, interpreting the Base64-encoded bytes as UTF-8 character sequence.

```lsl title="How to use" frame="terminal"
string result = llBase64ToString("");
```

## Caveats

- If the conversion creates any unprintable characters, they are converted to spaces.
- Converts invalid characters into question marks ('?').

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default {
    state_entry()
    {
        string test = llBase64ToString("U2VjcmV0Ok9wZW4=");
        llSay(0,test );
    }
}
```

</details>

<details>
<summary>This can be used in [Basic Authentication](https://en.wikipedia.org/wiki/Basic_access_authentication), such as this login:</summary>

```lsl
GET / HTTP/1.1
User-Agent: Mozilla/4.0 (compatible; MSIE 7.0; Windows NT 5.2)
Host: www.example.com
Authorization: Basic U2VjcmV0Ok9wZW4=
```

</details>

<details>
<summary>Example 3</summary>

```lsl
llBase64ToString("U2VjcmV0Ok9wZW4="); //will return the string "Secret:Open"
```

</details>

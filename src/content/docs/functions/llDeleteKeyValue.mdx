<LSLFunction name="llDeleteKeyValue" />

Start an asynchronous transaction to delete a key-value pair associated with the script's [Experience](/categories/experience/) with the given key (**k**).

If the key does not exist the [dataserver](/events/dataserver/) will return a failure along with the error [XP_ERROR_STORAGE_EXCEPTION](/constants/XP_ERROR_STORAGE_EXCEPTION/).

Returns a [key](https://wiki.secondlife.com/wiki/key) that can be used to identify the corresponding [dataserver](/events/dataserver/) event to determine if this command succeeded or failed and the results.

```lsl title="How to use" frame="terminal"
key result = llDeleteKeyValue("");
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={16-27}
key trans;
default
{
    state_entry()
    {
        trans = llDeleteKeyValue("FOO");
    }

    dataserver(key t, string value)
    {
        if (t == trans)
        {
            // our llDeleteKeyValue transaction is done
            list result = llCSV2List(value);
            if (llList2Integer(result, 0) == 1)
            {
                // the key-value pair was successfully deleted
                llSay(0, "New key-value pair was deleted");
            }
            else
            {
                // the key-value pair was not deleted
                llSay(0, "Key-value failed to delete: " + llList2String(result, 1) );
            }
        }
    }
}
```

</details>

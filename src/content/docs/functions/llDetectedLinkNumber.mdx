<LSLFunction name="llDetectedLinkNumber" description />

For [touch](/categories/touch/) and [collision](https://wiki.secondlife.com/wiki/Category:LSL_Collision) categories of events only.

```lsl title="How to use" frame="terminal"
integer result = llDetectedLinkNumber(0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    // Drop this script into the root prim of of a build
    // Touch any prim to learn its link number
    touch_start(integer num_detected)
    {
        llOwnerSay("Link number clicked: " + (string)llDetectedLinkNumber(0));
    }
}
```

</details>

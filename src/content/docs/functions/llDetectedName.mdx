<LSLFunction name="llDetectedName" />

Returns

[NULL_KEY](/constants/NULL_KEY/)

if **item** is not valid.

If the item detected is an avatar then the [legacy name](https://wiki.secondlife.com/wiki/Category:LSL_Avatar/Name) is returned.

Returns a [string](https://wiki.secondlife.com/wiki/string) that is the name of the [detected](/categories/detected/) **item**.

```lsl title="How to use" frame="terminal"
string result = llDetectedName(0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer num_detected)
    {
        string name = llDetectedName(0);

        llOwnerSay("Touched by " + name);

       // name is the legacy name, as in "John Doe", or "John Resident" if the avatar has the default last name.
    }
}
```

</details>

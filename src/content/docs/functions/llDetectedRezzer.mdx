<LSLFunction name="llDetectedRezzer" />

Returns an `empty key` if **number** does not correspond to a valid sensed object or avatar.

Returns a [key](https://wiki.secondlife.com/wiki/key) that is the [UUID](https://wiki.secondlife.com/wiki/UUID) of the object or avatar that rezzed the [detected](/categories/detected/) object **number**.

```lsl title="How to use" frame="terminal"
key result = llDetectedRezzer(0);
```

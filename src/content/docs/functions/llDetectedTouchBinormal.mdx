<LSLFunction name="llDetectedTouchBinormal" />

For the [touch](/categories/touch/) category of events only. The prim that was touched may not be the prim receiving the event, use [llDetectedLinkNumber](/functions/llDetectedLinkNumber/) to check for this; likewise you can use [llDetectedTouchFace](/functions/llDetectedTouchFace/) to determine which face was touched.To find the third tangent vector, [cross](https://wiki.secondlife.com/wiki/LSL_Cross_Product) this vector with the [normal](/functions/llDetectedTouchNormal/).

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the surface binormal (tangent to the surface, pointing along the positive T (V) direction of tangent space) where the touch event was triggered. Along with [llDetectedTouchNormal](/functions/llDetectedTouchNormal/), this information can be used to find the [tangent space](http://en.wikipedia.org/wiki/Tangent_space) at the touch location.

```lsl title="How to use" frame="terminal"
vector result = llDetectedTouchBinormal(0);
```

## Caveats

- [TOUCH_INVALID_VECTOR](/constants/TOUCH_INVALID_VECTOR/) is returned when...
- The avatar's viewer does not support face touch detection.
- To check if face touch detection is supported check the return of [llDetectedTouchFace](/functions/llDetectedTouchFace/).
- The touch has moved off the surface of the prim.
- The event triggered is not a [touch](/categories/touch/) event.

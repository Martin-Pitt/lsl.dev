<LSLFunction name="llDetectedTouchNormal" />

For the [touch](/categories/touch/) category of events only. The prim that was touched may not be the prim receiving the event, use [llDetectedLinkNumber](/functions/llDetectedLinkNumber/) to check for this; likewise you can use [llDetectedTouchFace](/functions/llDetectedTouchFace/) to determine which face was touched.To find the third tangent vector, [cross](https://wiki.secondlife.com/wiki/LSL_Cross_Product) the [binormal](/functions/llDetectedTouchBinormal/) with this vector.

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the surface normal (perpendicular to the surface) where the touch event was triggered. Along with [llDetectedTouchBinormal](/functions/llDetectedTouchBinormal/), this information can be used to find the [tangent space](http://en.wikipedia.org/wiki/Tangent_space) at the touch location.

```lsl title="How to use" frame="terminal"
vector result = llDetectedTouchNormal(0);
```

## Caveats

- [TOUCH_INVALID_VECTOR](/constants/TOUCH_INVALID_VECTOR/) is returned when...
- The avatar's viewer does not support face touch detection.
- To check if face touch detection is supported check the return of [llDetectedTouchFace](/functions/llDetectedTouchFace/).
- The touch has moved off the surface of the prim.
- The event triggered is not a [touch](/categories/touch/) event.
- The rotation of a legacy sphere prim does not influence touch normal like it does with other legacy prims.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_num)
    {
        llOwnerSay((string)llDetectedTouchNormal(0)); //Says the vector where the touched face is pointing to.
    }
}
```

</details>

## Helper functions

```lsl
touch_start(integer total_number){
    // rotates the prim, so the touched position points upwards
    llSetRot(llGetRot()*llRotBetween(llDetectedTouchNormal(0),<0,0,1>));
}
```

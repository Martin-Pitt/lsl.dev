<LSLFunction name="llDetectedType" description />

Returns `zero` if **number** is not valid sensed object or avatar.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is the types of the detected object or avatar.

```lsl title="How to use" frame="terminal"
integer result = llDetectedType(0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-6, 12-18}
//--// Type & name of collision source //--//

default{
    collision_start( integer vIntCollided ){
        integer vBitType;
        string vStrType;
        do
        {
            vBitType = llDetectedType( --vIntCollided );
            if (vBitType & AGENT_BY_LEGACY_NAME)
                vStrType = "avatar";
            else
                vStrType = "object";
            llOwnerSay( "An " + vStrType + " named '" + llDetectedName( vIntCollided ) + "' collided with me" );
        }
        while (vIntCollided);
    }
}
```

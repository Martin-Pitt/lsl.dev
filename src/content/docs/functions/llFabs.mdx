<LSLFunction name="llFabs" />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the positive version of **val**.

```lsl title="How to use" frame="terminal"
float result = llFabs(0.0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        llSay(0,"The (Float)absolute value of -4.5 is: "+(string)llFabs(-4.5) );
    }
}
// returns :
// The (Float)absolute value of -4.5 is: 4.500000
```

</details>

## Notes

- Using `val-2*val*(val<0)` is roughly 60% faster than `llFabs` as it avoids a function call, though it produces `{{abbr|NaN|not a number}}` if given an infinite value and (correctly) returns 0.0 instead of -0.0 when taking the absolute value of negative zero.

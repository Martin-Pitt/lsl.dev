<LSLFunction name="llForceMouselook" description />

Sets if a sitting avatar should be forced into [mouselook](https://wiki.secondlife.com/wiki/mouselook) when they sit on this prim.

A [sit target](/functions/llSitTarget/) is not necessary for this function to work.

```lsl title="How to use" frame="terminal"
llForceMouselook(0);
```

## Caveats

- This function has no effect on avatars already seated.
- The user may exit mouselook mode at any time.
- This can be detected by polling [llGetAgentInfo](/functions/llGetAgentInfo/).
- There is nothing stopping someone from modifying or making a client that ignores this.

## Examples

<details open>
<summary>**Force Mouselook on Sit**</summary>

```lsl
default
{
    state_entry()
    {
        llForceMouselook(TRUE); // Forces sitting avatars into mouselook.

        llForceMouselook(FALSE); // Reverts the setting to the default...
                                 // ...as with a newly created prim.
    }
}
```

</details>

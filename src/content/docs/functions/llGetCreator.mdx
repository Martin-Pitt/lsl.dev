<LSLFunction name="llGetCreator" description />

Returns a [key](https://wiki.secondlife.com/wiki/key) for the creator of the prim.

```lsl title="How to use" frame="terminal"
key result = llGetCreator();
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        key owner = llGetOwner();
        key creatorThisPrim = llGetCreator();

        llSay(0, "The creator of this prim has the key '"+(string)creatorThisPrim + "'.");
        llSay(0, "My owner has the key '" + (string)owner + "'.");
    }
}
```

</details>

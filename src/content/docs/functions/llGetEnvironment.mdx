<LSLFunction name="llGetEnvironment" />

If an unknown rule is encountered in the parameter list an error is sent to the debug channel.

Returns a [list](https://wiki.secondlife.com/wiki/list) containing the current environment values for the parcel or region as a list of attributes. Takes a list of attributes to retrieve in **params** and returns them in the order requested.

```lsl title="How to use" frame="terminal"
list result = llGetEnvironment(ZERO_VECTOR, []);
```

## Caveats

- If the script can not run in the requested parcel, this function returns an empty list and issues a warning in the debug channel.
- [SKY_LIGHT](/constants/SKY_LIGHT/)'s param *fade_color* does not return a clamped value, meaning an unusually bright scene will cause it to return an out-of-bounds color. (This can be fixed by clamping the value manually, but this should really return a clamped value).

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        list environment = llGetEnvironment(llGetPos(), [SKY_TRACKS, SKY_AMBIENT, SKY_CLOUDS]);
        llOwnerSay(llDumpList2String(environment, ", "));
    }
}
```

<LSLFunction name="llGetExperienceErrorMessage" />

Returns a text description of a particular Experience LSL error constant.

Returns a [string](https://wiki.secondlife.com/wiki/string) describing the error code passed or the string corresponding to **error**. Returns [XP_ERROR_UNKNOWN_ERROR](/constants/XP_ERROR_UNKNOWN_ERROR/) if the **error** is not a valid error code.

```lsl title="How to use" frame="terminal"
string result = llGetExperienceErrorMessage(0);
```

## Specification

| LSL Constant |  | Message returned via [llGetExperienceErrorMessage](/functions/llGetExperienceErrorMessage/) | Description |
| --- | --- | --- | --- |
| [XP_ERROR_NONE](/constants/XP_ERROR_NONE/) | 0 | no error | No error was detected. |
| [XP_ERROR_THROTTLED](/constants/XP_ERROR_THROTTLED/) | 1 | exceeded throttle | The call failed due to too many recent calls. |
| [XP_ERROR_EXPERIENCES_DISABLED](/constants/XP_ERROR_EXPERIENCES_DISABLED/) | 2 | experiences are disabled | The region currently has experiences disabled. |
| [XP_ERROR_INVALID_PARAMETERS](/constants/XP_ERROR_INVALID_PARAMETERS/) | 3 | invalid parameters | One of the string arguments was too big to fit in the key-value store. |
| [XP_ERROR_NOT_PERMITTED](/constants/XP_ERROR_NOT_PERMITTED/) | 4 | operation not permitted | Experience permissions were denied by the user. |
| [XP_ERROR_NO_EXPERIENCE](/constants/XP_ERROR_NO_EXPERIENCE/) | 5 | script not associated with an experience | This script is not associated with an experience. |
| [XP_ERROR_NOT_FOUND](/constants/XP_ERROR_NOT_FOUND/) | 6 | not found | The sim was unable to verify the validity of the experience. Retrying after a short wait is advised. |
| [XP_ERROR_INVALID_EXPERIENCE](/constants/XP_ERROR_INVALID_EXPERIENCE/) | 7 | invalid experience | The script is associated with an experience that no longer exists. |
| [XP_ERROR_EXPERIENCE_DISABLED](/constants/XP_ERROR_EXPERIENCE_DISABLED/) | 8 | experience is disabled | The experience owner has temporarily disabled the experience. |
| [XP_ERROR_EXPERIENCE_SUSPENDED](/constants/XP_ERROR_EXPERIENCE_SUSPENDED/) | 9 | experience is suspended | The experience has been suspended by Linden Lab customer support. |
| [XP_ERROR_UNKNOWN_ERROR](/constants/XP_ERROR_UNKNOWN_ERROR/) | 10 | unknown error | An unknown error not covered by any of the other predetermined error states. |
| [XP_ERROR_QUOTA_EXCEEDED](/constants/XP_ERROR_QUOTA_EXCEEDED/) | 11 | experience data quota exceeded | An attempt to write data to the key-value store failed due to the data quota being met. |
| [XP_ERROR_STORE_DISABLED](/constants/XP_ERROR_STORE_DISABLED/) | 12 | key-value store is disabled | They key-value store is currently disabled on this region. |
| [XP_ERROR_STORAGE_EXCEPTION](/constants/XP_ERROR_STORAGE_EXCEPTION/) | 13 | key-value store communication failed | Unable to communicate with the key-value store, or attempted to create key that already exists |
| [XP_ERROR_KEY_NOT_FOUND](/constants/XP_ERROR_KEY_NOT_FOUND/) | 14 | key doesn't exist | They requested key does not exist. |
| [XP_ERROR_RETRY_UPDATE](/constants/XP_ERROR_RETRY_UPDATE/) | 15 | retry update | A checked update failed due to an out of date request. |
| [XP_ERROR_MATURITY_EXCEEDED](/constants/XP_ERROR_MATURITY_EXCEEDED/) | 16 | experience content rating too high | The content rating of the experience exceeds that of the region. |
| [XP_ERROR_NOT_PERMITTED_LAND](/constants/XP_ERROR_NOT_PERMITTED_LAND/) | 17 | not allowed to run on this land | The experience is blocked or not enabled for this land. |
| [XP_ERROR_REQUEST_PERM_TIMEOUT](/constants/XP_ERROR_REQUEST_PERM_TIMEOUT/) | 18 | experience permissions request timed out | The request for experience permissions was ignored. |

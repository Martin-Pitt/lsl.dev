<LSLFunction name="llGetExperienceErrorMessage" />

Returns a text description of a particular Experience LSL error constant.

Returns a [string](https://wiki.secondlife.com/wiki/string) describing the error code passed or the string corresponding to **error**. Returns [XP_ERROR_UNKNOWN_ERROR](/constants/XP_ERROR_UNKNOWN_ERROR/) if the **error** is not a valid error code.

```lsl title="How to use" frame="terminal"
string result = llGetExperienceErrorMessage(0);
```

## Specification

Errors fall into two families. Permission requests ([llRequestExperiencePermissions](/functions/llRequestExperiencePermissions/), reported through [experience_permissions_denied](/events/experience_permissions_denied/)) depend on the avatar and on whether the experience is allowed on the land, so they can fail with [XP_ERROR_NOT_PERMITTED_LAND](/constants/XP_ERROR_NOT_PERMITTED_LAND/). Key-value store calls ([llCreateKeyValue](/functions/llCreateKeyValue/) and the rest, reported through [dataserver](/events/dataserver/)) only need the script compiled with an experience and do not depend on the land[^xp-land]. Errors about the experience itself can come from either.

| [XP_ERROR_QUOTA_EXCEEDED](/constants/XP_ERROR_QUOTA_EXCEEDED/) | 11 | experience data quota exceeded | An attempt to write data to the key-value store failed due to the data quota being met. | Key-value store |

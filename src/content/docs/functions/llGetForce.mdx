<LSLFunction name="llGetForce" description />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the force (if the script is physical)

```lsl title="How to use" frame="terminal"
vector result = llGetForce();
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-7}
default
{
    state_entry()
    {
        llSetForce(<0,llFrand(10),0>,FALSE); //Sets the force in a frand of 10 in Y axis.
        llSetTimerEvent(1); //Resets the force every second.
    }
    touch_start(integer total_num)
    {
        llOwnerSay((string)llGetForce()); //Says the force.
    }
    timer()
    {
        llResetScript();
    }
}
```

</details>

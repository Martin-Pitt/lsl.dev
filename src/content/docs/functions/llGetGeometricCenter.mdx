<LSLFunction name="llGetGeometricCenter" description />

```lsl title="How to use" frame="terminal"
vector result = llGetGeometricCenter();
```

## Caveats

The "geometric center" is different from the "center" in viewer's build tools and also different from what [llRezObject](/functions/llRezObject/) considers to be the "center" of a linkset.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        llOwnerSay("Geometric center of the object relative to the root prim: " + (string)llGetGeometricCenter());
    }
}
```

</details>

## Notes

- The "geometric center" is the average of all linked prim centers. Mathematically, it's the root-relative positions of all linked prims in the linkset added together and divided by the number of prims in the linkset.

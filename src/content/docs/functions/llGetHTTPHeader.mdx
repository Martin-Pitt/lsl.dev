<LSLFunction name="llGetHTTPHeader" />

Returns an empty string if the header is not found, if the **request_id** is not a valid key received through the [http_request](/events/http_request/) event, or if the headers can no longer be accessed. Headers can only be accessed before [llHTTPResponse](/functions/llHTTPResponse/) is called and with-in the first 30 seconds after the [http_request](/events/http_request/) event is queued.

Returns a [string](https://wiki.secondlife.com/wiki/string) that is the value for **header** for **request_id**.

```lsl title="How to use" frame="terminal"
string result = llGetHTTPHeader(NULL_KEY, "");
```

## Specification

#### Generated Headers

These headers are automatically generated by the simulator, they were not actually sent by the requesting client. They supply information about the request to make parsing easier.

Sample URL: [`{{HoverTextStyle|style=color:green;|https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322|2={{String|x-script-url}} = {{String|https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322}}}}``{{HoverTextStyle|style=color:blue;|/foo/bar|2={{String|x-path-info}} = {{String|/foo/bar}}}}`?`{{HoverTextStyle|style=color:red;|1=arg=gra|2={{String|x-query-string}} = {{String|1=arg=gra}}}}`](https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322/foo/bar?arg=gra)

| header | description | example |
| --- | --- | --- |
| "x-script-url" | The base url, as originally received from [llRequestURL](/functions/llRequestURL/)/[llRequestSecureURL](/functions/llRequestSecureURL/) | &lt;font color="green">https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322&lt;/font> |
| "x-path-info" | Any trailing path information from the requested url | &lt;font color="blue">/foo/bar&lt;/font> |
| "x-query-string" | Any query arguments, the text past the first "?" in the url | &lt;font color="red">arg=gra&lt;/font> |
| "x-remote-ip" | IP address of the host that made the request |  |

## Caveats

- Header information becomes inaccessible after 30 seconds or if [llHTTPResponse](/functions/llHTTPResponse/) is called.
- Function returns an empty string in any context outside the [http_request](/events/http_request/) event. For instance, it cannot be used in the [http_response](/events/http_response/) event.
- Custom headers are not supported, only the headers listed in the specification are supported.
- LSL is not a CGI environment
- "Content-Type" is an example of a normal header name, in a CGI environment the name would be "HTTP_CONTENT_TYPE".
- **header** must be lower case (or it will match nothing). All header names are converted to lower case when they are received.
- When making a request...
- The path part of the URL must be prefixed with a forward slash
- Good: https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322/foo
- Bad: https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322foo
- In order to use the query string, you must include a path (even if it is just a slash)
- Good: https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322/?arg=gra
- Bad: https://sim3015.aditi.lindenlab.com:12043/cap/a7717681-2c04-e4ac-35e3-1f01c9861322?arg=gra

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-40, 46-51}
key url_request;

default
{
    state_entry()
    {
        url_request = llRequestURL();
    }

    http_request(key id, string method, string body)
    {
        if (url_request == id)
        {
        //  if you're usually not resetting the query ID
        //  now is a good time to start!
            url_request = "";

            if (method == URL_REQUEST_GRANTED)
            {
                llOwnerSay("URL: " + body);

                key owner = llGetOwner();
                vector ownerSize = llGetAgentSize(owner);

                if (ownerSize)//  != ZERO_VECTOR
                    llLoadURL(owner, "I got a new URL!", body);
            }

            else if (method == URL_REQUEST_DENIED)
                llOwnerSay("Something went wrong, no url:\n" + body);
        }

        else
        {
            list headerList = ["x-script-url",
                            "x-path-info", "x-query-string",
                            "x-remote-ip", "user-agent"];

            integer index = -llGetListLength(headerList);
            do
            {
                string header = llList2String(headerList, index);
                llOwnerSay(header + ": " + llGetHTTPHeader(id, header));
            }
            while (++index);

            llOwnerSay("body:\n" + body);
            llHTTPResponse(id, 200, body);
        }
    }
}
```

</details>

## Notes

- There is no specific function to set HTTP headers. Use [llHTTPRequest](/functions/llHTTPRequest/) with [HTTP_CUSTOM_HEADER](/constants/HTTP_CUSTOM_HEADER/) for requests. There is no way to set headers for responses.

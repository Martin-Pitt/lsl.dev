<LSLFunction name="llGetInventoryCreator" description />

Returns a [key](https://wiki.secondlife.com/wiki/key) of the creator of the inventory **item**.

```lsl title="How to use" frame="terminal"
key result = llGetInventoryCreator("");
```

## Caveats

- If **item** has multiple creators, then this function will return [NULL_KEY](/constants/NULL_KEY/). (e.g. if an object created by Lex contained a script created by Strife). See [SVC-6985](https://jira.secondlife.com/browse/SVC-6985) and [SVC-6820](https://jira.secondlife.com/browse/SVC-6820) for more information.

## Examples

<details open>
<summary>Add an object to a prims inventory, as well as this script, in order to get the name of the creator.</summary>

```lsl
default{
    state_entry(){
        llRequestAgentData(llGetInventoryCreator(llGetInventoryName( INVENTORY_OBJECT, 0)),DATA_NAME);
    }

    dataserver(key qid, string data){
        llOwnerSay(data);
    }
}
```

</details>

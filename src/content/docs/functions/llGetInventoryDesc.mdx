<LSLFunction name="llGetInventoryDesc" description />

Returns a [string](https://wiki.secondlife.com/wiki/string) with the description of the inventory **item**.

```lsl title="How to use" frame="terminal"
string result = llGetInventoryDesc("");
```

## Caveats

- If **item** has no description an empty string is returned.

## Examples

<details open>
<summary>Add an object to a prims inventory, as well as this script, in order to get the name of the creator.</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        integer count = llGetInventoryNumber(INVENTORY_ALL);
        integer index;
        for (index = 0; index < count; ++index)
        {
            string name = llGetInventoryName(INVENTORY_ALL, index);
            string desc = llGetInventoryDesc(name);

            llSay(0, "Item: \"" + name + "\" -- \"" + desc + "\"");
        }
    }
}
```

</details>

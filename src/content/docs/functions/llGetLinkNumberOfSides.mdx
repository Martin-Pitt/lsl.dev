<LSLFunction name="llGetLinkNumberOfSides" />

See [Face](https://wiki.secondlife.com/wiki/Category:LSL_Face) for more information about faces and the conditions that control the number of faces a prim will have.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is the number of faces (or sides) of the prim **link**.

```lsl title="How to use" frame="terminal"
integer result = llGetLinkNumberOfSides(0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        // Tell the owner the number of sides on the root prim
        integer numOfSides = llGetLinkNumberOfSides(LINK_ROOT);
        llOwnerSay( "The root prim has " + (string) numOfSides + " sides." );
    }
}
```

</details>

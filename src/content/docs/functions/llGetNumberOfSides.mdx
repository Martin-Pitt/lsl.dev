<LSLFunction name="llGetNumberOfSides" />

See [Face](https://wiki.secondlife.com/wiki/Category:LSL_Face) for more information about faces and the conditions that control the number of faces a prim will have.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is the number of faces (or sides) of the prim.

```lsl title="How to use" frame="terminal"
integer result = llGetNumberOfSides();
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        // Set the hovertext to indicate the number of sides
        integer numOfSides = llGetNumberOfSides();
        llSetText( "I have " + (string)numOfSides + " sides.", <1,1,1>, 1 );
    }
}
```

</details>

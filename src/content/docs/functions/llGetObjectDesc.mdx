<LSLFunction name="llGetObjectDesc" />

To get the *object's* description (not the current prim's), use [PRIM_DESC](/constants/PRIM_DESC/) or [OBJECT_DESC](/constants/OBJECT_DESC/).

Returns a [string](https://wiki.secondlife.com/wiki/string) containing the description of the prim the script is attached to.

```lsl title="How to use" frame="terminal"
string result = llGetObjectDesc();
```

## Caveats

:::note
This function **does not** get the description of the object's rootprim, but the description of the prim containing the script. Please use [llList2String](/functions/llList2String/)([llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/)([LINK_ROOT](/constants/LINK_ROOT/), \[ [PRIM_DESC](/constants/PRIM_DESC/) \]), 0); instead.
:::

## Examples

<table>
	<tr>
		<th>**Get this prim's description**</th>
	</tr>
	<tr>
		<td>

			```lsl
			default
			{
			    state_entry()
			    {
			    //  PUBLIC_CHANNEL has the integer value 0
			        llSay(PUBLIC_CHANNEL, "This prim's description: " + llGetObjectDesc() );
			    }
			}
			```

		</td>
	</tr>
</table>

<table>
	<tr>
		<th>**Get the root prim's description**</th>
	</tr>
	<tr>
		<td>

			```lsl
			default
			{
			    state_entry()
			    {
			    //  PUBLIC_CHANNEL has the integer value 0
			        llSay(PUBLIC_CHANNEL, "Rootprim's description: "
			            + llList2String(llGetLinkPrimitiveParams(LINK_ROOT, [ PRIM_DESC ]), 0));
			    }
			}
			```

		</td>
	</tr>
</table>

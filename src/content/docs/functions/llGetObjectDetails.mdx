<LSLFunction name="llGetObjectDetails" />

An empty list if **id** is not found.

[OBJECT_UNKNOWN_DETAIL](/constants/OBJECT_UNKNOWN_DETAIL/) is returned when passed an invalid integer parameter.

Returns a [list](https://wiki.secondlife.com/wiki/list) of the details for **id**, specifically those requested in **params**.

```lsl title="How to use" frame="terminal"
list result = llGetObjectDetails(NULL_KEY, []);
```

## Caveats

- [OBJECT_ROT](/constants/OBJECT_ROT/) will return an accurate facing for Avatars seated or in mouselook, but only a rough direction otherwise.
- Adjacent regions are not searched for prims which match **id**.
- Information for avatars that can no longer be found will still be available for a short period (about 45 seconds) but it is not updated.
- Items in **params** that are not integers are silently ignored, [OBJECT_UNKNOWN_DETAIL](/constants/OBJECT_UNKNOWN_DETAIL/) is not returned.
- This function does not return information about items in inventory.
- [llTargetOmega](/functions/llTargetOmega/) will only effect the return of [OBJECT_ROT](/constants/OBJECT_ROT/) if the object is [physical](/constants/STATUS_PHYSICS/). If the object is not physical then the original start rotation is returned, [llTargetOmega](/functions/llTargetOmega/) is a [client side effect](/categories/effects/).
- [OBJECT_SCRIPT_MEMORY](/constants/OBJECT_SCRIPT_MEMORY/) reports the maximum memory that all scripts in an object could use, not the actual amount of real memory currently used. In particular, [Mono](https://wiki.secondlife.com/wiki/Mono) scripts only report the default 64K or what they chose with [llSetMemoryLimit](/functions/llSetMemoryLimit/), not the current dynamic allocation that is only accessible from within the script. For [LSO](https://wiki.secondlife.com/wiki/LSO) scripts, the 16K is real usage in all cases. In practice, this makes the number reported a worst case scenario.
- [OBJECT_RUNNING_SCRIPT_COUNT](/constants/OBJECT_RUNNING_SCRIPT_COUNT/) includes crashed scripts in its count.
- [OBJECT_REZZER_KEY](/constants/OBJECT_REZZER_KEY/) will return [NULL_KEY](/constants/NULL_KEY/) for objects rezzed prior to server version 16.01.16.310114
- Objects copied in-world between server versions 16.01.16.310114 & 16.10.14.320687 return the object's creator key for rezzer key.
- Child prims linked before server version 17.11.11.510664 return the root prim's rezzer key.
- Child prims delinked before server version 17.11.11.510664 return [NULL_KEY](/constants/NULL_KEY/) for rezzer key.
- When targeting an agent with [OBJECT_REZZER_KEY](/constants/OBJECT_REZZER_KEY/) while they are sitting on an object, the rezzer key of the object's root prim is returned.
- When targeting an attachment with [OBJECT_MASS](/constants/OBJECT_MASS/), the mass of the avatar (or that of the avatar's sat-upon object) is returned.
- Since [OBJECT_GROUP](/constants/OBJECT_GROUP/) returns [NULL_KEY](/constants/NULL_KEY/) for avatars, a workaround is required to acquire an avatar's active group. A common approach is to query the avatar's attachments with [llGetAttachedList](/functions/llGetAttachedList/) and if at least one is found, get the [OBJECT_GROUP](/constants/OBJECT_GROUP/) for that attachment as it is likely to match the avatar's group.

// group join inviter
// gets the name of the object's active group from the online group profile

key groupNameRequestId;
key groupKey;
string groupName;

init()
{
    // WARNING:
    // different prims can have different active groups!!!

    // get the key of the root prim's group
    groupKey = llList2Key(llGetObjectDetails(llGetLinkKey(LINK_ROOT), [OBJECT_GROUP]), 0);

    // request the name of the root prim's group
    groupNameRequestId = llHTTPRequest("http://world.secondlife.com/group/" + (string)groupKey, [], "");
}

default
{
    state_entry()
    {
        init();
    }

    touch_start(integer num_detected)
    {
        if (groupKey == NULL_KEY || groupName == "")
            return;

        key id = llDetectedKey(0);
        llInstantMessage(id,
            "Click the link to join the group '" + groupName + "'\n"
            + "secondlife:///app/group/" + (string)groupKey + "/about");
    }

    http_response(key request_id, integer status, list metadata, string body)
    {
        if (request_id != groupNameRequestId)
            return;

        list args = llParseString2List(body, ["title"], []);
        groupName = llList2String(llParseString2List(llList2String(args, 1), [">", "<", "/"], []), 0);
    }
}

## Helper functions

See [Link/Get](https://wiki.secondlife.com/wiki/Category:LSL_Link/Get) for some [link](https://wiki.secondlife.com/wiki/Category:LSL_Link) related helper functions. Also see [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/) if you need to get the position and rotation of a linked prim.

```lsl
integer isLindenTreeOrGrass(key id){
    //Check if it's an OPT_OTHER and not an attachment, which makes it a Linden tree or grass!
    list out = llGetObjectDetails(id, [OBJECT_PATHFINDING_TYPE, OBJECT_ATTACHED_POINT]);
    return (llList2Integer(out, 0) == OPT_OTHER) && !llList2Integer(out, 1);
}
```

<LSLFunction name="llGetObjectPrimCount" />

Avatars sitting on the object are not counted`{{Footnote|[[llGetNumberOfPrims]] on the other hand does count avatars sitting on the object.|llGetNumberOfPrims on the other hand does count avatars sitting on the object.}}`. Zero is returned if **prim**: `(A)` is not found, `(B)` is part of an attachment`{{Footnote|Whether the attachment exception is a bug or a feature is unclear.|handle=attachment}}`, or `(C)` is not a prim.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is the total number of prims in the object that contains **prim**.

```lsl title="How to use" frame="terminal"
integer result = llGetObjectPrimCount(NULL_KEY);
```

## Caveats

- This cannot be used to detect if an avatar is seated (by checking for a non-zero return), use [llGetAgentInfo](/functions/llGetAgentInfo/) instead.
- The prim count for attachments are not returned`{{Footnote|handle=attachment}}`. If possible use [llGetNumberOfPrims](/functions/llGetNumberOfPrims/) instead.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={11-18}
default
{
    touch_start(integer num)
    {
        integer prims = llGetObjectPrimCount(llGetKey());
        if (prims == 0)
        {
            // llGetObjectPrimCount returns zero for attachments.
            prims = llGetNumberOfPrims();
            // Avatars can't sit on attachments so this is ok.
        }
        llOwnerSay("This object has "
                    + (string)prims
                    + " prims and "
                    + (string)(llGetNumberOfPrims() - prims)
                    + " avatars.");
    }
}
```

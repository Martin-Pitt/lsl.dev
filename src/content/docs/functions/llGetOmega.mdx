<LSLFunction name="llGetOmega" description />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the rotation velocity of the object in radians per second.

```lsl title="How to use" frame="terminal"
vector result = llGetOmega();
```

## Caveats

- Returns the omega of the root if called in a child prim.

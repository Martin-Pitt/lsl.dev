<LSLFunction name="llGetRegionMoonDirection" />

Returns a normalized vector to the current moon position at the location of object containing the script. [llGetMoonDirection](/functions/llGetMoonDirection/) is the vector to the parcel's moon, [llGetRegionMoonDirection](/functions/llGetRegionMoonDirection/) is the vector to region's moon. If there is no custom environment set for the current parcel [llGetMoonDirection](/functions/llGetMoonDirection/) returns the direction to the region's moon. These functions are altitude aware.

```lsl title="How to use" frame="terminal"
vector result = llGetRegionMoonDirection();
```

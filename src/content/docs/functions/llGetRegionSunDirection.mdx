<LSLFunction name="llGetRegionSunDirection" />

Returns a normalized vector to the current sun position at the location of object containing the script. [llGetSunDirection](/functions/llGetSunDirection/) is the vector to the parcel's sun, [llGetRegionSunDirection](/functions/llGetRegionSunDirection/) is the vector to region's sun. If there is no custom environment set for the current parcel [llGetSunDirection](/functions/llGetSunDirection/) returns the direction to the region's sun. These functions are altitude aware.

```lsl title="How to use" frame="terminal"
vector result = llGetRegionSunDirection();
```

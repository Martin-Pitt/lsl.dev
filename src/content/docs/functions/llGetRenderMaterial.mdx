<LSLFunction name="llGetRenderMaterial" />

If the Material is in the prim's inventory, the return value is the inventory name, otherwise the returned value is the Material [UUID](https://wiki.secondlife.com/wiki/UUID).

Returns a [string](https://wiki.secondlife.com/wiki/string) that is the Material on **face**

```lsl title="How to use" frame="terminal"
string result = llGetRenderMaterial(0);
```

## Caveats

[NULL_KEY](/constants/NULL_KEY/)

is returned when the [owner](https://wiki.secondlife.com/wiki/Category:LSL_Owner) does not have [full permissions](https://wiki.secondlife.com/wiki/Category:LSL_Permissions/Asset) to the object and the Material is not in the prim's inventory.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Tells (on chat) the Material keys / Material names on 6 sides
default
{
    state_entry()
    {
        integer i = 0;
        integer max = llGetNumberOfSides();
        while(i < max)
        {
            llSay(0,"Side " + (string)i + " Material is: " + (string)llGetRenderMaterial(i));
            ++i;
        }
    }
}
```

</details>

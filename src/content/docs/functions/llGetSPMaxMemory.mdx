<LSLFunction name="llGetSPMaxMemory" description />

```lsl title="How to use" frame="terminal"
integer result = llGetSPMaxMemory();
```

## Specification

This function's behavior is dependent upon the VM the script is using. [Mono](#mono) is the new VM, [LSO](#lso) is the old VM. The big difference between between Mono and LSO is that Mono scripts run faster and can utilize four times more memory.

### Mono

During and after a [LlScriptProfiler](/functions/llScriptProfiler/) profiling run, `llGetSPMaxMemory` will return the most memory used during profiling.

### LSO

This function has no effect for scripts not compiled to Mono. It will always return 16384, the fixed LSO memory size.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-16}
// need to run something for the profile to register...
ScriptRotate()
{
    llTargetOmega(<0.5, 0.7, 0.2>, 0.75, 0.75);
}

default
{
    state_entry()
    {
        llSetMemoryLimit( 5000 ); // set the memory limit

        // call up the profiler, execute a method, stop profiler
        llScriptProfiler( PROFILE_SCRIPT_MEMORY );
        ScriptRotate();
        llScriptProfiler( PROFILE_NONE );

        // display memory usage...
        llSay(0, "Memory used: " + (string)llGetSPMaxMemory() + " bytes, total memory: " +
            (string)llGetMemoryLimit() + " bytes." );
    }
}

// outputs
// Object: Memory used: 4448 bytes, total memory: 5000 bytes.
```

</details>

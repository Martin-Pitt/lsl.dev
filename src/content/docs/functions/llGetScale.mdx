<LSLFunction name="llGetScale" description />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the scale of the prim.

```lsl title="How to use" frame="terminal"
vector result = llGetScale();
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        llSay(0, "My dimensions are: " + (string)llGetScale());
    }
}
```

</details>

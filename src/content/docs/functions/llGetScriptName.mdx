<LSLFunction name="llGetScriptName" />

Returns a [string](https://wiki.secondlife.com/wiki/string) that is the name of the script that called this function.

```lsl title="How to use" frame="terminal"
string result = llGetScriptName();
```

## Examples

<details open>
<summary>Remove the current script from the object</summary>

```lsl
default
{
    state_entry()
    {
        llRemoveInventory(llGetScriptName());
    }
}
```

</details>

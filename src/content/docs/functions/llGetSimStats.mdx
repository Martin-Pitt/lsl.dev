<LSLFunction name="llGetSimStats" description />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the requested statistic.

```lsl title="How to use" frame="terminal"
float result = llGetSimStats(0);
```

## Specification

| Name |  | Possible Return | Description |
| --- | --- | --- | --- |
| [SIM_STAT_PCT_CHARS_STEPPED](/constants/SIM_STAT_PCT_CHARS_STEPPED/) | 0 | \[0.0, 100.0\] | The % of pathfinding characters updated each frame, averaged over the last minute. The value corresponds to the "Characters Updated" stat in the viewer's Statistics Bar. |
| [SIM_STAT_PHYSICS_FPS](/constants/SIM_STAT_PHYSICS_FPS/) | 1 | \[0.0, Inf\] | Physics simulation FPS. |
| [SIM_STAT_AGENT_UPDATES](/constants/SIM_STAT_AGENT_UPDATES/) | 2 | \[0.0, Inf\] | Agent updates per second. |
| [SIM_STAT_FRAME_MS](/constants/SIM_STAT_FRAME_MS/) | 3 | \[0.0, Inf\] | Total frame time. |
| [SIM_STAT_NET_MS](/constants/SIM_STAT_NET_MS/) | 4 | \[0.0, Inf\] | Time spent in 'network' segment of simulation frame. |
| [SIM_STAT_OTHER_MS](/constants/SIM_STAT_OTHER_MS/) | 5 | \[0.0, Inf\] | Main simulation segment of frame, encapsulating task, script and misc. updates. |
| [SIM_STAT_PHYSICS_MS](/constants/SIM_STAT_PHYSICS_MS/) | 6 | \[0.0, Inf\] | Time spent in 'physics' segment of simulation frame. |
| [SIM_STAT_AGENT_MS](/constants/SIM_STAT_AGENT_MS/) | 7 | \[0.0, Inf\] | Time spent in 'agent' segment of simulation frame. |
| [SIM_STAT_IMAGE_MS](/constants/SIM_STAT_IMAGE_MS/) | 8 | \[0.0, Inf\] | Time spent in 'image' segment of simulation frame. |
| [SIM_STAT_SCRIPT_MS](/constants/SIM_STAT_SCRIPT_MS/) | 9 | \[0.0, Inf\] | Time spent in 'script' segment of simulation frame. |
| [SIM_STAT_AGENT_COUNT](/constants/SIM_STAT_AGENT_COUNT/) | 10 | \[0.0, Inf\] | Number of agents in region. |
| [SIM_STAT_CHILD_AGENT_COUNT](/constants/SIM_STAT_CHILD_AGENT_COUNT/) | 11 | \[0.0, Inf\] | Number of child (neighboring) agents in region. |
| [SIM_STAT_ACTIVE_SCRIPT_COUNT](/constants/SIM_STAT_ACTIVE_SCRIPT_COUNT/) | 12 | \[0.0, Inf\] | Number of active scripts in region. |
| [SIM_STAT_PACKETS_IN](/constants/SIM_STAT_PACKETS_IN/) | 13 | \[0.0, Inf\] | Average packets in per second. |

| [SIM_STAT_SCRIPT_EPS](/constants/SIM_STAT_SCRIPT_EPS/) | 21 | \[0.0, Inf\] | Script events per second. |
| [SIM_STAT_SPARE_MS](/constants/SIM_STAT_SPARE_MS/) | 22 | \[0.0, Inf\] | Spare time left after frame. |
| [SIM_STAT_SLEEP_MS](/constants/SIM_STAT_SLEEP_MS/) | 23 | \[0.0, Inf\] | Time spent sleeping. |
| [SIM_STAT_IO_PUMP_MS](/constants/SIM_STAT_IO_PUMP_MS/) | 24 | \[0.0, Inf\] | PumpIO time. |

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer num_detected)
    {
        float pct_chars_stepped = llGetSimStats(SIM_STAT_PCT_CHARS_STEPPED);
        llSay(0,
            "The percentage of pathfinding characters updated each frame was "
            + (string)pct_chars_stepped + "averaged over the last minute. The "
            + "value corresponds to the 'Characters Updated' stat in the "
            + "viewer's Statistics Bar. ");
    }
}
```

</details>

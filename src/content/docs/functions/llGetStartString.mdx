<LSLFunction name="llGetStartString" />

- If the containing object was manually rezzed, by dragging from inventory, the start string is blank.
- This function reads the start string of the object's root prim.
- Child prims of objects rezzed via `llRezObjectWithParams()` have an empty start string. Returns the initialization string passed to the object's root prim on rez with llRezObjectWithParams (via REZ_PARAM_STRING; returns an empty string if rezzed by an agent).

Returns a [string](https://wiki.secondlife.com/wiki/string) that was passed to the object's root prim on rez with [llRezObjectWithParams](/functions/llRezObjectWithParams/).

```lsl title="How to use" frame="terminal"
string result = llGetStartString();
```

## Caveats

- Start string survives script resets, region crosses and region restarts.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    on_rez(integer param)
    {
        llOwnerSay("rezzed with the number " + (string)param + " and a start string of \"" + llGetStartString() + "\"");
    }
    state_entry()
    {
        string s = llGetStartString();
        llOwnerSay("I was given the string \"" + s + "\" when I was rezzed");
    }
}
```

</details>

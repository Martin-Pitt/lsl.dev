<LSLFunction name="llGetStatus" description />

Returns an [integer](https://wiki.secondlife.com/wiki/integer) equal to the **status** of the object.

```lsl title="How to use" frame="terminal"
integer result = llGetStatus(0);
```

## Caveats

- Status is an object attribute; all prims in an object share the same status.
- [STATUS_BLOCK_GRAB](/constants/STATUS_BLOCK_GRAB/) only really deals with the root prim. Try [STATUS_BLOCK_GRAB_OBJECT](/constants/STATUS_BLOCK_GRAB_OBJECT/) instead.
- Querying for [STATUS_CAST_SHADOWS](https://wiki.secondlife.com/wiki/STATUS_CAST_SHADOWS) always returns [FALSE](/constants/FALSE/) regardless of the setting.
- Only one flag should be specified at a time. As of Second Life Server 2022-09-09.574921, if more than one flag is specified, [STATUS_DIE_AT_NO_ENTRY](/constants/STATUS_DIE_AT_NO_ENTRY/) takes priority, followed by [STATUS_BLOCK_GRAB_OBJECT](/constants/STATUS_BLOCK_GRAB_OBJECT/), [STATUS_DIE_AT_EDGE](/constants/STATUS_DIE_AT_EDGE/), [STATUS_RETURN_AT_EDGE](/constants/STATUS_RETURN_AT_EDGE/), [STATUS_BLOCK_GRAB](/constants/STATUS_BLOCK_GRAB/), [STATUS_SANDBOX](/constants/STATUS_SANDBOX/), [STATUS_ROTATE_Z](/constants/STATUS_ROTATE_Z/), [STATUS_ROTATE_Y](/constants/STATUS_ROTATE_Y/), [STATUS_ROTATE_X](/constants/STATUS_ROTATE_X/), [STATUS_PHANTOM](/constants/STATUS_PHANTOM/), and [STATUS_PHYSICS](/constants/STATUS_PHYSICS/).

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        if (llGetStatus(STATUS_PHYSICS))
        {
            llSay(0, "This object is physical");
        }
        else
        {
            llSay(0, "This object is not physical");
        }
    }
}
```

</details>

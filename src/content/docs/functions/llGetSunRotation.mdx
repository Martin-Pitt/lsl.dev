<LSLFunction name="llGetSunRotation" />

Return the rotation applied to the sun for the parcel at the location of the object containing the script. These function are altitude aware and so will pick up the sun for their current track. [llGetRegionSunRotation](/functions/llGetRegionSunRotation/) returns the rotation applied at the region level, [llGetSunRotation](/functions/llGetSunRotation/) does the same for the parcel. If there is no custom environment applied to parcel [llGetSunRotation](/functions/llGetSunRotation/) returns the same value as [llGetRegionSunRotation](/functions/llGetRegionSunRotation/).

```lsl title="How to use" frame="terminal"
rotation result = llGetSunRotation();
```

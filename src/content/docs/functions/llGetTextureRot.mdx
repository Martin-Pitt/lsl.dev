<LSLFunction name="llGetTextureRot" description />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the texture rotation, expressed as an `angle`, on **face**

```lsl title="How to use" frame="terminal"
float result = llGetTextureRot(0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//Tells the owner the texture rotation on all sides
default
{
    state_entry()
    {
        integer i = 0;
        integer max = llGetNumberOfSides();
        while(i < max)
        {
            llSay(0,"Face "+(string)i+" texture rotation is " + (string)llGetTextureRot(i));
            ++i;
        }
    }
}
```

</details>

<LSLFunction name="llGetVisualParams" />

An empty list if **agentid** is not found.

An empty string, "", is returned in the place of any invalid or unknown visual parameter.

Returns a [list](https://wiki.secondlife.com/wiki/list) of the details for **agentid** requested in **params**.

```lsl title="How to use" frame="terminal"
list result = llGetVisualParams(NULL_KEY, []);
```

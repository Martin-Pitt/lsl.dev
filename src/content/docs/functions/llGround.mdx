<LSLFunction name="llGround" description />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the ground height directly below the [prim position](/functions/llGetPos/) + **offset**

```lsl title="How to use" frame="terminal"
float result = llGround(ZERO_VECTOR);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={9-19}
// Makes the object land on ground or on water

FindGroundOrWater()
{
    vector vTarget = llGetPos();
    vTarget.z = llGround( ZERO_VECTOR );
    float fWaterLevel = llWater( ZERO_VECTOR );
    if( vTarget.z < fWaterLevel )
        vTarget.z = fWaterLevel;
    llSetRegionPos(vTarget);
}

default
{
    touch_start(integer total_number)
    {
        FindGroundOrWater();
    }
}
```

</details>

<LSLFunction name="llGroundContour" />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the ground contour direction below the prim [position](/functions/llGetPos/) + **offset**. The contour is the direction of a contour line at that point, that is the direction in which there is no change in elevation.

```lsl title="How to use" frame="terminal"
vector result = llGroundContour(ZERO_VECTOR);
```

## Specification

This function is defined as:

```lsl
vector llGroundContour(vector offset)
{
    vector slope = llGroundSlope(offset);
    return <-slope.y, slope.x, 0.0>;
}
```

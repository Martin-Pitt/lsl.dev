<LSLFunction name="llGroundNormal" description />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the ground [normal](https://en.wikipedia.org/wiki/Normal_%28geometry%29) from the current [position](/functions/llGetPos/) + **offset**.

```lsl title="How to use" frame="terminal"
vector result = llGroundNormal(ZERO_VECTOR);
```

## Specification

This function is defined as:

```lsl
vector llGroundNormal(vector offset)
{
    vector slope = llGroundSlope(offset);
    return <slope.x, slope.y, 1.0>;
}
```

## Notes

- There seems to some confusion be between a [Surface Normal](http://en.wikipedia.org/wiki/Normal_%28geometry%29) (the direction from the surface) and [Normalized Vector](http://en.wikipedia.org/wiki/Unit_vector) (a vector with a magnitude of 1.0, AKA Unit Vector). This function does **not** return a unit vector. Surface normals may encode additional information in the magnitude of the vector. If you need a Unit Vector, simply use [llVecNorm](/functions/llVecNorm/).

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is the ground slope below the object [position](/functions/llGetPos/) + **offset**

```lsl title="How to use" frame="terminal"
vector result = llGroundSlope(ZERO_VECTOR);
```

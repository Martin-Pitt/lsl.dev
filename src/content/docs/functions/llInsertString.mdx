<LSLFunction name="llInsertString" />

i.e. unlike other somewhat similar string functions such as [llGetSubString](/functions/llGetSubString/) and [llDeleteSubString](/functions/llDeleteSubString/), you cannot use -1 for the counting with this function. You may use instead the function provided a bit further below.

```lsl title="How to use" frame="terminal"
string result = llInsertString("", 0, "");
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
llInsertString("input", 2, "put out")// returns "input output"
```

</details>

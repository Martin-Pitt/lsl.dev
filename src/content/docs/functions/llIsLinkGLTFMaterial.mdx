<LSLFunction name="llIsLinkGLTFMaterial" description />

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is [TRUE](/constants/TRUE/) if the material is PBR and [FALSE](/constants/FALSE/) if it is [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) diffuse texture on **face**

```lsl title="How to use" frame="terminal"
integer result = llIsLinkGLTFMaterial(0, 0);
```

## Caveats

- Returns [FALSE](/constants/FALSE/) if link does not exist or refers to a multi-link target (such as [LINK_SET](/constants/LINK_SET/)).
- Returns [FALSE](/constants/FALSE/) if face does not exist.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-8}
//Tells (on chat) if the materials are PBR
default
{
    state_entry()
    {
        integer link = LINK_THIS;
        integer i;
        for(; i < llGetLinkNumberOfSides(link); ++i)
        {
            string message = "Side " + (string)i + " material is ";
            if (llIsLinkGLTFMaterial(link, i))
                message += "glTF/PBR";
            else
                message += "Blinn-Phong";
            llSay(0, message);
        }

        if (llIsLinkGLTFMaterial(link, ALL_SIDES))
            llSay(0, "All sides are PBR.");
        else
            llSay(0, "Some sides are Blinn-Phong (not PBR).");
    }
}
```

</details>

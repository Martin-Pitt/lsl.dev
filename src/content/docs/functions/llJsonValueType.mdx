<LSLFunction name="llJsonValueType" description />

Gets the [JSON](http://json.org) type for the value in **json** at the location **specifiers**.

```lsl title="How to use" frame="terminal"
string result = llJsonValueType("", []);
```

## Specification

See [Json usage in LSL](https://wiki.secondlife.com/wiki/Json_usage_in_LSL).

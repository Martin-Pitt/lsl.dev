<LSLFunction name="llKeyCountKeyValue" />

Start an asynchronous transaction to request the number of keys with the script's [Experience](/categories/experience/).

Returns a [key](https://wiki.secondlife.com/wiki/key) that can be used to identify the corresponding [dataserver](/events/dataserver/) event to determine if this command succeeded or failed and the results.

```lsl title="How to use" frame="terminal"
key result = llKeyCountKeyValue();
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={17-28}
key trans;
default
{
    state_entry()
    {
        trans = llKeyCountKeyValue();
    }


    dataserver(key t, string value)
    {
        if (t == trans)
        {
            // our llKeyCountKeyValue transaction is done
            list result = llCSV2List(value);
            if (llList2Integer(result, 0) == 1)
            {
                // data size retrieved
                llSay(0, "Keys in use: "+llList2String(result, 1));
            }
            else
            {
                // key count failed
                llSay(0, "Key-value failed to count keys: " + llList2String(result, 1) );
            }
        }
    }
}
```

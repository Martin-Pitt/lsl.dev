<LSLFunction name="llLinksetDataAvailable" />

The **`llLinksetDataAvailable`** returns the number of bytes available in the linkset's datastore.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) number of bytes available in the linkset store.

```lsl title="How to use" frame="terminal"
integer result = llLinksetDataAvailable();
```

<LSLFunction name="llLinksetDataCountFound" />

The **`llLinksetDataCountFound`** function returns the number of keys in the linkset datastore that match the **pattern** supplied in the **pattern**.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) Count of the keys in the datastore that match the supplied **pattern**.

```lsl title="How to use" frame="terminal"
integer result = llLinksetDataCountFound("");
```

## Specification

**pattern** is a [Regular expression](https://en.wikipedia.org/wiki/Regular_expression).

## Examples

<details open>
<summary>The following regular expression code can be used to count UUID keys. (Such as those use to identify user UUID)</summary>

```lsl
        integer numKeysFound = llLinksetDataCountFound("(?i)^[0-9a-f]{8}(-[0-9a-f]{4}){3}-[0-9a-f]{12}$",  0, 0);
```

</details>

<details>
<summary>The following code can also be used to count UUID keys in LinksetData memory.</summary>

```lsl
        integer numKeysFound = llLinksetDataCountFound("^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$",  0, 0);
```

</details>

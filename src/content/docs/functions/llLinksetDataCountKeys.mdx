<LSLFunction name="llLinksetDataCountKeys" />

The **`llLinksetDataCountKeys`** returns the number of unique keys that have been stored in the linkset's datastore.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) number of keys used in the linkset store.

```lsl title="How to use" frame="terminal"
integer result = llLinksetDataCountKeys();
```

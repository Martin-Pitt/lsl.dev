<LSLFunction name="llLinksetDataRead" />

The **`llLinksetDataRead`** and **[llLinksetDataReadProtected](/functions/llLinksetDataReadProtected/)** functions return the **value** in the linkset's datastore for the provided **name**. If **name** is not found, these functions return an empty string.

Reads an unprotected **name:value** pair from the linkset's datastore.

Returns a [string](https://wiki.secondlife.com/wiki/string) **value** corresponding to **name**

### Caveats

If the **name** is an empty string, or the **name:value** pair was created with [llLinksetDataWriteProtected](/functions/llLinksetDataWriteProtected/) this function returns an empty string.

```lsl title="How to use" frame="terminal"
string result = llLinksetDataRead("");
```

## Caveats

- While LSL scripts use [UTF-16](https://en.wikipedia.org/wiki/UTF-16) encoding for strings resulting in 2 bytes per character for codepoints up to U+FFFF or 4 bytes otherwise, linkset data uses [UTF-8](https://en.wikipedia.org/wiki/UTF-8) for a more varying encoding size (1 byte up to codepoint U+7F, 2 bytes up to U+7FF, 3 bytes up to U+FFFF and 4 bytes otherwise). Although a niche concern, this can result in strings not having an immediately obvious size and in very constrained situations, possibly not fit in script memory/linkset data.

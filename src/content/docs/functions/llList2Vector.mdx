<LSLFunction name="llList2Vector" description />

Returns a [vector](https://wiki.secondlife.com/wiki/vector) that is at **index** in **src**.

```lsl title="How to use" frame="terminal"
vector result = llList2Vector([], 0);
```

## Caveats

- When used to typecast from a string it will result in a [ZERO_VECTOR](/constants/ZERO_VECTOR/)
- A true typecast will solve this: ([vector](https://wiki.secondlife.com/wiki/vector))[llList2String](/functions/llList2String/)(**src**, index);
- Unfortunately, if it was already a vector type, using [llList2String](/functions/llList2String/) will cause the decimal values to be truncated to six decimal places.
- In any string representation of a vector such as [llList2String](/functions/llList2String/)(**src**, index), or (string) `llList2Vector` (**src**, index), spaces are automatically added after the commas. When received by a [listen](/events/listen/), make sure NOT to parse by spaces.

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-10}
// Best viewed in Chat History (ctrl-h)
default
{
    state_entry()
    {
        list my_list = ["a", 1, 2.0, <1,2,3>, <1,2,3,4>, llGetOwner()];
        integer i = ~llGetListLength(my_list);
        while(++i)
        {
            llOwnerSay("string=" + llList2String(my_list,i)
                        + "\n   integer=" + (string)llList2Integer(my_list,i)
                        + "\n   float=" + (string)llList2Float(my_list,i)
                        + "\n   vector=" + (string)llList2Vector(my_list,i)
                        + "\n   rot=" + (string)llList2Rot(my_list,i)
                        + "\n   key=" + (string)llList2Key(my_list,i) );
        }
    }
}
```

</details>

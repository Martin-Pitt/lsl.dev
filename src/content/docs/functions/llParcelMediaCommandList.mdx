<LSLFunction name="llParcelMediaCommandList" description />

Controls the playback of movies and other multimedia resources on a parcel or for an agent.

```lsl title="How to use" frame="terminal"
llParcelMediaCommandList([]);
```

## Specification

{/* Sorted/grouped based on everyday usage and related functionality. Order and groups: src/data/rule-groups/parcel-media.ts */}
<ConstantGroup name="ParcelMediaCommand" order={parcelMediaCommands} />

## Caveats

- This script's object must be owned by the landowner or the function will silently fail.
- If the script's object is over group owned land, then the object must be deeded to **that** group.
- If the [PARCEL_MEDIA_COMMAND_URL](/constants/PARCEL_MEDIA_COMMAND_URL/) value is greater than 254 characters, the command will silently fail.
- If using [PARCEL_MEDIA_COMMAND_URL](/constants/PARCEL_MEDIA_COMMAND_URL/) and [PARCEL_MEDIA_COMMAND_AGENT](/constants/PARCEL_MEDIA_COMMAND_AGENT/), make sure the *Media URL* in the *About Land ...* dialog is unset. See [SVC-4478](https://jira.secondlife.com/browse/SVC-4478).

## Examples

key myTexture = llGetTexture(0);

## Known issues

- [SVC-1764](https://jira.secondlife.com/browse/SVC-1764): Setting parcel media for a single agent was broken with new media functionality in release candidates of 1.19.1
- [SVC-4478](https://jira.secondlife.com/browse/SVC-4478): Using [PARCEL_MEDIA_COMMAND_AGENT](/constants/PARCEL_MEDIA_COMMAND_AGENT/) with [llParcelMediaCommandList](/functions/llParcelMediaCommandList/)() when parcel's [media URL](/constants/PARCEL_MEDIA_COMMAND_URL/) is set causes previous video [replay](/constants/PARCEL_MEDIA_COMMAND_PLAY/)

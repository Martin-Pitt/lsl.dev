<LSLFunction name="llParcelMediaQuery" description />

Returns a [list](https://wiki.secondlife.com/wiki/list) containing results of **query**. The results are in the same order as the request.

```lsl title="How to use" frame="terminal"
list result = llParcelMediaQuery([]);
```

## Specification

|  | Constant | Return | Description |
| --- | --- | --- | --- |
| 4 | [PARCEL_MEDIA_COMMAND_TEXTURE](/constants/PARCEL_MEDIA_COMMAND_TEXTURE/) | [key](https://wiki.secondlife.com/wiki/key) uuid | Used to get or set the parcel's media texture. |
| 5 | [PARCEL_MEDIA_COMMAND_URL](/constants/PARCEL_MEDIA_COMMAND_URL/) | [string](https://wiki.secondlife.com/wiki/string) url | Used to get or set the parcel's media url. |
| 10 | [PARCEL_MEDIA_COMMAND_TYPE](/constants/PARCEL_MEDIA_COMMAND_TYPE/) | [string](https://wiki.secondlife.com/wiki/string) mime_type | Used to get or set the parcel media MIME type (e.g. "text/html"). (1.19.1 RC0 or later) |
| 11 | [PARCEL_MEDIA_COMMAND_SIZE](/constants/PARCEL_MEDIA_COMMAND_SIZE/) | [integer](https://wiki.secondlife.com/wiki/integer) x, [integer](https://wiki.secondlife.com/wiki/integer) y | Used to get or set the parcel media pixel resolution. (1.19.1 RC0 or later) |
| 12 | [PARCEL_MEDIA_COMMAND_DESC](/constants/PARCEL_MEDIA_COMMAND_DESC/) | [string](https://wiki.secondlife.com/wiki/string) desc | Used to get or set the parcel media description. (1.19.1 RC0 or later) |
| 13 | [PARCEL_MEDIA_COMMAND_LOOP_SET](/constants/PARCEL_MEDIA_COMMAND_LOOP_SET/) | [float](https://wiki.secondlife.com/wiki/float) loop | Used to get or set the parcel's media loop duration. (1.19.1 RC0 or later) |

## Caveats

- This script's object must be owned by the landowner or the function will silently fail.
- If the script's object is over group owned land, then the object must be deeded to **that** group.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
//-- quick function to tell you the URL of the Media the Parcel is set for
default{
  touch_start( integer vIntNull ){ //-- named null because we're ignoring it
    llSay( 0, "The Media URL is\n" + (string)llParcelMediaQuery( (list)PARCEL_MEDIA_COMMAND_URL ) );
  }
}
```

<LSLFunction name="llPow" />

Returns NaN when **base** is negative and **exponent** is not an integer (an imaginary result, `(exponent != (integer)exponent) && (base < 0.0)`).

Returns a [float](https://wiki.secondlife.com/wiki/float) that is **base** raised to the power **exponent** (**base**<sup>**exponent**</sup>)

```lsl title="How to use" frame="terminal"
float result = llPow(0.0, 0.0);
```

## Caveats

- If **exponent** is a static integer and not a variable, `llPow` is dramatically slower than simple repeated multiplication, i.e. it's much faster to do `val = base*base*base` instead of `val = llPow(base, 3)`.
- Triggers a [Math Error](https://wiki.secondlife.com/wiki/Category:LSL_Error/Math) for imaginary results if not compiled in Mono.

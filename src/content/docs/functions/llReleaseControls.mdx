<LSLFunction name="llReleaseControls" description />

Stop taking inputs (that were taken with [llTakeControls](/functions/llTakeControls/)), dequeues any remaining [control](/events/control/) events. If [PERMISSION_TAKE_CONTROLS](/constants/PERMISSION_TAKE_CONTROLS/) was previously granted, it will be revoked.

```lsl title="How to use" frame="terminal"
llReleaseControls();
```

## Caveats

- In some cases, calling `llReleaseControls()` in one script can affect the controls of other script which has also captured the same control bit on the same agent.

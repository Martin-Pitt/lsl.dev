<LSLFunction name="llResetAnimationOverride" />

Resets the animation override of the specified animation state (**anim_state**) to the corresponding default value. Requires the PERMISSION_OVERRIDE_ANIMATIONS permission.

If **anim_state** equals "ALL", all animation states are reset.

```lsl title="How to use" frame="terminal"
llResetAnimationOverride("");
```

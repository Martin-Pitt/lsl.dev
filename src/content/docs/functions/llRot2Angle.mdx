<LSLFunction name="llRot2Angle" />

Use in conjunction with [llRot2Axis](/functions/llRot2Axis/).

To undo use [llAxisAngle2Rot](/functions/llAxisAngle2Rot/).

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the rotation angle represented by **rot**

```lsl title="How to use" frame="terminal"
float result = llRot2Angle(ZERO_ROTATION);
```

## Caveats

This always returns a positive angle &lt;= [PI](/constants/PI/) radians, that is, it is the unsigned minimum angle. A rotation of 3/2 [PI](/constants/PI/) radians (270 degrees) will return an angle of [PI](/constants/PI/) / 2 radians, not -PI / 2.

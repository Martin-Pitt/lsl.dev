<LSLFunction name="llRot2Axis" />

Use in conjunction with [llRot2Angle](/functions/llRot2Angle/).

To undo use [llAxisAngle2Rot](/functions/llAxisAngle2Rot/) or [llAxes2Rot](/functions/llAxes2Rot/).

Returns a [vector](https://wiki.secondlife.com/wiki/vector) the rotation axis represented by **rot**

```lsl title="How to use" frame="terminal"
vector result = llRot2Axis(ZERO_ROTATION);
```

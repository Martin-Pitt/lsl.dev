<LSLFunction name="llScriptDanger" />

The usefulness of this function is limited as it does not give the reason why the script would be in danger. [llGetParcelFlags](/functions/llGetParcelFlags/) on the other hand can be used in much the same way and gives more detailed information.

Returns an [integer](https://wiki.secondlife.com/wiki/integer) that is [TRUE](/constants/TRUE/) if **pos** is over `public land`, `sandbox land`, land that doesn't allow everyone to edit and build, or land that doesn't allow outside scripts.

```lsl title="How to use" frame="terminal"
integer result = llScriptDanger(ZERO_VECTOR);
```

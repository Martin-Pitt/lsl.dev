<LSLFunction name="llSensorRemove" />

Removes the sensor setup by [llSensorRepeat](/functions/llSensorRepeat/).

There are no parameters or return value for this function, as only one [llSensorRepeat](/functions/llSensorRepeat/) can be specified per script.

```lsl title="How to use" frame="terminal"
llSensorRemove();
```

## Caveats

- If called within the [sensor](/events/sensor/) event then it also removes all of the sensor data that is accessed by the [detection](/categories/detected/) functions.

## Examples

<details open>
<summary>The following basic example shows an object that when touched starts scanning for avatars in 10m every 30 seconds, and stops as soon as at least one is found, and returns their name.</summary>

```lsl
default {
    touch_start(integer x) {
        llSensorRepeat("", NULL_KEY, AGENT, 10.0, PI, 30.0);
    }

    sensor(integer x) {
        llSay(0, llDetectedName(0) + " was found first!");
        llSensorRemove();
    }
}
```

</details>

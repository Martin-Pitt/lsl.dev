<LSLFunction name="llSetCameraAtOffset" />

Sets the point the camera is looking at to **offset** for avatars that sit on the object.

This is the point the camera looks at, not the [position of the camera's eye](/functions/llSetCameraEyeOffset/).

```lsl title="How to use" frame="terminal"
llSetCameraAtOffset(ZERO_VECTOR);
```

## Caveats

- Setting this will not update the cameras of seated avatars, it will only effect avatars that subsequently sit down. The camera settings have to be prepared in advance.
- The **offset** is [locally relative](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#local) to the object, if you want it relative to the seated [avatar](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#agent) (which likely has a custom sit rotation and offset) or the [region](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#region), you must do the computation yourself.
- [ZERO_VECTOR](/constants/ZERO_VECTOR/) **offset** will cancel any offset.
- Camera focus set by this function is a **Prim Property**. **It will survive the script** and it will survive prim taking and prim rezzing

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={1-8, 14-21}
// Set the seated avatar looking at an arbitrary direction
// Look over the avatar's shoulders from behind once it sits down

back_view(float degrees)
{
     rotation sitRot = llAxisAngle2Rot(<0, 0, 1>, degrees * DEG_TO_RAD);

     llSitTarget(<0, 0, 0.1>, sitRot);

     llSetCameraEyeOffset(<-2, 0, 1> * sitRot);
     llSetCameraAtOffset(<2, 0, 1> * sitRot);
}

default
{
    state_entry()
    {
        back_view( 208 );
        llSay(0, "Please sit down");
    }
}
```

</details>

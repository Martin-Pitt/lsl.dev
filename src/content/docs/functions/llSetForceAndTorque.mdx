<LSLFunction name="llSetForceAndTorque" description />

Sets the force and **torque** of object (if the script is physical)

```lsl title="How to use" frame="terminal"
llSetForceAndTorque(ZERO_VECTOR, ZERO_VECTOR, 0);
```

## Caveats

- If either value is [ZERO_VECTOR](/constants/ZERO_VECTOR/), the function eliminates both forces. Both values must be non-zero for this function to work. (The workaround to this is setting both separately.)

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        llSetForceAndTorque( <0.0,0.0,5.0>, <1.0,0.0,0.0>, FALSE );
    }
}
```

</details>

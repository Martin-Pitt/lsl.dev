<LSLFunction name="llSetLinkCamera" description />

Sets the camera **eye** offset, and the offset that camera is looking **at**, for avatars that sit on the **link**ed prim.

```lsl title="How to use" frame="terminal"
llSetLinkCamera(0, ZERO_VECTOR, ZERO_VECTOR);
```

## Caveats

- Setting this will not update the cameras of seated avatars, it will only effect avatars that subsequently sit down. The camera settings have to be prepared in advance.
- The offsets **at** and **eye** are [locally relative](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#local) to the prim, if you want it relative to the seated [avatar](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#agent) (which likely has a custom sit rotation and offset) or the [region](https://wiki.secondlife.com/wiki/Viewer_coordinate_frames#region), you must do the computation yourself.

Camera position and focus set by this function is a **Prim Property**. **It will survive the script** and it will survive prim taking and prim rezzing

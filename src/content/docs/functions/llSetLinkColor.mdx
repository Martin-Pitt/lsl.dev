<LSLFunction name="llSetLinkColor" />

If a prim exists in the link set at **link**, set the [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) **color** on **face** of that prim.

```lsl title="How to use" frame="terminal"
llSetLinkColor(0, ZERO_VECTOR, 0);
```

## Caveats

- `llSetLinkColor` will have no visible effect on faces with a PBR material. To work on faces both with and without a PBR material, use this snippet:

  ```lsl
  if (llIsLinkGLTFMaterial(LINK_THIS, ALL_SIDES)) {
      llSetLinkGLTFOverrides(LINK_THIS, ALL_SIDES, [OVERRIDE_GLTF_BASE_COLOR_FACTOR, llsRGB2Linear(color)]);
  } else {
      llSetLinkColor(LINK_THIS, color, ALL_SIDES);
  }
  ```

## Examples

<details open>
<summary>Turn a link set green</summary>

```lsl
default
{
    touch_start(integer detected)
    {
        llSetLinkColor(LINK_SET, <0.0, 1.0, 0.0>, ALL_SIDES);
    }
}
```

</details>

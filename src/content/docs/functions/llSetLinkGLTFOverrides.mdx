<LSLFunction name="llSetLinkGLTFOverrides" description />

Sets or removes individual overrides applied to a [PBR](https://wiki.secondlife.com/wiki/PBR) texture on a face

```lsl title="How to use" frame="terminal"
llSetLinkGLTFOverrides(0, 0, []);
```

## Specification

{/* Sorted/grouped based on everyday usage and related functionality. Order and groups: src/data/rule-groups/gltf-overrides.ts */}
<ConstantGroup name="GLTFOverride" order={gltfOverrides} />

Passing an empty string ("") as the override value will clear that override.

## Caveats

- `OVERRIDE_GLTF_BASE_COLOR_FACTOR` and `OVERRIDE_GLTF_BASE_ALPHA` parameters are coupled. If an override is set for one parameter, then the other is automatically given an override. The default `OVERRIDE_GLTF_BASE_COLOR_FACTOR` is `<1,1,1>`, and the default `OVERRIDE_GLTF_BASE_ALPHA` is 1.0.

## Examples

<details open>
<summary>Toggle alpha on\\off</summary>

```lsl
integer toggle;
default
{
    touch_start(integer num_detected)
    {
        toggle=!toggle;
        llSetLinkGLTFOverrides( LINK_THIS, 0, [
            OVERRIDE_GLTF_BASE_ALPHA_MODE, PRIM_GLTF_ALPHA_MODE_BLEND,
            OVERRIDE_GLTF_BASE_ALPHA, toggle]);
    }
}
```

</details>

<LSLFunction name="llSetLinkRenderMaterial" />

If a prim exists in the link set at **link**, set **material** on **face** of that prim. This function will clear most [PRIM_GLTF\_\*](https://wiki.secondlife.com/wiki/LlSetPrimitiveParams) properties on the face, with the exceptions of repeats, offsets, and rotation_in_radians

```lsl title="How to use" frame="terminal"
llSetLinkRenderMaterial(0, "", 0);
```

## Caveats

- If **material** is provided as [NULL_KEY](/constants/NULL_KEY/), the [glTF Material](https://wiki.secondlife.com/wiki/PBR_Materials) is removed from **face**, reverting back to any underlying [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) materials.

## Examples

<details open>
<summary>Cover a link set in the material my_material</summary>

```lsl
default
{
    touch_start(integer detected)
    {
        llSetLinkRenderMaterial(LINK_SET, my_material, ALL_SIDES);
    }
}
```

</details>

<LSLFunction name="llSetLinkSitFlags" description />

Sets flags on the link's sittarget.

```lsl title="How to use" frame="terminal"
llSetLinkSitFlags(0, 0);
```

## Specification

Sets the sit flags for the sit target in the link. Sit flags only apply when a sit target is present in the link.

| Flag |  | Description |
| --- | --- | --- |
| [SIT_FLAG_SIT_TARGET](/constants/SIT_FLAG_SIT_TARGET/) |  | Read-only flag to indicate whether the link has a sit target. Use [llSitTarget](/functions/llSitTarget/), [llLinkSitTarget](/functions/llLinkSitTarget/), or [PRIM_SIT_TARGET](/constants/PRIM_SIT_TARGET/) to disable or enable this flag. Use [llGetLinkSitFlags](/functions/llGetLinkSitFlags/), or [llGetLinkPrimitiveParams](/functions/llGetLinkPrimitiveParams/) with [PRIM_SIT_FLAGS](/constants/PRIM_SIT_FLAGS/) to read this flag. |
| [SIT_FLAG_ALLOW_UNSIT](/constants/SIT_FLAG_ALLOW_UNSIT/) |  | Allow an avatar to manually unsit from a sit target. Only applies to agents who had been seated via an LSL script. See [llSitOnLink](/functions/llSitOnLink/). |
| [SIT_FLAG_SCRIPTED_ONLY](/constants/SIT_FLAG_SCRIPTED_ONLY/) |  | Only allow scripted sits on this sit target. |
| [SIT_FLAG_NO_COLLIDE](/constants/SIT_FLAG_NO_COLLIDE/) |  | Disable the avatar's collision volume when they are seated on this sit target. |
| [SIT_FLAG_NO_DAMAGE](/constants/SIT_FLAG_NO_DAMAGE/) |  | Do not distribute damage to agents sitting on this sit target. |

## Caveats

- [SIT_FLAG_NO_COLLIDE](/constants/SIT_FLAG_NO_COLLIDE/) is applied at the time of sitting. Updating this flag will not change the collision behavior of an agent that was previously seated on the sit target.

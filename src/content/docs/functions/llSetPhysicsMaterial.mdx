<LSLFunction name="llSetPhysicsMaterial" description />

Used to set the physical characteristics of an object.

```lsl title="How to use" frame="terminal"
llSetPhysicsMaterial(0, 0.0, 0.0, 0.0, 0.0);
```

## Caveats

- Using [PRIM_MATERIAL](/constants/PRIM_MATERIAL/) to set the material type will reset the values for **friction** and **restitution** to that material's defaults.
- [llSetPhysicsMaterial](/functions/llSetPhysicsMaterial/) silently fails if called from an attachment.

## Examples

<details open>
<summary>Example 1</summary>

- Basic Example

```lsl
     llSetPhysicsMaterial(FRICTION, 1.0,0.9,0.1,0.5); // Sets FRICTION to 0.1
```

</details>

<details>
<summary>Example 2</summary>

- Multiple Settings

```lsl
     llSetPhysicsMaterial(GRAVITY_MULTIPLIER | RESTITUTION | FRICTION | DENSITY, 0.5,0.9,0.1,1.0);
```

</details>

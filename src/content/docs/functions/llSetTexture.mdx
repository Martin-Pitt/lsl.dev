<LSLFunction name="llSetTexture" description />

Sets the [Blinn-Phong](https://wiki.secondlife.com/wiki/PBR_Materials#nomenclature-changes) diffuse **texture** of this prim's **face**.

```lsl title="How to use" frame="terminal"
llSetTexture("", 0);
```

## Caveats

- [Inspect](https://wiki.secondlife.com/wiki/Inspect) does not show texture information (like [creator](/functions/llGetInventoryCreator/))

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        // the first texture alphabetically inside the same prim's inventory
        string texture = llGetInventoryName(INVENTORY_TEXTURE, 0);

        // set it on all sides of the prim containing the script
        llSetTexture(texture, ALL_SIDES);
    }
}
```

</details>

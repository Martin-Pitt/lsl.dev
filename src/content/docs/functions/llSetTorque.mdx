<LSLFunction name="llSetTorque" description />

Sets the **torque** of object (if the script is physical)

```lsl title="How to use" frame="terminal"
llSetTorque(ZERO_VECTOR, 0);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    touch_start(integer total_number)
    {
        llSetTorque(<0,10,0>,1);
                   //X  Y Z  Local
    }
}
```

</details>

<LSLFunction name="llSetVehicleRotationParam" description />

Sets the vehicle rotation parameter **param** to **rot**.

```lsl title="How to use" frame="terminal"
llSetVehicleRotationParam(0, ZERO_ROTATION);
```

## Specification

| Constant | `{{#if:{{#var:display_type}}\|!Type}}` | Description |
| --- | --- | --- |
| [VEHICLE_REFERENCE_FRAME](/constants/VEHICLE_REFERENCE_FRAME/) | 44 `{{#if:{{#var:display_type}}\|{{!}} [[rotation]]}}` | rotation of vehicle axes relative to local frame |

## Examples

The reference frame can be computed and set in two steps:

- Place the vehicle with front facing east(red arrow) and with left side facing north(green arrow)
- [llSetVehicleRotationParam](/functions/llSetVehicleRotationParam/)( [VEHICLE_REFERENCE_FRAME](/constants/VEHICLE_REFERENCE_FRAME/), [ZERO_ROTATION](/constants/ZERO_ROTATION/) / [llGetRootRotation](/functions/llGetRootRotation/)());

<LSLFunction name="llSetVehicleType" description />

Sets the vehicle type to one of the default types.

```lsl title="How to use" frame="terminal"
llSetVehicleType(0);
```

## Specification

| Flags |  | Description |
| --- | --- | --- |
| [VEHICLE_TYPE_NONE](/constants/VEHICLE_TYPE_NONE/) | 0 | Turns off vehicle support |
| [VEHICLE_TYPE_SLED](/constants/VEHICLE_TYPE_SLED/) | 1 | Simple vehicle that bumps along the ground, and likes to move along its local x-axis |
| [VEHICLE_TYPE_CAR](/constants/VEHICLE_TYPE_CAR/) | 2 | Vehicle that bounces along the ground but needs the motors to be driven from external controls or [timer](/events/timer/) events |
| [VEHICLE_TYPE_BOAT](/constants/VEHICLE_TYPE_BOAT/) | 3 | Hovers over water with lots of friction and some angular deflection |
| [VEHICLE_TYPE_AIRPLANE](/constants/VEHICLE_TYPE_AIRPLANE/) | 4 | Uses linear deflection for lift, no hover, and banking to turn |
| [VEHICLE_TYPE_BALLOON](/constants/VEHICLE_TYPE_BALLOON/) | 5 | Hover, and friction, but no deflection |

## Caveats

Scripted Vehicles can have a maximum Physics weight of 32.0 Above that the function will fail with a warning on the Debug Channel.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
llSetVehicleType(VEHICLE_TYPE_BALLOON);
```

<LSLFunction name="llSetVehicleVectorParam" description />

Sets the vehicle vector parameter **param** to **vec**.

```lsl title="How to use" frame="terminal"
llSetVehicleVectorParam(0, ZERO_VECTOR);
```

## Specification

| Constant | `{{#if:{{#var:display_type}}\|!Type}}` | Description |
| --- | --- | --- |
| [VEHICLE_ANGULAR_FRICTION_TIMESCALE](/constants/VEHICLE_ANGULAR_FRICTION_TIMESCALE/) | 17 `{{#if:{{#var:display_type}}\|{{!}} [[vector]]}}` | vector of timescales for exponential decay of angular velocity about the three vehicle axes |
| [VEHICLE_ANGULAR_MOTOR_DIRECTION](/constants/VEHICLE_ANGULAR_MOTOR_DIRECTION/) | 19 `{{#if:{{#var:display_type}}\|{{!}} [[vector]]}}` | angular velocity that the vehicle will try to achieve |
| [VEHICLE_LINEAR_FRICTION_TIMESCALE](/constants/VEHICLE_LINEAR_FRICTION_TIMESCALE/) | 16 `{{#if:{{#var:display_type}}\|{{!}} [[vector]]}}` | vector of timescales for exponential decay of linear velocity along the three vehicle axes |
| [VEHICLE_LINEAR_MOTOR_DIRECTION](/constants/VEHICLE_LINEAR_MOTOR_DIRECTION/) | 18 `{{#if:{{#var:display_type}}\|{{!}} [[vector]]}}` | linear velocity that the vehicle will try to achieve |
| [VEHICLE_LINEAR_MOTOR_OFFSET](/constants/VEHICLE_LINEAR_MOTOR_OFFSET/) | 20 `{{#if:{{#var:display_type}}\|{{!}} [[vector]]}}` | [offset](https://wiki.secondlife.com/wiki/offset) from the [center of mass](/functions/llGetCenterOfMass/) of the vehicle where the linear motor is applied. |

## Notes

- [VEHICLE_ANGULAR_MOTOR_DIRECTION](/constants/VEHICLE_ANGULAR_MOTOR_DIRECTION/) may conflict with any active [llTargetOmega](/functions/llTargetOmega/) set in the root prim and prevent vehicle turns. Call [llTargetOmega](/functions/llTargetOmega/) with a gain of 0 to disable it.

<LSLFunction name="llShout" description />

Shouts the text supplied in string **msg** on channel supplied in integer **channel**.

```lsl title="How to use" frame="terminal"
llShout(0, "");
```

## Caveats

- Text can be a maximum of 1024 bytes. This can convey 1024 ASCII characters, or 512 UTF-8 characters such as á
- Shouts can be heard within 100 meters of the speaking prim (rather than the root). This is contrary to how [listen](/events/listen/)s work, where a message can only be heard by any prim in the object if and only if the root prim is capable of hearing it.
- A prim can **not** hear itself, this to prevent problems with recursion. It can however hear other prims within the same object. Use [llMessageLinked](/functions/llMessageLinked/) instead for intra-prim messaging.

## Examples

<details open>
<summary>If you prefer, you can make use of certain mnemonic constants such as [PUBLIC_CHANNEL](/constants/PUBLIC_CHANNEL/) instead of channel 0 and [DEBUG_CHANNEL](/constants/DEBUG_CHANNEL/) instead of channel +2,147,483,647.</summary>

```lsl
default
{
    state_entry()
    {
        llShout(0, "I scream icecream!");
    }
}
```

</details>

For communicating with a user or owner it is preferable to use [llOwnerSay](/functions/llOwnerSay/) or [llInstantMessage](/functions/llInstantMessage/) or [llRegionSayTo](/functions/llRegionSayTo/) as they won't spam other users.

The latter is also an excellent choice for communicating to an attachment of a known avatar, or to an object of known UUID.

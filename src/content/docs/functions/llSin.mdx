<LSLFunction name="llSin" description />

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the sine of **theta**.

```lsl title="How to use" frame="terminal"
float result = llSin(0.0);
```

## Caveats

Because of IEE754 on floats , `llSin(PI)` returns -8.742278E-8 ( hex : 0xB3BBBD2E ) and not 0.0 . The error is cumulative with multiples of [PI](/constants/PI/) : For instance `llSin(100000.0*PI)` = 0.015890 when the result should be 0.0

## Examples

<details open>
<summary>Example 1</summary>

```lsl
// Touch the object with this script in it to see the sine of random numbers!
default
{
    touch_start(integer num)
    {
        float r = llFrand(TWO_PI);
        llOwnerSay("The sine of " + (string)r + " in radians or " + (string)(r * RAD_TO_DEG) + " in degrees is " + (string)llSin(r));
    }
}
```

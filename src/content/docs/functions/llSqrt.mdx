<LSLFunction name="llSqrt" />

For imaginary results (**val** &lt; 0.0), a [Math Error](https://wiki.secondlife.com/wiki/Category:LSL_Error/Math) is triggered under LSO , or 'NaN' (Not A Number) is returned under Mono

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the square root of **val**.

```lsl title="How to use" frame="terminal"
float result = llSqrt(0.0);
```

## Caveats

- Crashes the script if passed a negative number.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
  state_entry()
  {
    float num1 = llFrand(100.0);

    llOwnerSay("The square root of " + (string)num1 + " is " + (string)llSqrt(num1));
  }
}
```

</details>

## Notes

- If you need the square root of two, you can use the constant [SQRT2](/constants/SQRT2/).
- Other roots can be computed by [llPow](/functions/llPow/)(**val**, 1.0/**root**).

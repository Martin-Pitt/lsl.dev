<LSLFunction name="llStopSound" />

Stops the attached sound(s) currently playing, if they were started by [llLoopSound](/functions/llLoopSound/)

`{{LSL Function/Head |func=llStopSound |func_id=92|func_sleep=0.0|func_energy=10.0 |func_footnote |func_desc |return_text }}``{{LSL Function/Head |func=llLinkStopSound |p1_type=integer|p1_subtype=link|p1_name=link |func_id=|func_sleep=0.0|func_energy=10.0 |func_footnote |func_desc |return_text }}`

```lsl title="How to use" frame="terminal"
llStopSound();
```

## Caveats

- There is no way to stop a specific sound.
- In a linked set use [llLinkStopSound](/functions/llLinkStopSound/) to stop sound in a specific prim.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        llLoopSound("string soundname if in object inventory or UUID", 1.0);
    }
    touch_start(integer total_number)
    {
        llStopSound();//As if by magic the sound stops!!
    }
}
```

</details>

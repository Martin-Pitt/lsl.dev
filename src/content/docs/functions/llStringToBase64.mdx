<LSLFunction name="llStringToBase64" />

If extra bits are needed to complete the last base64 symbol, those extra bits will be zero.

To go in the other direction, use [llBase64ToString](/functions/llBase64ToString/). Returns the Base64 representation string of str, interpreting it as a UTF-8 byte sequence.

```lsl title="How to use" frame="terminal"
string result = llStringToBase64("");
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
integer getStringBytes(string msg) {
    return (llStringLength((string)llParseString2List(llStringToBase64(msg), ["="], [])) * 3) >> 2;
}
```

</details>

<LSLFunction name="llTeleportAgentHome" description />

Teleports **avatar** on owner's land to their home location without any warning, similar to a [God Summons](https://wiki.secondlife.com/wiki/God_Summons) or [dying](https://wiki.secondlife.com/wiki/death).

```lsl title="How to use" frame="terminal"
llTeleportAgentHome(NULL_KEY);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default
{
    state_entry()
    {
        // floattext is red and opaque
        llSetText("Don't touch me!", <1.0, 0.0, 0.0>, 1.0);
    }

    touch_start(integer num_detected)
    {
        key id = llDetectedKey(0);

        llTeleportAgentHome(id);
    }
}
```

</details>

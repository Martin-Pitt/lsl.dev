<LSLFunction name="llToUpper" description />

The opposite is [llToLower](/functions/llToLower/).

Returns a [string](https://wiki.secondlife.com/wiki/string) that is **src** with all upper-case characters.

```lsl title="How to use" frame="terminal"
string result = llToUpper("");
```

## Caveats

- There is no Linden Library "llToProperCase", which would return *[correctly](http://en.wikipedia.org/wiki/Sentence_case)* capitalized strings; However, there are user functions that do this: [ToNormal](https://wiki.secondlife.com/wiki/User:Fred_Gandt/Scripts/Functions#tonormal)
- The function also works for many characters outside the 7-bit ASCII range, especially latin, cyrillic and greek, but not all characters tagged as "lowercase" in the Unicode specification are converted.

## Examples

<details open>
<summary>Example 1</summary>

```lsl
string msg = "I like candy!";
string p = llToUpper(msg);
llOwnerSay(p);//Will say "I LIKE CANDY!"
```

</details>

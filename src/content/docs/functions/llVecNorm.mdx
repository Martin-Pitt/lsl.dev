<LSLFunction name="llVecNorm" description />

If **vec** is a [ZERO_VECTOR](/constants/ZERO_VECTOR/), than the value returned is a [ZERO_VECTOR](/constants/ZERO_VECTOR/).

```lsl title="How to use" frame="terminal"
vector result = llVecNorm(ZERO_VECTOR);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl
default {
    state_entry()
    {
        vector input = <1.0,2.0,3.0>;
        llSay(0,"The unit vector on "+(string)input+" is: "+(string)llVecNorm(input) );
    }
}
```

</details>

## Notes

- Mathematically equivalent to:
- **vec** / [llVecMag](/functions/llVecMag/)( **vec** )
- **vec** / `llSqrt( vec.x * vec.x + vec.y * vec.y + vec.z * vec.z )`

## Known issues

From the issue templates included by the wiki article:

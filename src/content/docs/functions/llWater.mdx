<LSLFunction name="llWater" />

Water height is constant across each entire sim and is typically 20 meters but not always.

Returns a [float](https://wiki.secondlife.com/wiki/float) that is the water height below the prim's [position](/functions/llGetPos/) + **offset**

```lsl title="How to use" frame="terminal"
float result = llWater(ZERO_VECTOR);
```

## Examples

<details open>
<summary>Example 1</summary>

```lsl collapse={10-19}
// Makes the object land on ground or on water

FindGroundOrWater()
{
    vector vTarget = llGetPos();
    vTarget.z = llGround( ZERO_VECTOR );
    float fWaterLevel = llWater( ZERO_VECTOR );
    if( vTarget.z < fWaterLevel )
        vTarget.z = fWaterLevel;
    llSetRegionPos(vTarget);
}

default
{
    touch_start(integer total_number)
    {
        FindGroundOrWater();
    }
}
```

</details>

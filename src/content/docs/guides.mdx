Start with a small working script, then explore the events and functions that bring it to life. These learning paths connect the language reference with tutorials in the local wiki archive.

## Start scripting

<Steps>

1. **Write your first script.**

   [A Basic LSL Tutorial](/wiki/a-basic-lsl-tutorial-8d4e4ac0/) introduces scripting in Second Life.

2. **Understand the building blocks.**

   Read the [Fundamentals](/fundamentals/): [types](/fundamentals/types/), [states and events](/fundamentals/states-and-events/) and [flow control](/fundamentals/flow-control/).

3. **Respond to an interaction.**

   Read the [event reference](/events/) and look up [touch_start](/events/touch_start/) and [llSay](/functions/llSay/).

4. **Build something useful.**

   Choose a task below, then follow its function reference for parameters, examples, and caveats.

</Steps>

## Where the content comes from

lsl.dev is an **unofficial** site. It is not affiliated with or endorsed by Linden Lab. It merges two sources:

- **[LSL Definitions](https://github.com/secondlife/lsl-definitions)** supplies signatures, parameter names and descriptions, return types, constant values, categories and other metadata.
- **The official [LSL Wiki](https://wiki.secondlife.com/wiki/LSL_Portal)** supplies descriptive prose, caveats and examples, kept as written in the original revisions.

Wiki content is used under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), and every page that uses it links to its source revision and history. See [About these docs](/about/) for snapshot dates and details.

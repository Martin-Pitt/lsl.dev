Wiki description

Used with llGetAgentInfo to determine if the queried avatar has 'always running' set.

Examples

    // This is a code fragment only
    if (llGetAgentInfo( llGetOwner() ) & AGENT_ALWAYS_RUN)    
        llSay(0, "Give me a rest!");

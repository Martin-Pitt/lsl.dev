Example Scripts

Come to this page to see short examples of how to use parts of LSL.
Go to the Script Library page to see more complex examples that show how to combine parts of LSL.
For documentation of a User Function you can use the LSL Function template with parameter mode=user set. It's very important to set this parameter to avoid adding the User Function to the Index of Standard LSL Functions! You can get a prototype of the template for filling in the blanks here.

A user's legacy name depends upon what type of account it is:
TypeFormat
Legacy "FirstName LastName"
Modern "FirstName Resident"
See Avatar/Name for more details.
Random fact: Prior to the recent wiki upgrade, to log in to the Second Life Wiki, users would have to use their Legacy Name. Which meant users with Modern accounts would have to use the Legacy last name "Resident". Despite the change to the login method, wiki usernames are still legacy names.

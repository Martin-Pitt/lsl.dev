Wiki description

Prim Blinn-Phong color or alpha parameters have changed

Examples

default
{
    changed(integer change)
    {

        if (change & CHANGED_COLOR) //note that it's & and not &&... it's bitwise!
        {
            llOwnerSay("The color or alpha changed.");
        }
    }
}

Wiki description

Prim Media on the prim has changed.

Examples

default
{
    changed(integer change)
    {
        if (change & CHANGED_MEDIA) //note that it's & and not &&... it's bitwise!
        {
            llOwnerSay("The prims media has changed.");
        }
    }
}

Wiki description

Used with llRequestAgentData to return the string "0, 0, 0, 0, 0, 0".
The CSV list returned used to contain the positive and negative ratings the user has acquired before ratings were removed from SL.

History

  • Originally returning:
    • "pos_behavior, neg_behavior, pos_appearance, neg_appearance, pos_building, neg_building"
  • Negative ratings were later removed, leaving this to return:
    • "pos_behavior, 0, pos_appearance, 0, pos_building, 0"
  • Much later ratings were removed outright leaving this to return:
    • "0, 0, 0, 0, 0, 0"

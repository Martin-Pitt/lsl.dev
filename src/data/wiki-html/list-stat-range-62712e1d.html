Wiki description

Calculates the range of the list. (max - min)

Examples

float range = llListStatistics( LIST_STAT_RANGE, numList );
float max = llListStatistics( LIST_STAT_MAX, numList );
float min = llListStatistics( LIST_STAT_MIN, numList );
float range = max - min;

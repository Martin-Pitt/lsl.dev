Wiki description

This event is triggered on all attachments worn by an avatar when that avatar's health reaches 0.

Examples

default
{
    on_death()
    {
        llSay(0, "Faster, faster, Bambi! Don't look back! Keep running! KEEP RUNNING!");
    }
}

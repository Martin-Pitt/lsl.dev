Wiki description

Which action will be taken when left-clicking the prim. Followed by one of these flags:
<div style="padding: 0.5em;">
Flag Description Cursor
CLICK_ACTION_NONE0Performs the default action: when the prim is touched, touch events are triggered
CLICK_ACTION_TOUCH0When the prim is touched, touch events are triggered
CLICK_ACTION_SIT1When the prim is touched, the avatar sits upon itFile:SitActionCursor.png‎
CLICK_ACTION_BUY2When the prim is touched, the buy dialog is openedFile:SaleOneclickCursor.png
CLICK_ACTION_PAY3When the prim is touched, the pay dialog is openedFile:SaleOneclickCursor.png
CLICK_ACTION_OPEN4When the prim is touched, the object inventory dialog is openedFile:OpenOneclickCursor.png
CLICK_ACTION_PLAY5Play or pause parcel media on touchImage:Toolplay.png
CLICK_ACTION_OPEN_MEDIA6Play parcel media on touch, no pauseImage:Toolmediaopen.png
CLICK_ACTION_ZOOM7Zoom the avatar camera on this object (Viewer 2)Image:Toolzoom.png
CLICK_ACTION_DISABLED8No click action. No touches detected or passed.
CLICK_ACTION_IGNORE9Clicks go through the object to whatever is behind it. No touches detected.
</div></div>

Caveats

  • The caveats described at llSetClickAction all apply to PRIM_CLICK_ACTION.

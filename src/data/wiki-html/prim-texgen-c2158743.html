Wiki description

PRIM_TEXGEN is used to get and set the configure the texture mapping mode of the face.
PRIM_TEXGEN_DEFAULT integer 0 m=3 s3=colspan="6" c=The texture repeats units are in texture repeats per face.
PRIM_TEXGEN_PLANAR integer 1 m=3 s3=colspan="6" c=The texture repeats units are in texture repeats per half meter. This is in contrast to the in-world editing tool, in which the planar texture scaling units are repeats per meter.

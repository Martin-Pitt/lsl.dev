Wiki description

This status flag would set an object's ability to cast shadows.
There is no client support for this feature. "that would be good, but would require a protocol change to include the information (the existing protocol does send a flag for this, but it's defunct)" — Runitai Linden, Mesh User Group, 2011-07-18 12:13

Transfer Options

Flags Parameters Description
TRANSFER_DEST0 [ TRANSFER_DEST, string ]Sets a root path that will be used as the parent for folder. If the root path does not exist it will be created. If it already exists in the target inventory it will be reused. Path folders are separated by a "|" character. The path may have have up to 4 folders in it. Note that transfers to certain system folders (such as 'Trash') are disallowed. Examples:
"Objects|Vehicles|My Motorcycle Company"
"Clothing|Shoes|Breedables"
"My Store|Home & Garden|"
TRANSFER_FLAGS1 [ TRANSFER_FLAGS, integer ] There are no flags defined at this time.

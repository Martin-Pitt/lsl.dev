Wiki description

Returned by llDetectedTouchPos, llDetectedTouchNormal, and llDetectedTouchBinormal when the touch position is not valid.

Caveats

  • For llDetectedTouchPos, LSL VR: {{LSL VR|0.0|0.0|0.0}} may be a valid value so it is possible to get a false negative in this rare situation.

Notes

  • Is treated like FALSE in conditionals.
